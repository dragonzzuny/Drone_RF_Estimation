# 드론 복소 I/Q 분리: 현행 목표와 실행계획

갱신: **2026-10-09 14:10 KST**. 실행 상태는 이 시점의 확인 결과다. [이전 계획·상태 기록](PLAN_HISTORY_THROUGH_20261009_1243_KO.md)을 보존하고, 현재 규약과 종료된 계획을 구분했다.

## 목표와 범위

혼합 I/Q만으로 각 기록의 기여 파형을 복원하고, 새 원기록·기종·조합으로 일반화되는지 검증한다. 우선 범위는1–3성분이며 성능을 실시간성보다 우선한다. 원 규모 모델·GPU 학습·seed0 초기 비교를 유지한다. 논문 주장은 확인한 복원 개선과 일반화 범위에 맞춘다.

현재 출력은 세 복소 성분 슬롯과 배경 슬롯이다. 정답·기종·실제 합성 개수는 추론 입력으로 전달하지 않는다. 학습과 채점에서 한 평가 구간 전체에 하나의 PIT 순열을 적용한다. 출력 슬롯의 순서를 맞추는 평가는 기종 식별·긴 구간의 출력 추적을 입증하지 않는다.

현재 정답은 **공통 관측 RF 대역으로 제한한 원기록 기여 파형**이며 수신 잡음도 포함한다. 합성한 기록 수를 물리 드론 대수로 취급하지 않는다. 원기록의 송신 방향·국소 활동 정답이 불충분하기 때문이다. 최근 NMF 없는 U-Net/WaveNet 성과를 Deep NMF 개선으로 부르지 않는다. 기존 detector 및 DR-NMF D2 학습은 중단 지시를 유지한다.

## 후속 가설과 검증

기존 긴20.89ms 보조 특징은 시간 평균을 거쳐 순서 정보를 잃는다. 단순히 입력 특징의 길이가 길다고 긴 복소 시간 구조를 학습했다고 설명하지 않는다. [구조·최신 선행 검토](../reports/2026-10-09/ARCHITECTURE_REVIEW_KO.md).

후속 후보는32인접 복소 표본을64실수 채널로 재배열하고 전체20.8896ms에서 기존0.63872ms 구간을 복원한다. 재배열은 표본 삭제·재표본화가 아니다. 두 군은 전체 혼합RMS·시간평균 전력 특징·초기 파라미터를 공유하고, 복원 구간 밖 복소 표본의 가림 여부만 바꾼다. 가린 군도 전체RMS와 전력 특징을 받는다. [후속 규약](../reports/2026-10-09/PHASE_CONTEXT_COMPARISON_KO.md).

전체 입력 CPU 검사·긴/짧은 파형45혼합 대응·독립 지표 계산·먼 복소문맥 접근 검사는 통과했다. GPU사전 검사에서 유한 기울기와 고정TRAIN4의 최종NMSE 감소를 확인해야 본학습을 시작한다. 두 군의 개수head는 기존 시간평균 특징을 사용하며 긴 복소문맥을 직접 읽는 새로운 개수추정기는 아니다.

CPU의 TRAIN48 정답 전력 마스크 진단에서FFT512→32768 확대는2/3성분 NMSE를 악화했다. 긴 복소문맥 제공과 국소STFT 창 확대는 다른 변경이다. 정답을 이용한 진단은 추론 성능·성능 상한이 아니다. [전체 설정·결과](../reports/2026-10-09/STFT_RESOLUTION_TRAIN.md).

## 고정된 데이터 원칙

- RFUAV 한 데이터셋·같은 원 RF 대역 안에서 합성한다. 다른 수신기·데이터셋과 풀링하지 않는다. native100MS/s를 유지하고 수신 중심주파수 차이를 보존한다. 수신 중심을 실제 송신 반송파 정답으로 간주하지 않는다.
- 긴 구간에서 상대 전력·위상을 정한 뒤 짧은 창을 추출한다. 짧은 창마다 각 성분을 전력1로 다시 만들지 않는다. 명목 전력차와 창별 실제 전력차를 구분한다.
- 원기록 묶음을 먼저 분할한다. 현재 학습8묶음·개발검증5묶음이며 검증은VTSBW20이어서 기록과 대역폭 변화가 함께 있다. 많은 혼합 창을 독립 녹음 수로 세지 않는다.
- 학습·검증 기종은Avata2/FPV/Mavic3Pro(5.8GHz),Mini3/Mini4Pro(2.4GHz)다. 가능한2성분 조합4개,3성분 조합1개가 현재 규약에 포함된다. 개발630행의3성분이 한 대역·조합에 한정된 점을 공개한다.
- Autel과 기존 예약 확인파일6개는 계속 미개봉이다. 확인자료로 모델·학습량·임계값을 고르지 않는다. 기존 전이 모델을 쓸 때는 부모의 노출 이력도 포함한다.
- 명시적 조종기·기체/조종기 결합 라벨은 제외한다.37범주 중 나머지가 모두 조종기라고 단정하지 않는다. 영상 여부는 편입 기준이 아니며 기체 송신 텔레메트리·상태·응답·식별도 대상이다. 추가 후보는 송신원 확인 후 별도 명세로 편입한다.

파일·세션·Mini3 메타데이터 불일치·중복 검사·송신 방향의 한계는 [자료 정책](DATA_POLICY_KO.md), [조합 계획](DIVERSITY_MIXTURE_PLAN_KO.md), [37범주 검토](../reports/2026-10-07/RFUAV_SCOPE_CORRECTION_KO.md)를 따른다. 기존 cross-band 탐색은 역사적 결과로 구분한다. DroneDetect 후속은 자체 데이터·native표본률로 독립 구성한다.

## 성공 판정과 논문화

파형 비교는 보정하지 않은 복소I/Q NMSE, 평균 제거·복소 배율 투영 SI-SDR, 혼합 대비 개선량, 약한 성분 및 모든 성분의 성공/실패를 함께 보고한다. 전체 평균 감소가 약신호 악화를 가리지 않도록 기종·대역·명목/실제 전력차별로 확인한다. 현재 후속의 채택 기준은2/3성분 모두NMSE 감소와SI-SDR 증가이며 약신호·개수 실패도 별도로 공개한다.

개수의 정확도·혼동행렬은 파형 복원과 별도다. [공통2epoch의 대역별 개수 진단](../reports/2026-10-09/COUNT_BAND_E002.md)처럼 한쪽 조건만의 높은 정확도를 전체 성공으로 해석하지 않는다. 국소 활동 정답 없이 파일 개수를 물리 대수로 바꾸지 않는다.

개발에서 모델·예산·평가를 고정한 뒤 새 원기록·기종·조합의 확인 평가를 구분한다. 통계는 원기록 수와 한seed의 한계를 반영한다. 드론 식별 효과는 같은 식별기에 혼합/복원/원신호를 넣은 별도 비교로 검증한다. STFT나 파형이 보기 좋아진 것을 식별 향상으로 대신하지 않는다. 확인된 기여·근거로 한국어 원고와 발표자료를 갱신한다.

## 운영과 보고

각epoch의 실제 완료·검증값·이전epoch 대비·현재 다음 작업을 대화에서 보고한다. 로컬 감시기는30초마다 상태와 완료 기록을 갱신하지만 채팅 자동 발송 서비스는 아니다. GPU 작업과 CPU 분석을 분리해 병행하고, 실행 중 소스·규약·데이터 해시는 고정한다.

후속v1 대기는 학습 시작 전에v2로 교체했다. RustDesk 화면 처리CUDA를 다른 학습기로 오인하던 조건만 수정했고 모델·학습·평가 계산은 그대로다. 해당 실행파일·해시·사용자·메모리 상한을 고정했으며 미확인 CUDA 작업은 계속 차단한다. 원기록·규약·스냅샷·교체 이유를 보존했다.

검산한 코드·결과·그림을 지정 저장소에 커밋·푸시한다. 원시I/Q·체크포인트·개인 경로 및 인증정보는 Git에 올리지 않는다. 불필요한 산출물은 현재 의존성을 확인한 뒤 정리하고 근거와 삭제 이력을 남긴다. 이번 정리는 계획 문서만 현행화하고 기존 연구 기록을 보존했다.
