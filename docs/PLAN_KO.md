# 드론 복소 I/Q 분리: 현행 목표와 실행계획

갱신: 2026-10-11. 아래 실행 상태는 각 worker의 STATE·저장점과 대조한다.

## 목표와 현재 실행

혼합 I/Q만으로 최대3개 원기록의 기여 파형을 복원하고, 다른 녹음과
기종에서 일반화되는지 검증한다. 정답·기체명·실제 합성 개수는 추론
입력에 제공하지 않는다. 파형 복원 성능을 실시간성보다 우선한다.

**4위상 대8위상 비교와 CPU 감사가 완료됐으며8위상을 새 추론 최선으로 선택했다.**
같은 native e2 U-Net 가중치에서 DEV630의 두·세 성분 NMSE·복소SI-SDR·최약NMSE
공동 기준을 통과했다. 학습0회, 총5040forward,5분34초였다.
[현재 최선과 사용 설정](CURRENT_BEST_KO.md),
[전체 결과](../reports/2026-10-11/PHASE_EIGHT_RESULT_KO.md).
이번에 실행한 GPU·CPU 실험은 모두 종료됐다. 다음 실험은 아직 자동 등록하지 않았다.

별도 시간 변화 인코더 실험은 **전체1epoch를 완료하고 중지**했다.
TRAIN2400혼합·75업데이트,DEV630의단일/4위상 평가와 CPU 감사를 마쳤다.
4위상 NMSE2/3는0.447189/0.688616으로, 세 성분만 소폭 개선했다.
최약NMSE는 두·세 성분 모두 악화하여 기존e0를 유지한다.
기존131가중치는 정확히 유지되고 새735,232파라미터는 학습됐다.
학습6분54초,평가3분6초. 같은 설정을 자동 연장하지 않는다.
[전체 결과](../reports/2026-10-11/ORDERED_BRANCH_RESULT_KO.md),
[기종별 사후 분석](../reports/2026-10-11/ORDERED_BRANCH_CONDITIONAL_ANALYSIS_KO.md).

TF-GridNet 전체/출력층 적응도 공동 개선 기준을 실패했다. 반면 TF64의
4위상 추론은 TRAIN30의73성분 중72개에서 두 지표가 함께 좋아졌다.
이는 반복 TRAIN 진단이며 현재 DEV 최선과 순위를 매기지 않는다.
[TF 진단](../reports/2026-10-11/TFGRIDNET_PHASE_PROBE_RESULT_KO.md).

8위상 비교는 위상 평균의 이득이 더 남았는지 확인하는 한 번의 추가 검사다.
연속 각도/계수 탐색이나 무조건 개선을 가정하지 않는다. 위상 평균은
시간상 호핑 반복 구조와 다른 특성이다. 기존 후보 대기열은 재개하지 않는다.

## 현재 검증된 최선

별도 녹음 DEV630에서 기존 U-Net의 여덟 위상 추론을 선택한다.

|추론 설정|두 성분 NMSE↓|세 성분 NMSE↓|두 성분 복소SI-SDR↑ dB|세 성분 복소SI-SDR↑ dB|
|---|---:|---:|---:|---:|
|기존 U-Net,1회|0.466896|0.690253|3.777|−3.109|
|기존 U-Net,4위상 평균|0.446896|0.689089|4.174|−2.784|
|기존 U-Net,8위상 평균·선택|0.444601|0.688948|4.249|−2.736|

여덟 위상은 여덟 번의 추론이며 정답 없이 출력끼리 대응한다. 평균 개선은
작고 세 성분 약신호 문제는 남아 있다. 아래 TRAIN4 숫자와 직접 순위를
매기지 않는다. 선택 가중치는 native `SELECTED_005.pt`의 e2이다.

## 이번 진단에서 확인한 것

- warm-start 전체 U-Net256은 TRAIN4 NMSE2/3=0.027757/0.194550,
  복소SI-SDR18.814/7.379dB였다. 세 성분은 마지막까지 개선했고
  모든 성분 NMSE≤0.05에는 미달했다. CPU 파형 재추론을 통과했다.
  [전체 결과](../reports/2026-10-11/CONVERGENCE_RESULT_KO.md).
- 정답을 이용한 최적 복소 배율로도 이 U-Net의 세 성분 NMSE는
  0.194550→0.193556만 줄었다. 단순히 출력을 키우는 것보다
  파형 분리 오차를 줄이는 방법이 우선이다.
  [오차 분해](../reports/2026-10-11/CONVERGENCE_RESIDUAL_KO.md).
- 출력 공간에서 보였던 손실 충돌은 같은 초기4혼합의 실제 파라미터
  기울기에서는 확인되지 않았다. coherence 항을 원인으로 단정하지 않는다.
- 전체 TF-GridNet64는 TRAIN4 NMSE2/3=0.076288/0.308528,
  복소SI-SDR12.011/4.932dB, 세 성분 최약NMSE0.541124였다.
  CPU 저장점·optimizer 감사를 통과했지만 모든 성분 NMSE≤0.05에는 미달했다.
  [64회 전체 결과](../reports/2026-10-11/TFGRIDNET_CONTINUATION_RESULT_KO.md).
- 고정4개 밖의32 TRAIN 혼합에서 NMSE2/3=1.007672/10.509555,
  복소SI-SDR1.126/−5.351dB였다. 새 기종·기록·전력 조건이 함께 다르다.
  사후 전력 분해에서 −25dB 미만8성분의 평균 NMSE47.64였으며 이를
  삭제하거나 복원 성공으로 해석하지 않는다.
  [범위별 전체 결과](../reports/2026-10-11/TFGRIDNET_OUTSIDE_FIT_RESULT_KO.md).
- 배경 출력을 약신호 출력으로 바꾼 한 사례에서 NMSE는 낮아졌지만
  SI-SDR은 더 나빠졌다. 순서만 맞추면 정밀 복원이 되는 상태는 아니었다.
  [출력 배정 검사](../reports/2026-10-11/TFGRIDNET_ROUTING_RESULT_KO.md).
- 계산 설정 검사에서 chunk64는 느렸고 BF16은 수치 기준을 실패했다.
  FP32 chunk32를 유지한다. 상세 추적의 시스템 OOM 실패도 남겼다.
  [시간·정확도 검사](../reports/2026-10-11/TFGRIDNET_THROUGHPUT_RESULT_KO.md).

## 다음 판단 순서

### 사용자 재확인: 속도보다 복원 성능

2026-10-11 사용자가 성능 우선을 재확인했다. 추론 시간이나 학습 시간을
줄이는 것 자체를 새 방법의 채택 기준으로 삼지 않는다. 추가 계산이 필요해도
별도 녹음에서 두·세 성분의 I/Q NMSE와 최약 성분 NMSE가 낮아지고
복소 SI-SDR이 함께 개선되는 방법을 우선한다. 기종·전력 조건별 결과도
유지하여 전체 평균만으로 약신호의 악화를 가리지 않는다.

- 현재8위상 추론은 계산량 증가를 감수하고 유지한다. 더 큰 모델·긴 문맥·
  여러 예측의 결합도 성능 근거가 있다면 후보이며 속도만으로 제외하지 않는다.
- 새 학습 실험은 구현과 자료 검사를 통과한 뒤 학습 곡선을 볼 수 있는
  예산과 중단 기준을 사전 등록한다. 특정 실험의1epoch 중지는 해당 조건의
  미채택 결과이며, 그 구조가 충분히 학습해도 실패한다는 증거가 아니다.
- 사용자가 중지를 지시한 기존 실험은 종료 상태로 보존한다. 이번 선호
  재확인만으로 종료한 대기열을 자동 재개하거나 기존 결과를 바꾸지 않는다.
- 실행 속도와 자원 사용량은 기록하지만, 성능 개선의 대용 지표로 쓰지 않는다.

현재는 계획 반영 단계다. 후속 위상 일관성 학습은 아직 구현·실행하지 않았다.

1. 이번에는8위상이 기준을 통과했지만 세 성분 NMSE 감소는0.0206%다.
   각도 수만 계속 늘리는 고정 대기열은 만들지 않는다. 큰 잔차는 해결되지 않았다.
2. 다음 학습 후보는 추론에서 효과를 보인 **위상별 복원의 일관성**을 학습 목표
   또는 경로에 반영하는 방법이다. 기존 canonical phase와 복소 마스크 실패를
   재검토하고, 현재8위상을 그대로 대조로 쓴다. 아직 구현·학습·효과검증 전이다.
3. 시간 변화 경로는 새 파라미터가 실제 갱신됐지만 약한 성분이 악화했다.
   긴 문맥을 넣었다는 사실만으로 개선을 전제하지 않으며 동일 설정은 연장하지 않는다.
4. TMLR2025의 위상 수신기는 pilot/LS입력·2수신안테나·bit LLR 연구다.
   단일채널 드론 파형 분리의 검증 근거와 구분한다.
   [원문·코드 검토](../reports/2026-10-11/PHASE_EQUIVARIANCE_REVIEW_KO.md).
5. 최종 방법을 동결한 뒤 미개봉 확인 자료를 사용한다. repeated DEV의
   작은 개선을 통계적 우월성 또는 논문화 완료로 해석하지 않는다.

## 자료와 해석 통제

RFUAV 한 데이터셋의 같은 원 RF 대역끼리 합성하고 native100MS/s와
수신 중심 간격을 유지한다. 긴 구간에서 전력·위상을 정한 뒤 잘라서,
짧은 창마다 정답 성분을 전력1로 바꾸지 않는다. 수신 중심 메타데이터는
실제 송신 반송파 정답을 보장하지 않는다.

원기록을 먼저 나눴다. TRAIN8묶음·83파일, DEV5묶음·48파일이며
DEV의 VTSBW20 조건이 TRAIN에는 없어 기록 변화와 수집 조건 변화가
함께 있다. 이 사실만으로 원인을 확정하거나 DEV를 TRAIN으로 옮기지 않는다.
현재5기종의 서로 다른 두 기종4조합·세 기종1조합이라는 제한을 공개한다.

조종기 단독·명시적 기체/조종기 결합 라벨은 제외한다. 영상 여부는
편입 기준이 아니며 기체명 폴더만으로 기체 단독 송신을 보증하지 않는다.
37범주·358파일·53 XML묶음의 최근 감사에서 추가 승인 TRAIN 묶음은0개다.
Autel 및 예약 확인 파일은 미개봉이다. DroneDetect는 별도 데이터셋 실험으로
관리하며 RFUAV와 섞지 않는다. [자료 정책](DATA_POLICY_KO.md).

복원 정답은 수신 잡음을 포함한 원기록 기여 파형이다. 합성 기록 개수와
실제 드론 대수를 구분한다. NMF 없는 현재 모델을 Deep NMF 개선으로
부르지 않으며 정밀 복원·범용 분리·논문 게재를 입증한 것으로 표시하지 않는다.

## 기록과 운영

GPU는 공유 잠금 아래 한 worker, CPU 검산은 별도 제한 코어로 실행한다.
소스·규약·체크포인트 지문을 보존한다. 저장점마다 활성 채팅에서 보고하고
로컬 알림도 남긴다. 로컬 알림은 자동 채팅 메시지가 아니다.

종료된 SepTDA26구간·통합e1·50%보정 및 각 방법의 결과와 미채택 이유는
[보존된 이전 계획](PLAN_HISTORY_THROUGH_20261011_TF32_KO.md)과
[같은75업데이트 방법 표](../reports/2026-10-10/METHOD_LEDGER_KO.md)에 있다.
기존 소스·수치·가중치를 삭제하거나 종료된 대기열을 재개하지 않았다.
