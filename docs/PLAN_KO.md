## 목표

관측 혼합 I/Q만으로 각 드론 기록의 기여 파형을 복원하며, 처음 보는 원기록·기종·조합에서도 성능이 유지되는지 검증한다. 사용자 지시에 따라 이번 가변 개수 범위는 1–3개 신호로 제한한다. 최종 논문 주장은 **검증된 일반화 범위와 복원 개선**에 맞춘다. NMF 없는 최근 U-Net의 개선을 Deep NMF 개선이라고 부르지 않는다.

모델이 정답 파형 없이 추론한다는 사실은 암기 가능성을 배제하지 않는다. 새로운 녹음과 기종에 대한 평가가 핵심이다. 완벽한 분리나 범용성을 미리 약속하지 않는다.

기존 고정 N은 과거 학습 이력이 다른 **전이 기준선**이다. 새 모델과의 차이를 PIT 하나의 인과적 개선량으로 해석하지 않는다. PIT 자체의 기여를 분리하는 고정 순서/PIT 감독 비교는 후속으로 남긴다. 이번 우선 비교는 세 출력에 동일한 PIT를 쓰면서 시간 문맥을 유지하는 TCN과 시간 평균 문맥만 주는 동일 TCN이다. 두 군의 초기화·자료·출력·손실·업데이트 수는 같다.

## 합성 및 학습

- 긴 원기록 구간에서 상대 전력을 정하고 복소 위상·시간 위치를 무작위화한 뒤 짧은 입력 창을 추출한다. 짧은 창마다 각 신호를 다시 같은 전력으로 만들지 않는다.
- 모든 군은 같은 원기록·혼합 목록·최적화 업데이트 수를 사용한다. 처음 본 기종으로 학습량·체크포인트·임계값을 고르지 않는다.
- 두 신호 비교에서는 기존 모델도 정답 두 개에 대한 두 가지 출력 순서를 모두 채점한다. 이 정답 기반 순서 맞추기는 **평가용**이고 추론에 정답이 들어가지 않는다.
- 이번 3출력 비교에서는 각 출력에 특정 기종을 고정하지 않고, 전체 파형에 하나의 순열을 적용하는 PIT를 사용한다. 창마다 정답을 보고 다른 순열을 고르는 방식은 제외한다. 실제 긴 파형 추론의 창 간 출력 추적은 혼합·예측만으로 구현하고 별도 검증한다.
- 비활성 출력은 0 정답과 혼합 전력으로 정규화한 누출 손실을 사용한다. 별도 배경 출력이 있어 0대 입력에 대해 드론 출력 합을 잡음과 억지로 같게 만들지 않는다.
- 처음에는 ±10dB 및 0dB를 공통 조건으로 사용하고, 강·약 신호를 따로 보고한다. 추가한 STFT 크기 손실은 기존 대조의 검증 결과에 따라 채택 여부를 정하며 선반영하지 않는다.

2026-10-06 CPU 입력 검사에서 첫 학습 epoch의 84.0%는 설정 SIR과 국소 SIR이 3dB 넘게 달랐다. 따라서 새 다기종 평가는 설정 SIR 결과와 실제 창별 SIR 결과를 함께 기록한다. 설정값만으로 모든 창의 약한 기종을 지정하지 않는다. 수신 잡음 전력도 포함되므로 작은 전력 창을 물리 드론 부재 정답으로 사용하지 않는다. [검사 범위와 결과](../reports/2026-10-06/MIXTURE_INPUTS_KO.md). 이는 입력의 진단이며 분리 모델의 개선 결과가 아니다.

새 다기종 주 비교는 원 규모 U-Net, seed 0, 최대 50 epoch를 기본 후보로 한다. 자료량이 달라지므로 기존 3,750업데이트와 자동으로 같은 학습량이라고 부르지 않는다. 데이터 고정 후 샘플 수·배치·실제 업데이트 예산을 명시하고 GPU 처리량을 측정한 다음 실행한다. 5·10·25·50 epoch의 중간 결과와 검증 선택 규칙을 사전에 고정한다.

## 성공 판정

1. **복원:** 조건별 성분 NMSE와 절대 SI-SDR, 혼합 대비 SI-SDR 개선량, STFT 크기 오차를 함께 산출한다. 출력 배율은 정답으로 보정하지 않는다. 두 성분 중 하나만 맞는 경우를 별도 집계한다.
2. **약신호:** −10dB와 +10dB를 각각 보고, 평균 개선이 한쪽의 악화를 가리지 않도록 한다. 기종·기록·대역폭·활동량별 결과를 남긴다.
3. **일반화:** 새 원기록, 새 기종, 새 조합을 구분한다. 동일 원기록의 많은 창을 독립 표본으로 세지 않고 원기록 단위 결과를 함께 제시한다. 원기록 수가 적은 경우 통계적 우월성을 과장하지 않는다.
4. **개수:** 정확 일치율·MAE·혼동행렬과 약신호 누락/가짜 추가 출력률을 측정한다. 1–3개 기여 기록의 수와 실제 물리 드론 대수를 구분한다. 국소 송신이 없는 창에 파일 개수만 정답으로 강제하지 않도록 긴 구간 또는 활동 주석을 사용한다.
5. **식별 효과:** 파형이 보기 좋아진 것과 식별에 도움이 된 것을 별도 입증한다. 새 식별기 학습은 검증 분할을 다시 섞지 않는다.

진행 여부를 판단하는 첫 기준은, 보류한 조건에서 동일 예산 기준선보다 NMSE가 낮고 혼합 대비 SI-SDR 개선량이 양수인지를 확인하는 것이다. 이것만으로 논문 게재나 완벽한 분리를 선언하지 않는다. 수치 목표를 결과 확인 후 유리하게 바꾸지 않는다.

## 전력 처리 대조의 완료 결과

2026-10-06, DRFF의 동일 50 epoch 대조와 저장 출력 84개 검산을 완료했다. 긴 구간 전력 보존 N은 전체 NMSE 0.970858로 기존 창별 정규화 N의 0.377778보다 나빴고, 양쪽 약신호도 악화했다. 이 변경을 현재 N의 개선안으로 채택하지 않는다. 기존 정규화를 유지하는 비로그 STFT 크기 손실 대조는 별도로 진행한다. [최종 결과](../reports/2026-10-06/POWER_COMPARISON_KO.md).

새 RFUAV의 혼합 로더는 국소 변동을 보존하는 입력 생성 후보로 남긴다. 이 입력 검산을 성능 개선 근거로 쓰지 않는다. 이번 RFUAV 대조의 학습 전력 처리·검증 선택 규칙은 별도 실행 규약과 PREPARATION.json에 고정했다. 이전 DRFF의 실패를 RFUAV 전체 방법의 실패로 일반화하지 않는다.

## 기존 실행과 저장소

2026-10-06 사용자 제안으로 시간 구조를 추가 검토했다. RFUAV 학습 후보 249구간의 CPU 분석에서 149구간에 약 2.5/4/5ms 전력 반복 후보가 관찰됐다. 기존 한 번 입력 길이는 0.63872ms다. 약 20ms 혼합 문맥의 시간·주파수 특징과 원 규모 복소 복원 경로를 결합하는 후보를 설계하며, 측정 주기를 기종별 상수로 강제하지 않는다. 호핑 해독이나 분리 성능 개선을 완료한 결과는 아니다. [범위·검산·대조 설계](../reports/2026-10-06/TEMPORAL_STRUCTURE_KO.md).

N 전체 구간 전력 보존 50 epoch는 완료·비채택으로 기록했다. 비로그 STFT 크기 손실 50 epoch 대조는 GPU에서 실행 중이다. 새 다기종 학습의 실행기·큐 연결을 완료했다. 전체 입력 GPU 사전 검사를 선행 조건으로 등록했으며 통과 전 본 학습을 시작했다고 표시하지 않는다. 기존 크기 손실과 창 병합 검산 뒤 새 시간 대조가 실행되고 native RF 원 비교는 그 뒤 재개한다.

이 저장소에 검증된 코드·분할 명세·표·진행 기록을 커밋한다. 원자료와 가중치는 외부에 보관하며, Git에 원자료가 없다는 이유로 자료를 합성했다고 오인하지 않도록 출처와 해시를 별도 명세한다.

## 방법 근거와 작성 절차

출력 순서 문제는 [Yu 외의 PIT 연구](https://arxiv.org/abs/1607.00325)를 참고한다. 이는 음성에서 제안된 학습 방법의 적용 후보이며 드론 성능을 보장하는 근거가 아니다. 데이터 수집과 파일 해석은 [RFUAV 저자 저장소](https://github.com/kitoweeknd/RFUAV/) 및 [원문](https://arxiv.org/html/2503.09033v2)을 확인했다.

원기록 단위 반복·혼동 요인·사전 비교 규칙 정리에는 experimental-design 절차를 참고했다. 절차 출처: Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026). *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*. [arXiv:2609.00065](https://arxiv.org/abs/2609.00065), 2026-09-02 개정판 확인. 연구 성능 근거로 인용한 것은 아니다.

## 최대 세 신호와 긴 시간 문맥 구현

2026-10-06 추가 지시에 따라 이번 실행 범위는 최대 세 신호다. 전체 U-Net에 약 21ms 혼합 문맥을 연결하는 TCN·Transformer·양방향 LSTM 후보와 1/2/3개 개수 head를 구현했다. 105개 학습 자료 합성 입력과 34개 CPU 구조·자료 검사를 통과했다. 정규 입력 GPU 사전 검사·새 자료 학습·성능 평가는 아직 하지 않았다. 동일 파라미터의 시간 평균 대조와 ordered TCN을 우선 비교하며, 구체적인 정답 범위와 비교 조건은 [구현 보고](../reports/2026-10-06/CONTEXT_THREE_KO.md)에 기록했다. 이전 4출력 코드는 호환용이며 이번 실행 대상으로 해석하지 않는다.

## 실제 실행 연결

후속 지시로 43개 CPU 검사를 통과한 학습·평가 실행기와 동일 seed 0, 50 epoch/3,750업데이트의 시간 문맥 2군 대조를 고정했다. 검증 630개와 첫 두 학습 epoch 4,800개의 문맥 특징을 준비했고, 현재 N 크기 손실 worker를 유지한 채 GPU 실행 대기열에 새 비교를 등록했다. 1/2/3개 정답은 이번 단계에서 합성 기록 성분 수이며 물리 드론 대수 검증은 아니다.
