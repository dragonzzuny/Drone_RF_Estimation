# 드론 복소 I/Q 분리: 현행 목표와 실행계획

갱신: **2026-10-10 01:26 KST**. [직전 계획과 종료된 비교 이력](PLAN_HISTORY_THROUGH_20261010_0029_KO.md)을 보존했다. 실행 상태는 기록 시점 기준이다.

## 목표와 현재 범위

혼합 I/Q만으로 1–3개 원기록의 기여 파형을 복원하고, 새 기록·기종·조합에서 일반화되는지 검증한다. 복원 성능을 실시간성보다 우선하며 원 규모 모델과 seed 0의 첫 대조를 유지한다. 정답·기종·실제 합성 개수는 추론 입력으로 제공하지 않는다.

현재 목표는 공통 관측 RF 대역에 포함된 기록 기여 파형이다. 수신 잡음도 정답에 포함한다. 합성 기록 수는 물리 드론 대수 정답과 다르며 기체 송신 방향·실제 동시 수신 정답을 확보한 것으로 표시하지 않는다. 현재 NMF 없는 U-Net 결과를 Deep NMF 개선으로 부르지 않는다. detector 및 DR-NMF D2는 중단 지시를 유지한다.

## 완료한 비교와 결론

- 새 초기화 WaveNet 두 군과 U-Net의 각 5 epoch·375업데이트 비교에서 U-Net이 앞섰다. 모델 크기·계산량이 달라 계열 전체의 우열 또는 충분한 수렴의 증거는 아니다. [완료 비교](../reports/2026-10-09/ARCHITECTURE_FINAL.md).
- 전체 20.89 ms 복소 문맥 후보는 같은 예산 대조에서 채택 기준을 충족하지 못했다. 입력을 길게 주는 것만으로 유용한 시간 구조를 학습했다고 주장하지 않는다. [완료 결과](../reports/2026-10-09/PHASE_CONTEXT_FINAL.md).
- 기존/log1p 손실·학습률 5e-4/1e-4를 각각 총 3 epoch까지 확인했다. 낮은 학습률의 선택은 기존 e1·log1p e2이며, 시작 모델의 네 평균 파형 지표를 함께 넘지 못했다. e1은 모델·optimizer·RNG를 정확히 가져왔고 각 군에 150업데이트만 추가했다. [전체 결과와 같은 epoch의 학습률 대조](../reports/2026-10-09/LOW_LR_CONTINUATION_FINAL.md), [학습 곡선](../reports/2026-10-09/LOW_LR_CONTINUATION_EPOCHS.pdf).
- 출력 표현·기울기·국소 전력·합 일치·정답 이용 배율 보정·단독 파형의 선형 기종 구분도 검사했다. 실패 결과와 한계는 [직전 계획](PLAN_HISTORY_THROUGH_20261010_0029_KO.md)에 연결해 보존한다.

## 보존 중인 최선의 구성

이전에 학습한 native RF U-Net 선택 e2를 유지한다. 같은 개발검증에서 단일 추론의 NMSE 2/3는 0.466896/0.690253, SI-SDR은 3.777/−3.109 dB다. 네 위상 평균은 0.446896/0.689089, 4.174/−2.784 dB이며 추가 추론이 필요한 별도 조건이다. 더 긴 부모 학습 이력 때문에 새 초기화 구조 대조와 구분한다.

세 성분 약신호 NMSE는 네 위상 평균에서도 0.948934다. 완벽 복원·범용 분리·드론 식별 향상을 입증한 상태는 아니다. [추론 검토](../reports/2026-10-09/NATIVE_RF_INFERENCE_DIAGNOSIS.md), [상수 배율·DC로 제거 가능한 잔차 진단](../reports/2026-10-09/CURRENT_AFFINE_RESIDUALS.md).

## 현재 GPU 본 비교

**기존 최선 U-Net / 성분 상호작용 출력층을 추가한 U-Net**의 대조를 시작했다. 양쪽 모두 같은 부모와 전체 본체를 사용하며, 원 손실·새 AdamW 1e-5·자료 일정·실효 batch 32·각 추가 3 epoch/225업데이트를 맞춘다. 첫 군은 기존 U-Net이며 초기 개발검증을 재현한 뒤 학습한다.

두 군의 추가 e1은 완료했고 후보 e2가 진행 중이다. e1의 개발 NMSE 2/3는 기존 0.488902/0.699657, 후보 0.488915/0.699675로 모두 부모보다 악화했다. 선택은 양쪽 e0다. CPU TRAIN48에서는 두 군 모두 적합도가 조금 개선됐으나 서로 차이가 작았다. TRAIN4에서 추가층만 켜고 끈 파형 변화 에너지도 혼합 대비 약 1e−8 수준이다. 다음 새 층 학습률 비교는 검토 후보이며 아직 GPU 대기열에 등록하지 않았다.

같은 TRAIN의 38개 다중 혼합에서 정답 전력 비율 마스크의 NMSE 2/3는 0.074709/0.262007이었다. 정답을 사용하는 진단값으로, 실제 모델 성능이나 성능 한계가 아니다. 전력 배분을 실제로 학습할 여지는 검토하되, 기존 전력 KL 보조 손실의 실패 이력을 함께 고려한다. [e1과 CPU 진단 종합](../reports/2026-10-10/SOURCE_INTERACTION_E1_DIAGNOSIS_KO.md).

추가층은 37,888파라미터다. 기존 초기 출력을 정확히 유지하고 세 성분 보정의 합을 0으로 만든다. 긴 문맥·개수 head·자료를 동시에 변경하지 않는다. 전체 SepTDA의 재현이나 이미 검증된 드론 분리 방법으로 표시하지 않는다.

GPU 사전 검사에서는 고정 TRAIN4·각 32업데이트의 NMSE 2/3가 기존 0.073123/0.368011, 후보 0.072147/0.367325였다. 차이는 작고 학습 적합도다. 사전 검사 가중치는 폐기했으며 본 비교는 공통 부모에서 다시 시작한다. [검사 전체 결과](../reports/2026-10-10/SOURCE_INTERACTION_PREFLIGHT_AUDIT.md), [본 비교 규약](../reports/2026-10-10/SOURCE_INTERACTION_MAIN_PLAN_KO.md), [epoch별 결과](../reports/2026-10-10/SOURCE_INTERACTION_PROGRESS.md).

선택은 e0를 포함한 2·3성분 평균 raw NMSE 최소 규칙을 유지한다. 채택 판단에는 같은 예산 대조와 부모 대비 NMSE 감소·복소 SI-SDR 증가를 함께 확인한다. 약신호·1성분 보존·개수 실패·모든 성분의 성공 여부를 함께 남긴다. 마지막 실제 모델과 선택 모델은 구분한다.

## 데이터와 평가 통제

- RFUAV 한 데이터셋의 같은 원 RF 대역끼리 합성한다. native 100MS/s와 수신 중심 간격을 보존한다. 중심 메타데이터를 실제 송신 반송파 정답으로 간주하지 않는다.
- 긴 구간에서 상대 전력·위상을 정한 뒤 자른다. 짧은 창마다 성분을 전력 1로 다시 정규화하지 않는다. 명목 전력차와 창별 실제 전력차를 구분한다.
- 원기록 묶음을 먼저 분할한다. 학습 8묶음·개발 5묶음이며, 630창을 독립 기록 630개로 세지 않는다. 검증 대역폭 변화와 기록 변화가 함께 있다.
- 현재 학습·검증은 Avata2/FPV/Mavic3 Pro의 5.8 GHz 및 Mini3/Mini4 Pro의 2.4 GHz다. 서로 다른 기종의 두 성분 4조합·세 성분 1조합이며, 조합 다양성의 제한을 공개한다.
- 같은 기종의 다른 기록을 이용한 9개 두 성분 구성·14개 세 성분 구성은 별도 후보다. 현재 로더를 바꾸거나 진행 중인 학습에 끼워 넣지 않는다.
- 조종기 단독·명시적 기체/조종기 결합 라벨은 제외한다. 폴더 이름만으로 기체 단독 송신을 보증하지 않는다. 영상 여부는 편입 기준이 아니며 송신원 근거를 확인한다.
- Autel 및 예약 확인 파일 6개는 미개봉이다. 개발 선택을 고정한 뒤 확인 평가를 진행한다. DroneDetect는 자체 데이터셋·native 표본률의 별도 후보이며 RFUAV와 풀링하지 않는다.

## 선행·수학 검토에서 얻은 다음 판단

세 신호 선행에는 IQUMamba-1D, SepFormer, SepTDA 및 ADS-B SplitNet-3가 있다. 대상·단일/다중 채널·복소 파형/이진 비트 목표를 구분한다. 출력 투영과 PIT는 세 정답 파형을 표현·평가할 수 있음을 검산했다. 현재 긴 평균 문맥은 호핑 순서를 없애지만 TCN 경계에 따른 위치 의존성은 남는다. [선행·수식 검토](../reports/2026-10-09/THREE_SOURCE_DESIGN_REVIEW_KO.md), [추가 해석](../reports/2026-10-10/THREE_SOURCE_RESEARCH_UPDATE_KO.md).

구조가 개선되면 성분별 독립 처리와의 제거 대조, 다른 원기록·조합의 확인, 같은 식별기로 혼합/복원/원신호를 비교하는 후속 순서로 진행한다. 파형이 보기 좋아진 것을 식별 향상으로 대신하지 않는다.

## 운영

GPU는 공유 잠금 아래 한 학습 worker만 사용한다. CPU 준비·읽기 전용 검산은 별도 제한 코어에서 병행한다. 실행 소스와 규약을 고정하고 완료 epoch의 수치·체크포인트·optimizer를 다시 검사한다. 로컬 진행 파일은 자동 갱신하지만 채팅 보고는 활성 대화에서 별도로 확인한다. 검토한 코드·보고서만 지정 저장소에 반영하고 원자료·체크포인트·인증정보는 공개하지 않는다.
