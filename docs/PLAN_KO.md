## 목표와 현재 범위

혼합 I/Q만으로 1–3개 원기록의 기여 파형을 복원하고, 새 기록·기종·조합에서 일반화되는지 검증한다. 복원 성능을 실시간성보다 우선하며 원 규모 모델과 seed 0의 첫 대조를 유지한다. 정답·기종·실제 합성 개수는 추론 입력으로 제공하지 않는다.

현재 목표는 공통 관측 RF 대역에 포함된 기록 기여 파형이다. 수신 잡음도 정답에 포함한다. 합성 기록 수는 물리 드론 대수 정답과 다르며 기체 송신 방향·실제 동시 수신 정답을 확보한 것으로 표시하지 않는다. 현재 NMF 없는 U-Net 결과를 Deep NMF 개선으로 부르지 않는다. detector 및 DR-NMF D2는 중단 지시를 유지한다.

## 완료한 비교와 결론

- 새 초기화 WaveNet 두 군과 U-Net의 각 5 epoch·375업데이트 비교에서 U-Net이 앞섰다. 모델 크기·계산량이 달라 계열 전체의 우열 또는 충분한 수렴의 증거는 아니다. [완료 비교](../reports/2026-10-09/ARCHITECTURE_FINAL.md).
- 전체 20.89 ms 복소 문맥 후보는 같은 예산 대조에서 채택 기준을 충족하지 못했다. 입력을 길게 주는 것만으로 유용한 시간 구조를 학습했다고 주장하지 않는다. [완료 결과](../reports/2026-10-09/PHASE_CONTEXT_FINAL.md).
- 기존/log1p 손실·학습률 5e-4/1e-4를 각각 총 3 epoch까지 확인했다. 낮은 학습률의 선택은 기존 e1·log1p e2이며, 시작 모델의 네 평균 파형 지표를 함께 넘지 못했다. e1은 모델·optimizer·RNG를 정확히 가져왔고 각 군에 150업데이트만 추가했다. [전체 결과와 같은 epoch의 학습률 대조](../reports/2026-10-09/LOW_LR_CONTINUATION_FINAL.md), [학습 곡선](../reports/2026-10-09/LOW_LR_CONTINUATION_EPOCHS.pdf).
- 출력 표현·기울기·국소 전력·합 일치·정답 이용 배율 보정·단독 파형의 선형 기종 구분도 검사했다. 실패 결과와 한계는 [직전 계획](PLAN_HISTORY_THROUGH_20261010_0029_KO.md)에 연결해 보존한다.

## 데이터와 평가 통제

- RFUAV 한 데이터셋의 같은 원 RF 대역끼리 합성한다. native 100MS/s와 수신 중심 간격을 보존한다. 중심 메타데이터를 실제 송신 반송파 정답으로 간주하지 않는다.
- 긴 구간에서 상대 전력·위상을 정한 뒤 자른다. 짧은 창마다 성분을 전력 1로 다시 정규화하지 않는다. 명목 전력차와 창별 실제 전력차를 구분한다.
- 원기록 묶음을 먼저 분할한다. 학습 8묶음·개발 5묶음이며, 630창을 독립 기록 630개로 세지 않는다. 검증 대역폭 변화와 기록 변화가 함께 있다.
- 현재 학습·검증은 Avata2/FPV/Mavic3 Pro의 5.8 GHz 및 Mini3/Mini4 Pro의 2.4 GHz다. 서로 다른 기종의 두 성분 4조합·세 성분 1조합이며, 조합 다양성의 제한을 공개한다.
- 같은 기종의 다른 기록을 이용한 9개 두 성분 구성·14개 세 성분 구성은 별도 후보다. 현재 로더를 바꾸거나 진행 중인 학습에 끼워 넣지 않는다.
- 조종기 단독·명시적 기체/조종기 결합 라벨은 제외한다. 폴더 이름만으로 기체 단독 송신을 보증하지 않는다. 영상 여부는 편입 기준이 아니며 송신원 근거를 확인한다.
- Autel 및 예약 확인 파일 6개는 미개봉이다. 개발 선택을 고정한 뒤 확인 평가를 진행한다. DroneDetect는 자체 데이터셋·native 표본률의 별도 후보이며 RFUAV와 풀링하지 않는다.

구조가 개선되면 성분별 독립 처리와의 제거 대조, 다른 원기록·조합의 확인, 같은 식별기로 혼합/복원/원신호를 비교하는 후속 순서로 진행한다. 파형이 보기 좋아진 것을 식별 향상으로 대신하지 않는다.

## 운영

GPU는 공유 잠금 아래 한 학습 worker만 사용한다. CPU 준비·읽기 전용 검산은 별도 제한 코어에서 병행한다. 실행 소스와 규약을 고정하고 완료 epoch의 수치·체크포인트·optimizer를 다시 검사한다. 로컬 진행 파일은 자동 갱신하지만 채팅 보고는 활성 대화에서 별도로 확인한다. 검토한 코드·보고서만 지정 저장소에 반영하고 원자료·체크포인트·인증정보는 공개하지 않는다.
