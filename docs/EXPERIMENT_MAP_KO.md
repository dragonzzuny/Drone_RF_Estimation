# U-Net100과 native 맞춤 추적기의 차이

2026-10-13. 실험 번호보다 학습 대상·평가 자료를 먼저 구분한다.

|실험|학습 대상|학습량|평가와 현재 판단|
|---|---|---|---|
|B U-Net100|복소 I/Q 파형 분리 U-Net|100epoch·7500업데이트|동일 녹음의 시간 분리 B630으로99 선택; 별도 녹음 C에서는 native e2보다 나쁨|
|기존 native e2|이전 가중치를 native RF 좌표에 맞춰 추가 학습한 U-Net|native 적응5epoch 중2 선택|C630에서 기존 최선 유지; 처음부터 총2epoch라는 뜻이 아님|
|B99 학습 추적기|출력 PSD·상대전력·시간 위치의 Transformer 임베딩|FIT48·50epoch·600업데이트|B99 출력의 전체20.8896ms 배정을 개선; native에 직접 이식하면 PSD보다 악화|

## U-Net 선택의 근거

같은 C630·같은 C8 추론의 두/세 성분 평균 NMSE:

|U-Net|두 성분|세 성분|
|---|---:|---:|
|B100 과정의 선택99|0.539202|0.884038|
|native 선택2|0.444601|0.688948|

NMSE는 낮을수록 좋다. 이는 서로 다른 학습 이력의 모델을 같은 개발 자료에서
비교한 결과다. '2epoch가100epoch보다 항상 좋다'는 학습량 비교가 아니다.
C는 원녹음과 VTSBW 조건이 함께 바뀐 반복 개발 평가다.

## 지금 바꾸는 부분

혼합 I/Q → 고정 native e2 U-Net+C8 → 복원 조각3개와 배경 →
학습 추적기가 같은 신호 조각끼리 연결 → 각 신호의 긴 I/Q 파형.

U-Net은 고정되어 파형 값 자체를 다시 학습하지 않는다. 추적기는 약0.639ms
조각33개의 배정 순서만 바꾸며 배경을 보존한다. 따라서 신호가 다른 출력으로
옮겨가는 오류에는 도움이 될 수 있지만 조각 안에서 이미 섞인 파형을 완벽하게
분해한다고 보장하지 않는다. 최종 모델 선택은 등록된 평가 결과 뒤에 판단한다.

48개 native 학습 출력 생성과 추적기50epoch 학습을 완료했다. epoch별 FIT48
수치는 학습 진단이며 미학습 검증이 아니다. native 부모는 B 시간 분할 이전
자료로 학습됐으므로 B를 독립 검증처럼 표시하지 않는다. 최종 C24는 별도 CPU의
실제 I/Q 점수·배정 순서 검산을 통과해야 완료로 보고한다.
