# 짧은 복원 경로와 긴 복소 문맥 경로의 결합: 후속 가설

**실행 갱신:** 2026-10-08 사용자 승인 후 구현·CPU/GPU 사전 검사를 완료하고 2군 본 학습을 시작했다. 같은 짧은 문맥 e5 부모, 33,734,467파라미터, 별도 복소 TCN과 두 위치의 특징 조절로 확정했다. [실행 기록](../reports/2026-10-08/LOCAL_GLOBAL_FUSION_LAUNCH_KO.md). 아래 본문은 실행 전 설계 기록이다.

2026-10-08. 사용자의 “전체 맥락과 국소 부위를 모두 익히게 하자”는 제안을 구체화한 **설계 단계** 문서다. 새 모델 구현·GPU 검사·본 학습을 완료한 기록이 아니다. 현재 `waveform_context_20261008_v1`의 5 epoch 대조와 봉인 소스는 변경하지 않는다.

## 질문과 근거

짧은 I/Q 창에서 진폭·위상을 복원하는 경로에, 더 긴 복소 I/Q의 시간 구조를 제공하면 원파형 오차와 분리 품질이 함께 개선되는가?

긴 문맥에는 송신 활동·반복·주파수 변화가 포함될 가능성이 있다. 그러나 그 정보를 입력한다는 사실만으로 네트워크가 실제 분리에 이용한다고 단정할 수 없다. NMSE 감소와 복소 SI-SDR 증가를 동시에 확인한다. 현재 긴 단일 경로의 개발 결과는 두 지표의 일관된 이점을 보여주지 못했다.

“전체”는 우선 10.48576ms의 관측 문맥이다. 모든 원기록이나 완전한 호핑 주기를 관측했다는 뜻이 아니다. 채점·복원 정답 구간은 기존 0.63872ms로 유지한다.

## 기존 시도와 구별

| 시도 | 국소 복원과 추가 정보 | 검증된 상태 |
|---|---|---|
| 이전 TCN 문맥 대조 | 짧은 복소 STFT U-Net + 약 21ms 전력 특징; 시간 순서 유지/평균 대조 | 긴 전력 문맥의 일관된 이점 미확인 |
| 확대 자료 게이트 대조 | 같은 짧은 복소 STFT U-Net 병목에서 시간 게이트 추가 | 선택 검증 NMSE의 이점 미확인 |
| 현재 원파형 문맥 대조 | 동일 원파형 U-Net에서 채점 창 밖 복소 표본 가림/유지 | 5 epoch 비교 진행; 완료 보고로 판정 |
| 후속 가설 | 같은 국소 복원 경로 + 별도의 긴 **복소 I/Q** 문맥 경로 | 계획, 미구현·미학습 |

따라서 두 경로를 연결하는 아이디어 자체를 새로운 발견으로 주장하지 않는다. 이전 게이트는 전력 특징에만 적용된 구조가 아니라 국소 복소 특징의 병목에도 적용됐다. 후속 차이는 복소 문맥의 보존과 국소 경로를 분리한 결합 방식이며, 실험으로 유효성을 확인해야 한다.

## 구조 후보

1. 국소 경로는 원 규모 U-Net과 복소 I/Q 복원 출력을 유지한다. 긴 입력을 추가하면서 국소 경로의 입력 정규화·채점 구간을 함께 바꾸지 않는다.
2. 문맥 경로는 같은 혼합에서 얻은 약 10.49ms 복소 I/Q를 입력한다. 16표본 채널 재배열처럼 표본·위상을 유지하는 전처리를 사용할 수 있다. 이후 학습 특징 압축을 무손실이라고 부르지는 않는다.
3. 시간 순서를 유지한 문맥 특징을 채점 구간의 시간 좌표에 맞춰 국소 경로에 결합한다. 긴 특징을 처음부터 시간 평균 하나로 축약하지 않는다. 결합 지점·채널 수·정규화는 학습 전에 확정한다.
4. 출력은 3개 순서 없는 기록 성분과 별도 배경이며 현재 PIT·합 일치·평가 규약을 유지한다. 관심 파형의 원기록 정답과 개수 라벨은 추론 입력에 넣지 않는다.

## 가장 먼저 할 대조

동일한 두 경로 구조에서 문맥 경로가 보는 정보를 바꾼다. 대조군은 채점 창 밖 복소 I/Q를 가리고, 실험군은 긴 문맥을 제공한다. **두 군의 국소 경로에는 같은 짧은 혼합을 제공**하고 초기 가중치·파라미터 수·학습 예산·손실·혼합 목록을 맞춘다. 문맥 경로를 통째로 제거한 모델과의 비교는 부차적이며 파라미터 차이를 명시한다.

현재 학습 완료 후 기존 검증 규칙에 따른 공통 부모 체크포인트 또는 새 초기화 중 하나를 정하고 양쪽에 동일하게 적용한다. 부모 선택과 구조의 정확한 명세는 후속 GPU 학습 전에 새 프로토콜에 봉인한다. 서로 다른 부모를 쓰거나 한 군만 추가 학습한 결과로 문맥의 효과를 주장하지 않는다.

학습 전에는 국소 경로 입력의 일치, 문맥 시간 좌표, 혼합 합 일치, 정답 입력 차단, 문맥 교란 시 출력 변화, 문맥 경로의 유한한 역전파를 확인한다. 출력 변화가 있다는 사실을 성능 개선으로 해석하지 않는다.

본 비교의 첫 예산 후보는 각 5 epoch/12,000혼합/1,500업데이트, seed 0이다. 처리량과 메모리 검사 뒤 실행 전에 확정한다. 모델 폭을 줄여 맞추지 않는다. 고정된 소수 학습 혼합 적합 검사는 구현 진단이며 개발 검증 성능을 대신하지 않는다.

## 판정과 범위

- 복원 주 지표: 배율·위상을 정답으로 보정하지 않은 성분별 복소 NMSE.
- 보완 지표: 평균 제거와 상수 복소 배율을 허용하는 복소 SI-SDR. 일정한 배율만 바꾸면 이 값은 변하지 않는다.
- 체크포인트 선택: 기존처럼 2·3성분 평균 NMSE. 1성분, 약신호, 개수 예측은 별도로 기록한다.
- 개선 채택: 2·3성분 각각에서 NMSE 감소와 복소 SI-SDR 증가. 전체 평균만 좋아지고 약신호가 나빠지는 경우도 그대로 보고한다.
- 국소 전력차별 결과, 원기록 조합별 결과, 배경·비활성 출력 에너지를 함께 본다. 전력이 작은 평가 예제를 사후 삭제하지 않는다.

RFUAV 단일 데이터셋·같은 원 RF 대역, 원기록 그룹 분할, 조종기 클래스 제외, Autel 보류를 유지한다. 기존 중심 정렬 합성을 유지하면 원 수신 중심주파수 간격을 보존했다고 말하지 않는다. 정답은 수신 잡음을 포함한 개별 기록의 기여분이고, 1–3은 실제 물리 드론 대수가 아닌 합성 기록 성분 수다.

(2026), *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*, [arXiv:2609.00065](https://doi.org/10.48550/arXiv.2609.00065). 지표 근거: [Le Roux 외, SDR – half-baked or well done?](https://arxiv.org/html/1811.02508v1). 우리 복소 확장은 원 논문의 실수 음성 지표와 구분한다.
