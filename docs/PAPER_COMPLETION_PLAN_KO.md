# 파형 복원 논문의 주장·추가 학습·검증 계획

2026-10-13. 사용자 요청: 논문 작성을 위한 후속 연구, WaveNet100epoch 비교와
추가 비교 구조1개 선정. WaveNet은 시작 통보 및 완료5epoch마다 채팅 보고한다.

## 논문의 중심

가제: **장구간 출력 추적을 이용한 단일 채널 드론 RF 합성 혼합의 복소 I/Q 복원**.

연구 질문은 짧은 구간에서 복원한 원신호를 긴 시간 동안 같은 출력으로 유지해,
장구간 파형 오차를 줄일 수 있는가이다. 복소 I/Q는 후속 신호 분석을 위한 출력이며,
파형 복원만으로 기종 식별 향상까지 입증했다고 쓰지 않는다.

현재 확보한 성과는 B99 고정 U-Net+C8의 파형에 학습 추적기를 결합했을 때,
같은 녹음 시간분리 B24에서 고정 PSD 연결 대비 두/세 성분 NMSE가
37.616%/50.551% 감소한 것이다. 정답으로 출력 파형을 생성하거나 배율을 맞춘
결과가 아니다. 모든 조건은 [자동 재집계 표](../reports/2026-10-13/PAPER_EVIDENCE_TABLE_KO.md)에
포함했다. C24 같은 B99 부모에서도 평균 개선이 있었지만, 다른 부모 native e2에서는
기존 PSD가 학습 추적기보다 좋았다. 부모와 평가 구성을 바꿔 하나의 우월성으로 합치지 않는다.

본문의 기여 후보는 다음 세 가지다.

1. 같은 RFUAV·원 RF 대역·원 중심주파수 간격을 유지한1~3성분 복소 파형 평가.
2. RF 출력의 PSD·상대전력·시간 정보를 이용한 장구간 출력 연결과 복원 오차 개선.
3. 실제 추적 성능,정답을 이용한 최적 블록 순열 진단,조건 변화 성능을 나눠 분석한 근거.

분리 후 학습 추적 자체는 [Liu·Pons,2021](https://arxiv.org/html/2102.04945v2)에 선행한다.
그 개념의 최초성이나 범용 드론 분리 성공을 기여로 내세우지 않는다. 독립 시험에서
재현되기 전까지 현재 수치는 개발 결과이며,이 계획은 제출 준비 완료 선언이 아니다.

## 추가 학습의 우선순위

|순서|모델/실험|예산과 역할|실제 상태|
|---:|---|---|---|
|1|WaveNet30층·128채널|새 초기화100epoch/7,500업데이트,기존U-Net100과 같은B 자료|사용자 실행 요청,별도 준비·등록·실행 경로 구성|
|2|IQUMamba-1D RFUAV 적응|같은B 분할·100epoch/7,500업데이트를 제안,세 번째 구조 비교|원문·공개 코드 검토,어댑터/학습 실행 전|
|후속 개선|DualContext U-Net 전층 공동학습|부모99에서 추가20epoch를 제안,국소복원과창간연결을 함께 학습|GPU full-input 1업데이트 사전검사PASS 후 가중치 폐기,본학습 미등록|

모델 비교 학습은 구조마다 새 초기화한다. 기존 U-Net100 결과는 그대로 재사용한다.
WaveNet50은 중간 비교이며 최종 목표를50으로 줄인다는 뜻이 아니다. 기존WaveNet5는
다른 개발 분할의 탐색이므로 이어 쓰지 않는다.100epoch가 모든 구조의 충분한 수렴이나
동일 연산량을 보장하지는 않는다. 자료·업데이트·학습률 규칙·선택 규칙을 맞추고
파라미터 수·실제시간·마지막 구간의 학습곡선을 보고한다.

IQUMamba-1D는 1D U-Net과 Mamba를 결합한 통신 신호 분리 모델이며2026-01-13
출판됐다. [원문](https://link.springer.com/article/10.1007/s44443-025-00440-5)과
[공개 코드](https://github.com/wzdsqaa/IQUMamba1D)를 확인했다. 드론 실험 결과를
대신하는 근거는 아니며,논문 자체도 세 성분과burst 조건의 성능 저하를 보고한다.
우리 적용에는 같은입력63,872복소표본,출력3복소성분+배경,정답없는forward,
동일PIT파형손실·개수경로·C8추론 검산이 필요하다. 코드의실수I/Q채널 처리를
수학적으로 보장된 복소위상 등변성으로 표현하지 않는다. 필요한CUDA 의존성과
원출력/어댑터 일치를 확인한 뒤 실행을 등록한다.

추가 공동학습의 경우, 기존 공통 순열 3epoch는 각 창의 입력 길이가 그대로였고
DualContext 3epoch는 부모를 고정하고 추가 모듈만 학습했다. 전층 공동학습은
32,142,859개 본체 파라미터와 4,411,648개 추가 파라미터를 동시에 갱신하는 후보다.
GPU 검사에서 실제 세 창 1.91616ms, 36,554,507개 파라미터, 약 2.48GB 할당으로
역전파와 갱신을 확인했다. 이 값은 성능 결과나 전체 학습 시간 추정치가 아니다.
[사전검사](../reports/2026-10-13/JOINT_CONTEXT_FEASIBILITY.json).

입력 길이 증가만으로 합성곱 수용범위가 늘었다고 주장하지 않는다. 현재 후보는
창 사이 bottleneck 경로로 복소 특징을 전달하며, 20.8896ms의 보조 정보는 전력 특징이다.
새 모듈·학습 범위·추가 예산이 함께 바뀌면 복합 개선 실험으로 보고한다. 같은 3epoch
초기 지점은 기존 대조를 재사용할 수 있지만, 추가 20epoch 최종점의 비교만으로
구조 변경의 효과를 학습량의 효과와 분리할 수는 없다.

## 비교 결과의 판단

주 비교는 동일 B630의 두/세 성분 평균 NMSE를 이용하되, 복소 SI-SDR·최약 NMSE·
단일 성분 성능·개수 정확도와 조건별 악화를 함께 제시한다. 긴 B24/C24는 별도 표다.
기존 C24의 native+PSD와 B99+learned를 같은 부모의 결과처럼 비교하지 않는다.
정답을 이용하는 순열·배율·개수 진단은 실제 추론 성과와 구분한다.

WaveNet의 기울기·메모리 검사, 동일 100개 합성 목록 검산, 매 epoch CPU 검산을
통과한 결과만 비교에 넣는다. 두/세 성분의 평균 오차·약신호 오차·파형 유사도를
함께 판단한다. 한 seed 설정을 유지하므로 학습 변동성은 추가 확인 대상으로 남긴다.

## 제출 전 보강해야 할 근거

같은 조건의 새 원녹음 평가 A는 현재 편입한 5기체의 13개 기체×VTSBW 조합마다
원녹음이 한 묶음뿐이어서 구성되지 않았다. 기존 조각을 다시 나누어 독립 녹음으로
만들 수는 없다.
[기록감사](../reports/2026-10-11/RECORDING_ADMISSION_KO.md).
B는 시간 분리, C는 녹음과 VTSBW 변화가 겹친 반복 개발 평가로 표시한다.

새 기종 확인용 Autel은 모델·표본 선정·합성 조건·후처리·비교군을 고정한 뒤의
별도 평가 후보로 유지한다. 이것도 같은 기종의 독립 녹음 평가 A를 대체하지는 않는다.
추가 자료의 적격성과 송신 방향은 메타데이터로 먼저 검토한다. 실제 동시 수신,
실제 드론 대수, 기종 식별 이득은 각각 그에 맞는 정답으로 검증해야 한다.

## 원고 및 그림의 구성

1. 서론: 혼합에서 원기록의 복소 파형을 복원하는 문제와 장구간 연결의 필요성.
2. 방법: 같은 RF 대역 합성, 복소 STFT U-Net/C8, 혼합 일치, 학습/PSD 출력 연결.
3. 실험: B/C 분할과 파형 지표, 동일 예산 구조 비교, 추적 요소 제거 비교.
4. 결과: 전체 사례 주표, 성분 수/전력 조건별 분포, 연결 전후 I/Q·STFT, 성공 및 악화 사례.
5. 논의: 정답 순열 진단과 실제 추론의 차이, 독립 녹음과 송신원 정답의 범위.

좋은 확대 그림은 정성 설명에 사용하되, 본문 수치는 전 사례 집계를 사용한다.
기존 native 맞춤 추적·직접 배정의 미개선 결과는 후속 분석/부록에 남긴다.

절차 검토에는 experimental-design/scientific-writing을 사용했다. 절차 출처:
Kassis,T.,Agarwal,V.,He,Y.,Patel,D.,&Brueckner,A.M.(2026),
*Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*,
[arXiv:2609.00065](https://arxiv.org/abs/2609.00065).
성능이나 논문 채택 가능성의 근거로 사용하지 않는다. 과학적 주장과 서지는 저자의 최종 검토 대상이다.
