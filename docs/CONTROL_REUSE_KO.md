# 공통 대조 재사용

2026-10-10 사용자 지시에 따라 U-Net 대조는 한 학습 이력으로 관리한다. 후보마다 동일 대조를 새로 시작하지 않는다.

공통 대조는 `local/fresh_schedule_20261010_v1`의 실제e1과 이를 가져온 `local/septda_continuation_20261010_v1/control`이다. 원 부모·native RFUAV 분할·같은 대역 합성 일정·seed0·원 손실·학습률·검증 규약을 함께 식별한다. 완료한e1은75업데이트이며 처음부터 다시 학습하지 않았다.

현재 사용자 우선순위는 SepTDA 참고 후보 총50구간이다. 대조의 추가 학습은 보류한다. 대조e2 이후의 성능은 미측정이며 후보와 같은 학습량의 대조가 이미 있는 것처럼 표시하지 않는다.

후속 후보는 일치하는 구간의 저장된 대조 지표·검증630행·가중치 지문을 참조한다. 비교하려는 변경 요인 이외의 자료 분할·초기 부모·합성 일정·학습 예산·평가 정의가 다르면 차이를 명시한다. 이를 이유로 대조 학습을 자동 추가하지 않는다. 자료가 달라졌다면 기존 수치를 직접 비교 가능한 결과로 표시하지 않는다.

공통 대조의 추가 학습이 필요해지면 보존 LAST의 모델·optimizer·RNG에서 한 번 이어간다. 기존 구간 재실행 없이 하나의 기준 곡선을 확장한다. 이후 비교는 후보만 새로 학습하고 대조 결과를 재사용한다.
