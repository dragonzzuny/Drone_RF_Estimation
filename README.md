## 자료와 평가

RFUAV 한 데이터셋의 같은 원RF 대역만 합성하고100MS/s와 수신 중심 간격을 유지합니다. 학습8개·개발5개 원기록 묶음을 먼저 분할했으며630창을630개 독립 기록으로 세지 않습니다. 현재 두 성분은4개 기종 조합, 세 성분은1개 조합입니다. 명시적 조종기·결합 라벨은 제외하고, 기체명 폴더 안 송신 방향의 불확실성은 공개합니다. 합성 성분 수를 물리 드론 대수로 간주하지 않습니다.

Autel과 예약 확인용6파일은 미개봉입니다. 실제 기종·합성 개수·정답 파형은 추론 입력에 주지 않습니다. NMSE는 상대 오차 에너지이며 정확도 백분율이 아닙니다.
