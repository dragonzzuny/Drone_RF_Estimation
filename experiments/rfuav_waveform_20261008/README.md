# 복소 문맥 0.64ms 대 10.49ms: 같은 원파형 U-Net

2026-10-08 사용자가 더 긴 신호 관측을 요청하여, 본 학습 전에 우선순위를 **관측 길이 대조**로 변경했다. 처음 준비하던 STFT 대 원파형 구조 비교는 실행하지 않았다. 이 폴더의 실제 학습 두 군은 `short_context`, `long_context`다.

| 조건 | 공통 사항 / 차이 |
|---|---|
| 모델 | 두 군 모두 동일한 32,355,203파라미터 원파형 U-Net, 전체 초기 가중치 동일 |
| 폭 | 64/128/256/512/1024, 기존 규모 유지 |
| 복소 입력 | 짧은 군: 채점 창 밖 I/Q를 0으로 가림. 긴 군: 1,048,576표본 전체 사용 |
| 관측 시간 | 100MS/s에서 복소 0.63872ms 대 10.48576ms |
| 공통 보조 입력 | 기존 20.97152ms 혼합 전력 특징의 시간 평균; 두 군 모두 동일 |
| 출력·채점 | 같은 63,872표본의 세 기록 성분+배경, 기존 정답과 바이트 일치 |
| 자료 | RFUAV, 같은 원 RF 대역 안의 중심 정렬 합성, 기존 학습·검증 기록 묶음 분리 |
| 예산 | seed 0, 처음부터 각 5 epoch, 12,000혼합, batch 8, 1,500업데이트 |
| 최적화 | 같은 AdamW, cosine LR 1e-4→1e-5, weight decay 1e-4, gradient clip 1 |
| 선택 | 기존 개발 검증 630혼합, 2/3성분 평균 NMSE 최솟값, epoch 0 포함 |

`pack_iq`는 16개 연속 복소 표본을 32개 실수 I/Q 채널로 재배열한다. 표본을 버리는 1/16 다운샘플링이나 위상 평균이 아니다. 네 출력도 역재배열한 뒤 고정 채점 구간을 추출한다. 입력 표현에서 표본을 보존한다는 사실이 학습한 encoder/decoder의 완벽 복원을 보장하지는 않는다.

구조는 RF Challenge의 시간영역 처리·긴 초기 커널 아이디어를 참고한 새 다출력 적용이며 원 논문 재현이 아니다. 첫 kernel 101은 **packed step 단위**이고 원시 표본으로는 1,616표본 범위다. 9개 tap의 dilated 블록과 4단계 4배 pooling을 사용한다. 합성곱 경로의 최대 범위는 대략 6.85ms이며 정렬에 따라 달라진다. GroupNorm과 보조 전력 특징은 별도의 전역 통계 의존성을 만든다. 모든 10.49ms의 순서 관계가 반드시 학습됐다고 주장하지 않는다.

짧은 군은 긴 군과 같은 입력·출력 계산 모양과 파라미터 수를 갖는다. 바깥 표본 마스킹은 GroupNorm의 통계도 바꾸므로, 이를 정규화 효과와 무관한 순수 주기 정보의 인과 효과로 해석하지 않는다. 같은 모델이 더 긴 복소 관측을 활용해 개선하는지 묻는 대조다. 중앙 채점 구간이 원 문맥의 양 끝에 가까우면 좌우 문맥이 비대칭이며, 제외 없이 같은 사례를 두 군에 사용한다.

실행 경로는 `local/waveform_context_20261008_v1/`이다. 기존 `rfuav_dense_gated_20261008` 모듈을 가져오되 원 코드를 수정하지 않는다. `PROTOCOL.json`에 새 코드·의존 모듈·자료 해시가 있고 실행 디렉터리에 소스 사본을 보존한다. 기존 준비 명세의 e22 초기화·LR·batch 값은 이 실험에서 사용하지 않으며, 자료·혼합 목록·특징 캐시만 재사용한다.

실행 예시(기존 CUDA PyTorch 환경):

```bash
python experiments/rfuav_waveform_20261008/run_comparison.py --run local/waveform_context_20261008_v1
```

공유 GPU lock을 잡고 양쪽 GPU 사전 검사를 통과한 뒤 긴 군부터 시작하며 epoch마다 순서를 바꾼다. `PROGRESS.json`, 군별 `EPOCH_*.json`, `MATCHED_PROGRESS.json`, `COMPLETE.json`을 자동 저장한다. epoch별 모델·optimizer·난수 상태와 선택 가중치를 보관한다. 실행 도중 봉인된 코드를 수정하지 않는다.
