# 현재 실행 대상: 확대 자료의 기준 U-Net 대 게이트 U-Net

2026-10-08 사용자 지시로 **자료 확대만 먼저 비교하는 별도 단계를 제외**했다. 현재 GPU 비교는 아래 두 군이며, WaveNet·기존 대역 간 탐색 연장은 이 비교의 선행 조건이 아니다.

| 군 | 학습 자료 | 시작 가중치 | 추가 예산 |
|---|---|---|---|
| 기준 U-Net | RFUAV 확대 3,902문맥 | 같은 대역 최선 mean 모델, 선택 epoch 22 | 5 epoch / 375업데이트 |
| 게이트 U-Net | **동일한 3,902문맥·동일한 혼합 순서** | **동일한 공통 가중치** + 초기 출력이 0인 게이트 보정 | **5 epoch / 375업데이트** |

이것이 현재의 단일 비교다. 추가 자료 단계와 모델 단계를 각각 끝낸 뒤 시작하는 방식으로 진행하지 않는다. 기존 자료 249개에 대한 추가 학습군은 이번 비교에 없다.

## 실제 연결한 내용

- `dense_preparation/TRAIN.npy`: 5 epoch, 12,000혼합. 학습 목록에 확대 3,902문맥 전부가 실제 포함된다. 각 기종 내부에서 섞은 문맥 목록을 순회하고 소진하면 다시 섞는다. 새 독립 녹음을 확보했다는 뜻은 아니다.
- 원래 혼합 목록의 **1/2/3개수·기종 조합·명목 전력·위상·crop 순서를 유지**하고 각 학습 기종의 문맥 인덱스만 확대 자료로 교체했다. 두 군이 같은 새 혼합을 사용한다.
- `VALIDATION.npy`: 기존 검증 630혼합과 같은 원기록·배율·위상·crop. 새 manifest에 맞는 인덱스로만 변환했다. 기존 검증 문맥 특징도 비트 단위로 동일하게 복사·검산했다.
- 원기록 pack별 분할, 같은 RFUAV·같은 원 RF 대역, 100 MS/s, 조종기 전용 및 명시적 결합 클래스 제외, 보류 Autel 미사용을 유지한다.
- 현재 합성은 **기저대역 중심을 맞춘 같은 대역 중첩**이다. 실제 수신 중심주파수 간격을 보존한 합성이 아니다. 이 조건도 두 군에 같다.
- 두 군 모두 32.14M 기준 본체를 유지한다. 게이트 모델은 총 34.77M이다. 상세 복소 입력 63,872표본과 약 21ms 전력 문맥의 시간 평균을 사용한다. 관측 창 길이를 늘린 실험이라고 부르지 않는다.
- 같은 검증 선택 가중치에서 시작하고 optimizer는 양쪽 모두 재설정한다. **미세조정 학습률은 두 군 공통 1e-5**, AdamW weight decay 1e-4, batch 누적 32, microbatch 1, 파형 PIT 및 합성 개수 손실을 유지한다. 이 학습률이 최적이라고 검증된 것은 아니다.
- 1 epoch에서 두 군 결과를 보고하고, 최대 5 epoch에서 같은 예산으로 비교한다. 기존 50 epoch 모델과의 직접 대조는 전후 개선 참고이며, 구조 효과는 위 두 군 사이에서 판단한다.

## 검사 결과와 상태

`dense_preparation/INTEGRATION_CHECK.json`:

- 12,000개 학습 목록의 구성 조건 일치 및 3,902문맥 편입 확인.
- 검증 630개 원기록 대응과 특징 파일 일치 확인.
- 실제 **학습용** 3성분 혼합 63,872표본에서 초기 두 U-Net의 공통 가중치·출력 파형·개수 logits가 정확히 동일함을 확인.
- CPU 순전파 구현 검사이며 GPU 학습·개선 결과는 아니다. 검증 I/Q나 보류 기종 I/Q를 새로 열지 않았다.

문맥 특징은 `dense_preparation/feature_snapshot`의 고정 코드와 두 CPU worker로 5 epoch 전체 준비를 완료했다. `FEATURES_COMPLETE.json`과 각 특징 파일의 해시를 검산했다.

2026-10-08 13:48 이후 사용자 권한 변경으로 GPU 접근을 확인했다. 기존 큐는 두 군의 46 epoch 체크포인트를 보존하고 종료했다. 두 모델의 원 규모 1·2·3성분 GPU 순전파·역전파 검사가 `dense_gpu_run/<arm>/GPU_PREFLIGHT.json`에 PASS로 기록됐다. 지속 실행 감독 프로세스에 연결한 기준 U-Net은 실제 1 epoch 학습 업데이트를 진행 중이다. `BLOCKED_GPU.json`은 이전 격리 환경의 역사적 실패 기록이다. 현재 상태는 실제 PID와 `HOST_TRANSITION.json`, `PROGRESS.json`으로 확인한다.
