# 국소 원파형 복원과 긴 복소 문맥의 결합

2026-10-08 실행. 같은 국소 복원기를 유지하면서 **별도로 인코딩한 긴 I/Q 정보**가 복원에 기여하는지 비교한다. 원 규모 모델이며 두 군 모두 **33,734,467파라미터**다. 본 학습 상태·결과는 로컬 실행 기록 또는 시점이 명시된 보고서를 확인한다.

## 두 군과 공통 출발점

- `local_only`: 국소 경로와 추가 문맥 경로 모두 채점 창 밖 복소 표본을 가린다.
- `local_global`: 국소 경로는 동일하게 가리고, 추가 문맥 경로에는 전체 10.48576ms 복소 I/Q를 제공한다.
- 양쪽 국소 경로는 기존 `waveform_context_20261008_v1/short_context/BEST.pt`의 선택 e5를 **동일하게** 읽는다. 부모의 학습 이력은 1,500업데이트다. 추가 문맥 경로도 두 군의 초기 가중치가 정확히 같다.
- 기존 부모의 전체 32,355,203파라미터를 유지하고 1,379,264개를 추가했다. 너비 64/128/256/512/1024를 축소하지 않았다.
- 두 군 모두 기존 20.97152ms 전력 특징의 시간 평균을 보조 입력으로 받는다. 따라서 `local_only`가 모든 형태의 긴 구간 정보를 모르는 모델이라는 뜻은 아니다.

## 입력과 결합

원시 100MS/s 복소 입력은 1,048,576표본, 출력·감독은 그 안의 63,872표본(0.63872ms)이다. 긴 정답 파형을 추가 감독하지 않는다. 기존 로더가 긴 혼합의 해당 부분과 채점 혼합의 바이트 일치를 확인한다.

추가 경로는 16연속 복소 표본을 32실수 채널로 재배열하고, 4개의 학습 stride-4 convolution으로 256개의 순서 있는 토큰을 만든다. 재배열은 무손실이며, 이후 학습된 특징 압축은 무손실이 아니다. 128채널 TCN의 두 convolution씩 7개 블록(dilation 1/2/4/8/16/32/64)으로 문맥을 처리한다.

특징 조절은 국소 U-Net의 첫 64채널 특징과 마지막 1024채널 특징에 적용한다. 문맥으로부터 곱셈 이득과 덧셈 편향을 만들고, 실제 시간 좌표에 맞춰 채점 구간 중심에 해당하는 특징에만 적용한다. 이득은 `1 + 0.1 tanh(gamma)`, 편향은 `0.1 beta`다. 편향 전체가 유계라는 뜻은 아니다.

개수 헤드는 기존 시간 평균 전력 특징을 유지한다. 새 복소 문맥으로 개수 헤드를 별도 확장한 실험은 아니다. 정답 파형·기종·실제 성분 수는 추론 입력에 없다. 순서 없는 3개 기록 성분과 별도 배경 출력을 사용한다.

## 예산과 검사

각 5추가 epoch·12,000혼합·1,500업데이트, seed 0. effective batch 8, microbatch 4를 사용한다. 같은 기존 학습 혼합 목록을 반복하며 새 기종·원기록을 추가한 결과가 아니다. 각자 새 AdamW를 사용하고, 기존 경로 LR은 cosine 1e-5→1e-6, 새 경로는 10배인 1e-4→1e-5다. float32, TF32 off, gradient clip 1, weight decay 1e-4를 맞춘다.

학습 전 CPU 검사 3개를 통과했다: 표본 시간 좌표 정렬, 원 규모·양쪽 초기 가중치·부모 가중치 일치, optimizer 대상과 LR 예산. 실제 GPU에서 1/2/3성분·microbatch 4 순전파/역전파/AdamW를 검사하고 해당 업데이트는 폐기했다.

문맥을 끄면 부모 출력이 정확히 같았고, 대조군은 창 밖 위상 변화에 정확히 불변이었다. 긴 문맥군에는 출력 변화가 있었다. 이는 연결 검사이지 유용성 증거가 아니다. 새 인코더·두 특징 조절기의 역전파가 유한하고 0이 아님을 확인했다. 압축된 특징 조절기의 초기 gradient norm은 약 2.7e-7로 세밀한 특징 조절기(약 0.018)보다 작다. 두 결합 지점의 효과가 같거나 모두 유효하다고 미리 주장하지 않는다.

GPU preflight 최고 할당량은 대조군 2,952,672,256 bytes, 긴 문맥군 2,961,191,936 bytes였다. 원본·스냅샷·학습 목록·공통 부모 체크포인트의 SHA-256을 봉인하고 매 epoch 재개 시 확인한다.

## 판단과 범위

개발 검증 630혼합(1/2/3성분 각 210개)을 epoch 0 및 매 epoch 평가한다. 2·3성분 평균 NMSE가 가장 낮은 시점을 선택하고, **각 성분 개수에서 NMSE 감소와 복소 SI-SDR 증가**를 함께 요구한다. 아주 작은 참조 전력도 평가에서 삭제하지 않는다. 학습 NMSE의 수치 바닥값과 보고 NMSE의 양의 참조 전력 직접 나눗셈을 구분한다.

RFUAV 단일 데이터셋·같은 원 RF 대역·원기록 그룹 분할을 유지한다. 중심 정렬 합성으로 원 수신 중심주파수 차이는 보존하지 않는다. 조종기 클래스 제외, Autel 보류, VTSBW 분할 차이, 수신 잡음 포함 정답을 유지한다. 기종 폴더는 기체 단독 송신 증명이 아니며 성분 수는 물리 드론 수가 아니다. 문맥 가림이 추가 경로의 정규화 통계도 바꾸므로 순수 주기성의 인과 효과로 일반화하지 않는다.

특징별 affine conditioning은 [Perez 외, FiLM: Visual Reasoning with a General Conditioning Layer, AAAI 2018](https://arxiv.org/abs/1709.07871)을 참고한 응용이다. 해당 논문의 시각 추론 성과는 드론 I/Q에서의 효과를 입증하지 않는다. 기존 RF 원파형 경로의 배경은 [RF Challenge](https://arxiv.org/html/2409.08839v3)이며 저자 구조·결과의 재현이라고 부르지 않는다.

실험 설계 절차에는 기존 experimental-design 지침을 참고했다: Kassis 외(2026), [Scientific Agent Skills](https://doi.org/10.48550/arXiv.2609.00065). 절차 참고와 성능 증거는 구분한다.
