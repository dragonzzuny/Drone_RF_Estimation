# 개수 오류가 배정에 미치는 영향: 정답 개수 진단

B24/C24와 제약 군집 결과를 본 뒤 등록하는 사후 진단이다. 새로운 실용 방법의
검증이 아니다. 이미 노출된 C24의 모든 구간에서 기존 제약 군집을 그대로 쓰되,
모델의 예측 개수 대신 **실제 합성 성분 수**를 알려주었을 때의 변화를 측정한다.
정답 개수를 쓰므로 성능표의 실용 방법으로 채택하거나 일반화 성과로 보고하지 않는다.
정답 파형은 점수 계산에만 사용한다. 개수 자체의 진단용 누설은 명시한다.

추가 학습0회, 기존 저장된 부모99 출력 재사용, 같은 PSD/블록/20회 갱신/초기화.
24개 전체·신호 수별·개수 예측 성공/실패별 NMSE·복소SI-SDR·최약NMSE를 남긴다.
CPU 통계식은 작은24합성 테스트와 모든 기존 C24 실측 저장 지표 재현을 통과해야 한다.
기존GPU와 CPU의 수치 허용은 지표 rtol=1e-6,atol=1e-7, 활성 출력 대응 정확 일치다.
기준을 실패하면 실패 기록을 보존하고 지표를 발표하지 않는다. 허용을 결과 보고 늘리지 않는다.

이 비교는 같은 저장 출력을 사용하므로 개수 오차가 군집 후처리에 미치는 영향만
진단한다. 신경망을 정확한 개수로 다시 학습했을 때의 성능이나 분리 상한은 아니다.
부모 개수 예측 정확도는 원래 값 그대로 보고한다. 보류 자료는 열지 않는다.
