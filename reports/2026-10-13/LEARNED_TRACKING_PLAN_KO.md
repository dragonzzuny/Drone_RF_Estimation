# 출력 조각의 동일 신호 관계 학습: 고정50epoch 계획

작성:2026-10-13 06:00KST. 등록 여부는 별도 PROTOCOL.json과 STATE.json이 기준이다.
DualContext3epoch를 마친 뒤 결과를 확인하고 진행 여부를 결정한다.

## 가설과 모델

고정 PSD 유사도만으로 순서를 정할 때 남는 오류 일부는 같은 신호를 추적하는 특징을
지도학습하여 줄일 수 있다. 복소 파형 생성기를 크게 만드는 가설과 구분한다.
완전한 원신호 분리나 미학습 기종 일반화를 전제하지 않는다.

부모99 U-Net32.14M+C8 추론 가중치는 고정한다. 별도875,521파라미터 Transformer
임베딩(128차원·4층·4heads·FF512·dropout0)에33시간×3출력의 PSD512와 상대전력1을 준다.
같은 시각의 세 출력에 같은 시간 인코딩을 적용한다. 슬롯 번호나 기체 라벨을 주지 않는다.
추적 입력은 관측 출력만 사용하며 정답은 학습 affinity 손실에만 사용한다.
서로 같은 원성분에 대응한 조각은 내적1, 다른 원성분은0을 목표로 한다.
원성분별 에너지 가중치를 합이 같게 정규화한다. 국소 PIT 라벨의 불완전성이 한계다.

추론에서 임베딩을 기존 제약 구면 군집에 넣고, 각 블록의 출력3개를 일대일 순열로만
재배치한다. 배경과 파형값은 바꾸지 않는다. 군집 수는 부모가 예측한 값이다.
개수 오류·한 블록 안의 분리 오차를 해결하는 설계라고 주장하지 않는다.

## 자료와 예산

[학습 특징 준비](TRACKING_TEACHER_PLAN_KO.md)의 FIT48개를 사용한다.
동일 RFUAV·동일 원RF대역 합성·100MS/s·RC제외·Autel보류를 유지한다.
기존 학습 구간48문맥을50회 반복한다. seed0,배치4,매epoch12회·총600회 업데이트,
fresh AdamW lr2.5e−4,wd1e−4,clip1,FP32·TF32off·scheduler없음.
성능 조기종료·중간 C 선택은 하지 않는다. 최종50을 사전 고정한다.
GPU preflight는 FIT 세 신호 표본에16회 업데이트해 손실 감소를 확인하고 가중치를 폐기한다.
그 뒤 같은seed로 새로 시작한다. 기준 파형 모델의50epoch와 같은 학습량이 아니다.

## 평가와 채택 판단

B24 전체20.8896ms는 epoch0~50 학습 곡선, 이미 노출한 C24는 최종50에서만 평가한다.
둘 다 반복 사용한 개발 자료다. C의 별도 녹음과 VTSBW 조건 차이는 함께 존재한다.
새 독립 최종 시험이나 Autel 평가는 하지 않는다. 전체630 짧은 창 평가와 혼동하지 않는다.

비교 기준은 같은 부모 파형의 무후처리와 기존 PSD 제약 군집이다. 각1/2/3성분의
NMSE↓·복소SI-SDR↑·최약NMSE↓, 각 조건의 개선/악화, 개수 정확도를 모두 보고한다.
자동 채택은 하지 않는다. B와C 각각에서 두·세 성분 세 지표가 기존 제약 군집보다
모두 개선되고 단일 성분 세 지표가 악화하지 않아야 범용 대체 후보로 평가한다.
한쪽만 개선되면 조건 한정 성과로 기록하고 기존 CURRENT_BEST는 변경하지 않는다.
0.1% 같은 임의 허용폭이나 결과를 본 뒤의 임계값 조정은 사용하지 않는다.

각 epoch 저장 가중치·optimizer step·소스/자료 SHA·유한값을 검사하고 실제 수치를
채팅에 보고한다. 매우 짧은 epoch는 완료된 여러 행을 한 표로 보고하되 생략하지 않는다.
최종 학습 결과는 별도 CPU 경로에서 실제 I/Q를 순열 재배치하여48개 직접 점수를 검산한다.
입력 특징 재생성·최종 임베딩 CPU 재계산·군집 순열·배경 불변·혼합합도 확인한다.
수치 동일성 문제가 있으면 원인과 차이를 기록하며 통과한 결과처럼 표시하지 않는다.

근거는 [Deep Clustering,2016](https://www.merl.com/publications/docs/TR2016-003.pdf)와
[Causal Deep CASA,2020](https://doi.org/10.1109/TASLP.2020.3007779)의 학습된 추적 특징이다.
음성 분야 원리의 RF 출력 추적 적용이며 새로운 군집 이론 또는 최초 RF 방법이라고 하지 않는다.
