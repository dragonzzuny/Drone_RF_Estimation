# B에서 선택한99epoch의 별도 녹음 C 평가

등록일2026-10-13.100epoch의 기존B선정 결과인99를 고정하고,이미 공개·반복 사용한
C DEV630에 한 번 적용한다.목적은 동일10MHz 시간분할에서의 향상이 별도 녹음·
미학습20MHz 수집 조건에서도 이어지는지 확인하는 것이다.

- 추가 학습0회,체크포인트/위상 수/전처리/임계값 탐색0회.
- 같은 전체32,142,859파라미터,8위상 추론,같은 원래C의630합성 조건.
- B학습의5개10MHz 원녹음묶음과C검증의5개20MHz 묶음 및원파일SHA집합의
  비중복을 등록 때 검사한다.수신기·수집조건이 완전히 같다는 주장은 아니다.
- 기존C8최선의 저장된630개 정답 전력·배열 순서와 정확히 일치하는지 확인한다.
- 1/2/3신호 NMSE,복소SI-SDR,최약NMSE,개수 추정 성능을 모두 보고한다.
- C결과로 이번에 시험할Bepoch를 다시 고르지 않는다.기존C최선manifest도 자동 변경하지 않는다.
- 미개봉Autel/최종확인 자료를 사용하지 않는다.이미 노출된 개발 자료이므로 독립 최종시험이 아니다.

이전C최선과 학습량·학습범위가 다르므로 우월하더라도 구조 하나의 효과를
입증하는 대조로 해석하지 않는다.원녹음 분리와대역폭 변화가 함께 있는C평가이며
같은대역폭·독립녹음의A평가를 대신하지 않는다.

GPU는 현재공통/창별순열 비교가 완료된 뒤 사용한다.그사이 CPU 준비와학습을
중단하지 않으며,코드와등록계획은 실행중 수정하지 않는다.
