# 논문 비교용 WaveNet: 같은 B 분할의 총100epoch

2026-10-13. 사용자는 U-Net100과 비교할 WaveNet 학습 및 시작 통보·완료5epoch마다
보고를 요청했다. 신규 실행이며 과거 중지된 후보 큐를 재개하지 않는다.

## 비교 목적과 고정 설정

현재 STFT U-Net과 직접 I/Q WaveNet의 복원 성능을 같은 자료와 업데이트 예산에서
비교한다. 파라미터 수·연산량은 다르며 각 계열의 최적 성능을 보장하는 비교는 아니다.
RF Challenge의30층·128채널 구성을 참고한 프로젝트의 다중 출력 어댑터를 사용한다.
기존5epoch 탐색의 가중치는 새 B 검증 구간에 노출됐을 수 있어 재사용하지 않는다.

- 새 초기화 seed0, NativeWaveNet 4,601,867파라미터,30층·128채널,팽창률cycle10.
- 국소 입력63,872복소 표본(0.63872ms), 출력3개 복소 성분+배경. 입력은 혼합만 사용.
- 긴20.8896ms 관측의65×255전력 특징을 시간 평균해 기존과 같은 보조 경로에 제공.
  파형 합성곱 수용범위6,139표본은0.06139ms다. 모델 이름만으로 긴 호핑 문맥을
  확보했다거나20.8896ms 복소 파형 전체를 처리한다고 설명하지 않는다.
- RFUAV 한 데이터셋,같은 원RF대역,100MS/s,원 중심주파수 차이 유지.
- U-Net의B 학습1–100epoch 합성 목록을 파일·배열 해시로 전부 일치시킨다.
  매epoch2,400혼합(1/2/3성분 각각800개),75업데이트,총7,500업데이트.
- 실효batch32, GPU microbatch4·8회누적. 기존 U-Net microbatch1과의 차이를 기록하고
  full-input 단건/4건 순전파·전체 기울기 동등성 검사를 통과한 뒤 본학습한다.
  사전검사1업데이트는 폐기하고 새 초기화부터 시작한다.
- AdamW lr1e-4,weight_decay1e-4,gradient clip1,FP32·TF32off.
  ReduceLROnPlateau factor0.5,patience5,min_lr1e-6: U-Net과 같은 규칙이며
  검증 곡선이 다르면 실제 학습률 값과 변화 시점은 달라질 수 있다.
- 기존 PIT NMSE+coherence·비활성/배경 손실+0.1개수CE 유지.
- 매epoch 기존B630 전체와 정답 없는C8추론. 초기0 포함 두/세 평균NMSE 최소로
  체크포인트 선택. 마지막100과 선택 체크포인트를 함께 보고한다.
- 성능 조기 종료 없이100까지. 비유한 값·무결성·자원 오류는 복구점을 보존하고
  원인을 확인한다. 자동으로200epoch나 다른 모델을 시작하지 않는다.

## 공정성 및 보고

완료된 U-Net을 재학습하지 않는다. 같은50/100 예산에서 두/세 NMSE,복소SI-SDR,
최약NMSE와 개수 정확도,파라미터 수·총시간을 보고한다. 낮은 NMSE를 정확도 백분율로
바꾸지 않는다. 모델별 손실이나 자료를 임의로 바꾸지 않는다.

B는 같은 원녹음의 시간 분리이며 독립 녹음 검증이 아니다. C와Autel은 이100epoch
학습·선택에서 사용하지 않는다. 종료 후 별도 평가 절차를 고정한다.

매epoch 평가·CPU checkpoint/optimizer/RNG·집계 감사를 저장한다. 사용자 최신 요청에
따라 채팅 진행 보고는 완료5·10·15…100epoch마다 수행한다. 시작과 오류는 즉시 보고한다.
파일 갱신과 detached worker는 스스로 채팅 메시지를 발송하지 못한다.

GPU 공유잠금은 기존 neural_queue.lock을 사용한다. CPU 다음epoch 특징 생성은
12,13코어,학습은14,15코어로 병행한다. 체크포인트와 특징은 외장하드에 저장한다.
완료한epoch의 재생성 가능한 특징만 해시·삭제 사유를 남겨 정리한다.

## 선행 근거

[Lancho 외, RF Challenge, §III.B](https://arxiv.org/html/2409.08839v3)는 RF 복원에서
U-Net과WaveNet을 비교한다. 여기서는 우리1~3성분 출력·손실·RFUAV 자료로 적응한
구현이며 논문 수치 재현이나 드론 데이터에서의 선행 우월성을 의미하지 않는다.

실제 상태는 `local/wavenet_timeblock100_20261013_v1/STATE.json`과 프로세스로 확인한다.
