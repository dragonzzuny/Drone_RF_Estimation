# 군집 중심 갱신과 일대일 배정의 목적 일치

2026-10-13. B24 평가와 정답 기반 오차 진단을 본 뒤 설계한 후속 개발 실험이다.
현재 C24 평가의 개별/집계 성능은 아직 열람하지 않았다. 새 방법의 설정을 여기서
고정하고, 진행 중인 C24가 끝나면 저장된 B24/C24 출력 모두에 동일하게 적용한다.

관찰: 기존 v2는 각 특징을 독립적으로 가장 가까운 중심에 배정하여 중심을 갱신한다.
최종 출력은 블록마다 서로 다른 슬롯을 중심에 일대일 대응시킨다. 두 단계의 제약이 다르다.
이것이 실제 오류의 주원인인지는 아직 검증 전이다.

변경: 매 중심 갱신에서도 블록의 최대6순열을 비교하여 일대일 대응을 적용한다.
주파수 PSD 특징·전력 가중치·원출력별 초기 중심·63872표본 블록·최대20회 중심 갱신은
v2와 같다. 고정한 새로운 단일 후보 `constrained_slot_clusters`만 시험한다.
기종 사전·정답·명목 구성 개수는 사용하지 않는다. 실제 모델 예측 개수를 쓴다.

단위 길이 중심 c와 정규화 PSD v에 대해 목적은
`J = sum_b sum_j w[b, pi_b(j)] * dot(v[b, pi_b(j)], c[j])`다.
순열을 고정하면 전력 가중 특징 합의 방향으로 중심을 바꾸는 것이 J를 최대화한다.
중심을 고정하면6순열 중 최댓값을 고르는 것이 각 블록의 J를 최대화한다.
교대 갱신이 J를 낮추지 않는지 매번 확인한다. 이는 파형 NMSE의 단조 개선 보장이 아니다.
수치 검사36개와1/2/3성분 합성 파형 표본 보존 검사는 통과했다.

선행은 분명하다. [Deep CASA 원문](https://arxiv.org/pdf/1904.11148)은 국소 분리와
시간 방향 출처 추적을 나누며 제약 군집을 다룬다. 열람한 arXiv v1은2화자 실험이며
3화자 이상 확장은 결론에 제안돼 있다. 최신 저널본의 추가 수치를 이 v1에서 확인했다고
부르지 않는다. [COP-Kmeans](https://wkiri.com/research/papers/wagstaff-kmeans-01.pdf)도
제약 군집의 선행이다. 여기서는 학습 임베딩 대신 RF PSD와 복소 출력 보존을 쓰는
적용을 검증하며, 제약 군집 자체의 신규성을 주장하지 않는다.

B와C를 분리해 기존 부모·v2·새 후보의 신호 수별 NMSE/SI-SDR/최약 NMSE,
단일 신호 유지, 각 조건의 악화를 모두 남긴다. 각 자료에서 v2 대비2/3신호 주 지표
공동 개선과 단일 신호 유지 여부를 각각 판정한다. 결과가 나쁘면 대리 목적 J가
개선됐다는 이유만으로 채택하지 않는다. 기존 B/C 모델 선정은 바꾸지 않는다.

0 optimizer updates. 새로운 U-Net 학습이 아니다. 보류 자료는 열지 않으며
기존에 노출된 개발 자료의 추가 설계라는 이력을 유지한다. B24의 기존 네 규칙은
변경하지 않는다. 이 추가 알고리즘은 별도 코드·계획·소스 스냅샷으로 보존한다.
