# native e2 맞춤 추적기: 실행 전 고정 계획

2026-10-13 사용자 지시로 계획을 실제 실행한다. 오전 8시는 작업 종료 조건이 아니다.

## 질문과 고정 비교

B99 출력으로 학습한 추적기를 native e2에 옮기면 C24의 두/세 성분 NMSE가
고정 PSD의 0.426044/0.674980에서 0.458999/0.753204로 악화했다.
이것만으로 원인을 확정할 수는 없다. 같은 추적기 구조·초기화·학습 예산을
유지하고 FIT48 출력의 생성기를 native e2로 바꿔 학습한다.

- 파형 모델: SELECTED_005.pt 안의 native epoch2, SHA256
  `19888f8823fbb6ade6333d40bd849dec3202e522ded016e7265eaced6b52aa49`.
  32,142,859파라미터 U-Net을 동결한다. C8/Hann 전체20.8896ms 추론.
- 자료: 기존 teacher와 동일 FIT48 문맥/전력/위상/순서. 24층화별2개,
  단일10·두성분24·세성분14. 같은 RF 대역, 원100MS/s·주파수 간격 유지.
- 추적기: 기존 위치 정보 포함 Transformer 875,521파라미터 그대로.
  seed0, FP32/TF32off, AdamW 2.5e−4/weight decay1e−4, batch4,
  gradient clip1, 매 epoch12업데이트, 50epoch/600업데이트. scheduler·조기종료 없음.
  기존과 같은 epoch별 혼합 순서를 사용한다. 사전16업데이트는 버린다.
- 실제 추론: 모델 출력의 PSD·전력·시간 위치만 인코더에 넣고, 예측한
  성분 수로 기존 제약 군집화를 수행한다. 정답·기종명·참 성분 수는 넣지 않는다.
  출력33블록의 순서만 바꾼다. 진폭·위상·배경 파형을 맞추지 않는다.
- 정답은 FIT 학습 라벨 및 평가 지표에만 사용한다.

## 평가와 해석

native 원모델은 B 시간 분할 이전 녹음으로 학습한 계열이다. 따라서 B24를
미학습 검증으로 부르지 않는다. 매 epoch의 FIT48 복원 수치는 **학습 진단**이며
추적기 선택에 사용하지 않는다. 고정 final50에서 기존 native C24를 평가한다.
C24는 이미 반복 사용한 별도 녹음·VTSBW20 개발 자료이며 독립 최종시험이 아니다.

이미 저장된 native C24 원출력과 PSD 결과를 재사용한다. U-Net 재학습 및
대조 추적기 재학습은 하지 않는다. 기존 B99→native 전이 결과도 함께 비교한다.
최종 C24 라우팅은 별도 CPU 경로에서 실제 복소 I/Q를 재배열하고 평가하여
캐시 기반 지표·출력 순서·입력/소스 해시·배경 보존을 확인한다.

두/세 성분 평균 NMSE 감소, 복소 SI-SDR 증가, 최약 성분 NMSE 감소를 함께
확인한다. 단일 성분과 조건별 악화도 모두 남긴다. 일부 평균만 좋아진다면
조건부 이득으로 보고한다. C630의 기존 CURRENT_BEST는 이 작은 비교로 교체하지 않는다.
Autel 보류 자료는 열지 않는다.

## 실행 순서

GPU에서 FIT48 teacher 추론을 하는 동안 CPU에서 native C24 특징 캐시를 만든다.
둘이 검산을 통과하면 GPU 추적기50epoch를 실행하고 CPU 최종 파형 감사를 잇는다.
각 단계의 상태·완료 epoch를 채팅에 보고한다. 오류 시 실패 기록을 보존하고
자동으로 기준이나 예산을 바꾸지 않는다. 결과를 보고 후속 가설을 판단한다.
