# 100epoch 이후 native 후속 실험 완료 보고

2026-10-13 09:04KST. 아래 실행·평가·CPU 검산은 모두 완료했다. 현재 이 묶음의 GPU 학습은 없다.
논문화·범용 분리 목표 달성을 선언한 것은 아니다.

## 100epoch와 지금 실험의 관계

100epoch는 I/Q 파형 분리 U-Net을7500업데이트 학습한 B 실험이며,같은 녹음의 시간분할
검증으로99를 선택했다. 같은 별도 녹음 C630에서는 그99의 두/세 NMSE .539202/.884038보다
기존 native e2의 .444601/.688948이 좋았다. native e2는 이전 가중치에서 native RF 조건에
추가 적응한 단계2이며,처음부터 총2epoch만 학습한 모델이라는 뜻은 아니다.

이번에는 native e2의 파형 값을 고정하고,출력이 시간에 따라 바뀌는 배정 오류를 줄이는
별도 추적기를 학습했다. 기존100epoch 결과와 체크포인트를 보존했다.

## 실제 실행과 결과

- 같은 FIT48에서 native e2+C8 전체20.8896ms 출력 생성·검산 완료.
- native 맞춤 affinity 추적기50epoch/600업데이트 및 C24 직접CPU24 감사 완료.
- 정답 개수 진단,고정 PSD/학습 특징0.5결합,관측 목적값에 따른4시작 군집 검사 완료.
- 관찰에 따라 파형 오차를 학습하는 직접 배정 추적기도 동일 FIT48·50epoch/600업데이트로
  실행하고C24 직접CPU24 감사를 완료했다.100개의 후속 실제 epoch를 모두 채팅에 보고했다.
- 각 모델은 사전 고정final50에서 C를 평가했다. 좋은 중간epoch로 바꾸지 않았다.

## 얻은 근거와 다음 판단의 기준

학습 loss 감소나 관측 군집 목적값 증가만으로 I/Q 복원 개선을 판단하면 안 된다.
여러 시작의 관측 목적값은 모든 조건에서 유지/증가했지만 실제 파형은 악화했다.
정답 개수까지 알려 줘도 native affinity의 세 성분 NMSE .758257가 남아 개수만의 문제는 아니다.
정답 기반 최적 블록 순열에서도 .266095/.483946가 남았다. 이는 현재 고정 조각에서의
배정 변경 한계이며 모든 분리 모델이나 깨끗한 신호의 잡음 한계는 아니다.

후속 모델 변경은 고정 PSD보다 나은 파형 성능을 실제로 보여야 한다. 같은 특징의 군집화나
손실 가중치를 더 탐색했다는 사실을 성과로 삼지 않는다. 블록 내부 복원과 녹음/VTSBW 조건
변화의 영향을 배정 문제와 구분해야 하며,앞의 원인들은 확정된 하나의 설명이 아니다.

C24는 반복 개발 자료이고 독립 최종시험이 아니다. 짧은 C630 CURRENT_BEST는 유지한다.
Autel은 열지 않았다. 조종기 라벨 제외·한 데이터셋/같은 RF 대역·원100MS/s와 주파수 간격을 유지했다.
