# 연속 구간의 출력 배정 학습: 대조 실험

질문: 기존 파형 손실의 정규화·가중치와 모델을 유지하면서, 연속 세 창에 하나의
출력 대응을 적용하면 파형 복원과 긴 구간 출력 배정이 함께 개선되는가?

근거는 기존 e79 개발 사례의 **창 내부** FPV 출력 이동이다. C8/창간 병합 전에도
발생하므로 병합만의 문제라고 보기 어렵다. 한 사례에서 관찰했으며 원인 확정은 아니다.

## 비교와 변인 통제

- 두 군 모두 동일 B100epoch 완료 뒤 기존 고정 DEV630 macro NMSE 규칙으로 선택한
  체크포인트에서 시작한다. 선택 epoch·파일 SHA는 실제 시작 전 INITIALIZATION.json에 고정한다.
- 모델은 원래 전체 32,142,859 파라미터 U-Net, 기존 평균 문맥 인코더와 개수 head를 유지한다.
- 같은 RFUAV B 학습 구간, 같은 RF대역, 원래 중심 주파수 차이, 전체 문맥 전력 조절,
  seed0 무작위 위상을 사용한다. 보류 기종/별도 확인 자료는 사용하지 않는다.
- 1묶음은 같은 혼합의 연속된 63,872표본 창 3개, 총 1.91616ms이다.
  각 추가 epoch에 768묶음(1/2/3성분 각256), 2,304개 창을 쓴다.
  매 업데이트8묶음=24창, epoch당96업데이트, **각 군3epoch/288업데이트**다.
- 두 군 모두 fresh AdamW, lr=1e-5, weight_decay=1e-4, clip_norm=1,
  FP32/TF32 off, 동일 순서, 동일 예산. 원래100epoch optimizer의 연속 연장이 아니라
  같은 시작점에서 수행하는 두 미세조정 실험이다.
- **independent:** 창마다 기존 PIT 손실을 최소화하는 순열을 선택한다.
- **shared:** 세 창의 평균 기존 손실을 최소화하는 하나의 순열을 선택한다.
  성분 NMSE·coherence·비활성 출력·배경 벌점·0.1개수CE는 그대로다.
  긴 파형을 합쳐 전력 정규화하는 변경도 하지 않는다. 달라지는 것은 허용 순열이다.
- 두 군 모두 무기울기 순열 선택 후 같은 파형을 재계산해 역전파한다.
  dropout/상태 갱신 층이 없는지 검사하고, 재계산 출력의 일치를 실행 중 확인한다.
  기존 손실과의 값/기울기 일치, 인위적 순서 전환의 벌점, 재계산 기울기를 CPU에서 검산했다.
- 실행 순서는 shared1→independent1→shared2→independent2→shared3→independent3.
  대조군을 매번 새로 시작하지 않고 optimizer와 난수를 복구한다.

## 평가와 판단

1. 매epoch 기존630개 짧은 B DEV를 C8로 평가한다. 원래 부모 결과를 별도로 보존한다.
2. count×기종 조합×전력차 각각에서 고정 일정의 첫 사례를 선택한24개 개발 묶음에서
   1.916ms를 평가한다. 5개 겹친 창에 기존 예측 기반 대응·Hann 병합을 적용한 결과가
   실제 추론 평가다. 비중첩3창의 순서 미보정 연결과 창별 최적 순열은 진단으로 구분한다.
3. 먼저 등록된 FPV/Mavic3Pro2ms 사례는 복원·패킷 보존·누출을 별도로 측정한다.
   이미 반복 확인한 개발 사례이며 일반화 또는 검출 향상 증거로 대체하지 않는다.

주 비교는 **각 군 추가3epoch의 동일 예산 결과**다. 중간epoch는 학습 경향 보고에 사용한다.
새 방법 채택에는 두·세 성분의 NMSE 및 최약NMSE가 부모보다 낮고 복소SI-SDR이 높으며,
같은 예산 대조군 대비 두·세 성분 macro NMSE 및 긴 구간 병합 macro NMSE가 낮아야 한다.
일부만 개선하면 절충 결과로 보고하고 기존 선택 모델을 자동 교체하지 않는다.
긴 구간24개는 소규모 반복 개발 진단이며 독립 녹음 검증이 아니다.

3epoch는 미세조정 비교 예산이며 처음부터 학습한 모델의 수렴을 판정하는 실험이 아니다.
성능 변동만으로 첫epoch에서 조기 중지하지 않는다. 비유한 값·자료/소스 무결성·
GPU/메모리/디스크 오류이면 복구점과 원인을 보존한다. 오전8시가 되면 완료 구간을 보고하고
진행 중 단계는 정확히 구분한다. 최선200epoch 연장이나 과거 중지 큐 재개는 자동으로 하지 않는다.

이 실험은 출력 대응의 시간 범위를 늘리지만 모델의 파형 수용 범위를 늘리지는 않는다.
추가 문맥 구조가 필요한지는 결과를 본 뒤 별도 실험으로 다룬다.
[uPIT 원문](https://arxiv.org/abs/1703.06284)은 시간 전체의 공통 순열을 사용하는 방법 근거다.
현재0.64ms 안에도 기존 PIT가 있으므로 ‘PIT 최초 도입’이나 새 원천 알고리즘으로 주장하지 않는다.
