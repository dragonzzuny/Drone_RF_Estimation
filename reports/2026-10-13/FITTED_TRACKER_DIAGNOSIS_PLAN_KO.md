# 추적기의 학습 표본 성능과 실제 파형 목적 진단

2026-10-13,50epoch 학습 시작 전 계획. 현행 학습 코드·평가·선택 기준은 변경하지 않는다.
최종50과 B/C 직접 파형 CPU 검산이 끝난 뒤 학습에 사용한 FIT48개만 평가한다.

질문: 같은 신호 특징의 affinity 손실 감소가 학습 표본의 파형 배정 개선과 연결되는가?
초기seed0 임베딩, 고정 최종50 임베딩, 기존PSD 제약 배정을 같은 저장 부모 출력에서 비교한다.
초기모델은 재학습하지 않는다. 모든 배정은 기존 예측 개수를 사용하고 입력은 관측 특징뿐이다.
학습 라벨은 초기/최종 affinity 손실 계산에만 사용하며 추론 입력에 넣지 않는다.

1/2/3성분별 NMSE·복소SI-SDR·최약NMSE,전체48개 affinity 손실을 기록한다.
FIT·B·C 사이 성능 차이와 대리 목적/실제 복원 지표의 차이를 구별하는 진단이다.
과적합,라벨의 모호함,개수 오류의 단일 인과효과를 이 결과만으로 확정하지 않는다.
최종50은 바꾸지 않으며 결과를 보고 새 체크포인트를 고르지 않는다.
독립 녹음 결과로 발표하지 않는다. 추가 학습0회,보류 자료 사용없음.

CPU2코어·낮은 우선순위·1300MB에서 실행하고 기존 B/C 직접 I/Q 검산에 우선순위를 준다.
