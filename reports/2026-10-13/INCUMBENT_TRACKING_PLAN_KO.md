# 기존 C 최선 U-Net에 고정 추적기 이식 평가

2026-10-13, 학습 추적기 최종50와 B/C48 직접 I/Q 감사 결과를 확인한 뒤 등록.

학습 추적기는 B99 파형에서 B24 두/세 NMSE .143027/.242095,
C24 .517603/.710601을 기록했다. C의 파형 모델 자체가 기존 native e2보다
짧은630 평가에서 약했던 점을 근거로, 기존 native e2에 추적기를 그대로 이식한다.
이는 다른 가중치 사이의 학습 방법 우월성 비교가 아니라 고정 후처리의 전이 검사다.

- 기존 native SELECTED_005.pt 내부 선택 epoch2, SHA19888f8823fbb6ade6333d40bd849dec3202e522ded016e7265eaced6b52aa49.
- 추적기 ACTUAL_050.pt 고정; 가중치 수정/재학습/중간epoch 선택 없음.
- 이미 공개·반복 평가한 C24 전체를 사용한다. 기존 최초 층별24개 인덱스,
  5단일/12두성분/7세성분,20.8896ms,100MS/s,같은 RF대역·원래 RF 간격 유지.
- 원래 C8 단기평가의1/2/3성분 각1개 점수를 먼저 재현한다. 실패하면 중지한다.

- 같은 출력 파형에서 parent,기존 PSD 제약 군집,학습한 최종50 추적기를 비교한다.
  개수는 해당 파형 모델 예측값이며,정답/기체명은 추적 입력에 넣지 않는다.
- 각 출력 표본은 순열만 적용한다. 배경은 그대로 둔다. 복소 gain/phase 정답 보정 없음.
