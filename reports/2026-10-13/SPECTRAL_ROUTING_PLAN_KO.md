# 전체 구간 출력 정체성 유지: 학습 없는 두 방법의 고정 비교

2026-10-13 부모99의 전체20.8896ms 다섯 고정 조합 결과를 확인한 뒤 세운 개발 실험이다.
세 신호 사례는 전체 대응의 NMSE 평균 약0.893과 국소 정답 대응의 약0.155가 크게 달랐다.
후자는 정답을 쓰는 진단이며 추론법 또는 원파형 오차의 수학적 하한이 아니다.

새 U-Net을 바로 학습하기 전에 이미 복원한 파형의 출력 순서만 안정화할 수 있는지 확인한다.
이 계획은 결과를 본 개발 자료의 후속 실험이며 독립 최종 검증으로 표현하지 않는다.

## 고정한 방법

기존의 다섯 조합0/7/14/15/20, 동일 부모99 출력, 동일0.63872ms 비중첩 구간을 모두 쓴다.
마지막 짧은 구간도 버리지 않는다. 각 출력의512표본 sqrt-Hann 평균PSD를 L2 정규화한다.
평가의 정답·기체명·합성 개수는 아래 대응 추론에 입력하지 않는다.

1. **학습 PSD 사전 대응:** 이미 한 번 만든 FIT 전용 PSD 사전을 사용한다. 수신 대역의
   알려진 기종 사전이라는 제한이 있다. 각 구간에서 출력 전력×PSD 코사인 유사도의 합이
   가장 큰 일대일 대응을6개 순열 중 고른다. 2.4GHz의 두 사전 성분 이외 슬롯은 남겨 둔다.
2. **관측 내 스펙트럼 군집:** 해당 관측의 예측 출력만으로 전력 가중 구면k-means를 수행한다.
   k는 부모 모델이 예측한 개수다. 전력 최대점과 가중 최원점으로 결정적으로 초기화하며,
   최대20반복 또는 할당 불변에서 끝낸다. 얻은 중심에 첫 방법과 같은 순열 규칙을 적용한다.

두 방법 모두 기존 복소 표본 값을 다른 출력으로 옮길 뿐 새 값을 생성하거나 크기·위상을
맞추지 않는다. 배경 출력은 그대로 둔다. 다른 성분이 이미 섞인 파형을 이 단계에서 완전히
분리할 수 있다고 가정하지 않는다. 블록 경계의 불연속 가능성도 실제 전체 파형 점수에 포함한다.

## 평가와 결정

원 부모 출력 점수를 먼저 수치적으로 재현한 뒤 각 방법의 전체 파형 NMSE·복소SI-SDR·합 오차를
같은 함수로 계산한다.5개 조합을 모두 공개하며, 성공한 조합만 평균내지 않는다. 입력과 소스
해시를 확인한다. 원 파형은 보존하고 재구성 가능한 블록별 순열만 추가 저장한다.

기종 사전 방식의 개선은 알려진 사전 조건의 개선이다. 군집의 개선도 같은 관측을 전체로
보는 비실시간 조건이다. 새 기종·약신호 전체·독립 녹음·실제 동시 수신 성능으로 확대하지 않는다.
정답 대응 진단과의 차이를 함께 보고, 개선이 있으면 별도 조건 평가를 설계한다. 실패하면
시간 문맥을 직접 학습하는 준비된 U-Net 후보를 검토한다. 임계값·구간 길이·가중치 탐색은 하지 않는다.
