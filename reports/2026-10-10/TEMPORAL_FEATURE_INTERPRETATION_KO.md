# 측정한 시간 구조를 현재 모델이 보는 방식

2026-10-10. [일반 복소 상관](TRAIN_COMPLEX_LAGS_KO.md)과 [위상 무작위 대조](TRAIN_CYCLIC_STRUCTURE_KO.md)를 현재 코드의 시간 축에 대응시켰다. 구현 변경·추가 학습 결과가 아닌 설계 검토다.

## 입력 길이와 시간 표현을 구분한다

| 경로 | 현재 값 | 해석 |
|---|---|---|
| 국소 I/Q | 63,872표본, 638.72μs | 측정한 33–143μs 지연이 들어갈 길이 |
| 국소 복소 STFT | FFT 512, hop 128 | 분석 창 5.12μs, 간격 1.28μs |
| 긴 전력 특징 | 1024표본 FFT, 8프레임 묶음 | 특징 간격 81.92μs, 표본화 주파수 약 12.207kHz |
| 현재 긴 문맥 처리 | 시간 평균을 반복해서 TCN에 제공 | 원래 시간 순서를 그대로 전달하지 않음 |

긴 전력 특징을 시간 시퀀스로 쓰더라도 81.92μs 간격은 28kHz 변동을 원 주파수 그대로 나타낼 수 없다. 평균 모드는 추가로 시간 순서를 없앤다. 하지만 **국소 입력과 STFT에는 훨씬 촘촘한 시간·위상 정보가 남아 있다.** 모델 전체가 이런 변화를 전혀 볼 수 없다는 결론은 틀리다. TCN의 경계 위치 영향도 남으므로 내부 모든 위치가 같은 표현이라는 주장 역시 하지 않는다.

28kHz는 일부 단독 기록의 지연 곱에서 관찰한 피크이며 통신 규약·심볼률·호핑률 정답이 아니다. 한 구간의 변화가 지속적인 주기인지, 여러 원기록에서 재현되는지, 혼합에서도 성분을 구분하는지는 아직 남은 검사다.

## 후속 후보를 구체화한다

입력 혼합에서 \(x[t]x^*[t-\tau]\)의 국소 평균을 만들면, 일정한 전체 위상 회전은 곱에서 상쇄된다. 지연 곱의 실수·허수·크기를 추가 특징으로 쓰는 방향을 검토할 수 있다. 그러나 혼합의 지연 곱에는 서로 다른 신호 사이의 교차항도 포함한다.

\[
x[t]x^*[t-\tau]=\sum_i s_i[t]s_i^*[t-\tau]
+\sum_{i\ne j}s_i[t]s_j^*[t-\tau].
\]

독립·영평균이라는 조건에서 교차항의 기대값이 0이라는 것과 유한 구간의 교차항이 실제로 0이라는 것은 다르다. 따라서 이를 정답 성분별 분해나 잡음 없는 특징으로 취급하지 않는다. 창 앞의 지연 표본이 부족하면 유효 범위를 명시해야 하며, 0 패딩을 실제 관측으로 표시해서도 안 된다.

실험한다면 기존 전체 본체와 같은 혼합·손실·예산을 유지하고 **혼합에서 계산한 지연 특징만 추가**하는 대조가 필요하다. 추가 채널을 0 가중치로 시작해 기존 예측을 보존하고, 같은 수의 단순 전력 특징을 넣은 대조로 지연 관계 자체의 효과를 구분할 수 있다. 현재 이 후보는 구현·대기열 등록하지 않았다. 우선 진행 중인 성분 특징 규모 대조를 마친다.

[기존 긴 복소 문맥 실패 결과](../2026-10-09/PHASE_CONTEXT_FINAL.md)와 [FFT 해상도 진단](../2026-10-09/STFT_RESOLUTION_TRAIN.md)을 유지한다. 관측 시간 확대나 긴 FFT만으로 개선을 보장하지 않는다.
