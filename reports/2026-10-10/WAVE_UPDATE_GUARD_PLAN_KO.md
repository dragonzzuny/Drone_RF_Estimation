# 파형 복원 목표를 보호하는 실제 업데이트 보정

PCGrad와 CAGrad의 완료 결과를 보기 전에 다음 조건부 후속을 정한다. 두 방법이 모두 부모 대비 공동 개선 기준에 실패한 경우만 실행한다. 어느 하나가 통과하면 이 후속은 실행하지 않고 해당 개선을 추가 검증한다. 기준이나 보류 자료를 바꾸지 않는다.

고정 TRAIN6의 파형/분류 손실 분해에서 단일 성분의 파형 gradient는 두·세 성분과 반대 방향이었다. 현재 배치의 실제 AdamW 변위는 투영된 기울기와 달라질 수도 있었다. 이에 따라 개수별 전체 gradient를 조정하는 앞선 두 후보와 달리, **실제 업데이트에서 두·세 성분의 파형 목표만 보호**하는 방법을 비교한다.

원 손실 전체의 배치 평균 기울기를 그대로 clip한 뒤 원 AdamW로 이동 제안 delta를 계산한다. 따로 구한 `0.1 count CE` gradient를 빼서 두·세 성분 파형 손실의 기울기 h2,h3를 얻는다. 파형 손실에는 원 PIT NMSE·coherence·비활성 출력·background가 모두 포함된다. 이때 가장 작은 제곱 수정량으로 `h2^T delta_new <= 0`, `h3^T delta_new <= 0`을 만족하게 한다. 단일 성분과 개수 분류를 직접 보호하지 않는 선택이며 그 지표 악화도 함께 보고한다.

이는 [GEM 원 논문의 식 (7)–(8)](https://papers.nips.cc/paper_files/paper/2017/file/f87522788a2be2d171666752f97ddebb-Paper.pdf)에 있는 선형 제약/최소 수정 아이디어를 현재 배치의 파형 목표와 **AdamW 이후 실제 변위**에 적용한 후보다. 원 GEM의 과거 과제 메모리 실험을 재현한 것이 아니고 새로운 최적화 이론을 주장하지 않는다. 두 제약의 활성 집합 네 가지를 열거해 2×2 문제를 풀며, 독립적인 원문제 수치해와 비교 검증했다. 0 이동은 항상 이론상 가능하지만 수치 이상은 조용히 넘기지 않고 중단한다.

원 AdamW의 누적 모멘트는 그대로 저장한다. 제안 변위와 실제 적용 변위는 분리 기록한다. FP32 재적용 이후 제약도 다시 검사한다. 보호는 현재 배치 손실의 **일차 근사**에 대한 것이며 비선형 유한 이동에서의 손실 감소나 새 기록 성능을 보장하지 않는다. 이를 보장한다고 보고하지 않는다.

원 규모 U-Net 32,142,859파라미터, 같은 native RFUAV 부모 e2, 전체 가중치 학습, TRAIN epoch1 2,400예제, 75업데이트, microbatch1/batch32, seed0, 새 AdamW1e-5·weight decay1e-4·clip1, FP32/TF32 off를 유지한다. 파형 forward 횟수는 같고 다중 성분 예제의 분류 경로에 추가 미분이 있다. 모델 구조와 추론 입력은 같다. 정답 개수는 학습 기울기를 모으는 용도다.

원 손실 대조·PCGrad·CAGrad·부모와 실제 e1을 비교한다. 선택은 두·세 NMSE 평균 최소로 e0도 포함한다. 두·세 NMSE 감소·복소 SI-SDR 증가·약신호 NMSE 비증가를 부모와 같은 75업데이트 원 손실 대조 모두에서 충족해야 진전한다. 반복 DEV630, 한 seed, 다섯 검증 기록 묶음, 한 세 기종 조합의 한계를 유지하며 Autel/예약 확인 파일은 읽지 않는다.
