# 성분 상호작용 출력층: 본 비교 준비안

2026-10-10. **00:29 KST 본 비교를 등록하고 GPU 실행을 시작했다.** 낮은 학습률 비교는 두 군 모두 총 3 epoch와 최종 검산을 완료했으며 기존 최선 모델을 넘지 못했다. GPU TRAIN4 사전 검사도 통과했고 별도의 수치 재검산을 마쳤다. 첫 군은 기존 U-Net 대조다.

가설은 원 규모 U-Net의 공유 특징과 세 예측 파형에서 성분별 특징을 만들고 서로 정보를 교환하면, 기존 U-Net을 같은 양만큼 더 학습한 대조보다 파형 복원이 좋아지는가이다. [구현과 사전 검사](SOURCE_INTERACTION_PLAN_KO.md).

| 통제 항목 | 준비한 설정 |
|---|---|
| 부모 | 보존 중인 native RF U-Net 선택 e2, 양쪽 동일 |
| 군 | 전체 기존 U-Net / 전체 U-Net + 성분 상호작용 출력층 |

| 손실 | 기존 PIT NMSE·coherence·비활성/배경 및 0.1 개수 CE |

| 추론 | 동일한 단일 추론. 정답 개수·기종·원파형·사후 배율 보정 없음 |

첫 epoch는 기존→후보, 두 번째는 후보→기존, 세 번째는 기존→후보 순서다. 두 군 모두 새 optimizer를 시작하며, 첫 학습 이후에는 optimizer와 RNG를 그대로 이어간다. 사전 검사에서 만든 가중치는 사용하지 않는다.

CPU에서 전체 부모 파라미터의 동일 로드, 모든 본체 파라미터의 학습 가능 상태, 비영 보정 가중치의 저장·복원 경로를 검사했다. [검사 결과](SOURCE_INTERACTION_TRAINING_CHECK.json). 완료 후 별도 읽기 전용 검사기가 실제 epoch·선택 가중치·225 optimizer 업데이트·동일 검증 630개를 다시 검사하도록 대기 중이다.

추가층은 37,888파라미터이며 계산량 차이는 남는다. 새 구조 전체의 초기 비교이지 attention만의 독립적 인과 효과를 분리한 대조는 아니다. 개선되면 같은 규모의 성분별 독립 처리와 비교하는 후속 제거 실험이 필요하다.

이 출력층은 동일한 세 입력 특징을 서로 다른 것으로 만드는 기종 query를 갖지 않는다. 세 원시 예측 쌍이 완전히 같으면 공유 함수와 성분 순열 대칭성 때문에 세 보정도 같아져, 합 0 투영 후 추가 보정이 0이 된다. 본체의 기존 독립 출력 가중치는 유지하므로 전체 네트워크가 반드시 같은 출력을 내는 구조는 아니다. 현재 후보는 기존 성분 예측을 개선하는 변경이며 전체 SepTDA의 성분 유도 구조를 대체하지 않는다.

현재 반복 개발검증·한 seed·다섯 검증 기록 묶음·한 세 성분 기종 조합의 범위를 유지한다. 미학습 기종과 예약 확인 기록은 열지 않는다. 본 비교 결과를 얻기 전 개선이나 논문 기여를 확정하지 않는다.
