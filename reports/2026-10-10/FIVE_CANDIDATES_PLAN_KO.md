# 후보5개를 순차적으로 총50구간씩 학습하는 실행 규약

2026-10-10 사용자 최신 지시: “저5개 순차적으로50epoch씩 해보자. 계속 보고 진행해.” 앞선 Sep 우선 규약의 나머지4후보 미예약 방침을 대체한다. 실행 중인 Sep의 동결 소스·자료·optimizer·규약은 수정하지 않는다. 공통 대조 추가 학습은 보류하고 기존 결과를 재사용한다.

## 순서와 재개

|순서|후보|전체/학습 파라미터|총50구간의 시작점|기존 학습률|
|---:|---|---:|---|---|
|1|U-Net + SepTDA 참고 분리 경로|54,596,107 / 전부|진행 중인 연속 학습을 그대로 이어감|본체1e−5, 추가경로1e−4|
|2|본체 고정 시간·주파수 보강|37,406,475 / 5,263,616|완료e1의 실제LAST·optimizer·RNG → e2–e50|보강층1e−4|
|3|시간 순서 게이트|32,142,924 / 전부|완료e1의 실제LAST·optimizer·RNG → e2–e50|본체1e−5, 게이트1e−2·weight decay0|
|4|특징 규모 보정 성분 상호작용|32,180,747 / 전부|공통 부모에서 새 출력층을 초기화하여 e1–e50|본체1e−5, 새 출력층1e−3|
|5|파형 업데이트 보호|32,142,859 / 전부|완료e1의 실제LAST·optimizer·RNG → e2–e50|1e−5, 기존AdamW 변위 투영 유지|

4번의 TRAIN4 반복 진단은 전체 자료 epoch로 계산하지 않는다. 해당 가중치는 과거 정리됐으며 재사용하지 않는다. 나머지 후보의 선택BEST를 실제LAST 대신 이어 쓰지 않는다. 모델 크기와 기존 갱신 방법을 유지한다. 2번은 전체 구조를 보존하면서 본체를 고정하는 후보 자체의 설정이다.

## 자료와 학습량

RFUAV TRAIN8/DEV5 원기록 분할, 같은 원RF대역·native100MS/s·실제 중심주파수 간격을 유지한다. 기존 기체명5종의4개 쌍/1개 세 조합이다. 조종기 단독·명시적 결합 라벨은 제외했으나 FPV 등 기록 내부 송신 방향의 불확실성은 남아 있다. 합성 원기록 수를 실제 물리 드론 대수라고 표시하지 않는다. 미개봉 Autel 및 확인용6파일은 열지 않는다.

로그의1epoch는2,400합성·75업데이트, 실효batch32/microbatch1이다. 5개 봉인 일정=12,000합성이고 총50구간은각일정10회·3,750업데이트·고정자료10순회다. 학습 완료50구간을 새로50개 추가한다는 뜻이 아니다. 새 녹음이나 매번 새 합성도 아니다.

기존 시작 일정을 보존한다. 1·3번은3→4→5→1→2,2·5번은1→2→3→4→5를 반복한다. 새4번은3→4→5→1→2를 사용한다. 총50의 자료 노출량은 같지만 학습 순서가 완전히 같지는 않다. 성능순위를 구조만의 인과 효과라고 주장하지 않는다. seed0·FP32·TF32off, 기존 손실과 학습률 그룹·gradient clip1을 유지한다. 20구간부터 평균NMSE2/3의 개선을 추적하고,1e−5 이상 개선이10구간 없으면 모든 그룹 학습률을 절반으로 낮춘다. 학습률 규칙은 Sep 연속 규약과 같다. 조기종료 없이50까지이며 비유한 값·무결성 실패·자원 부족은 오류로 기록하고 큐를 멈춘다.

## 기록·검산·해석

매구간630개DEV 전체를 평가한다. 1/2/3성분별 NMSE·절대복소SI-SDR·최약NMSE·합성개수 정확도와630행의 모든 성공/실패를 저장한다. 기존 규칙인2/3성분 평균NMSE 최소로BEST를 선택하되, 실제 마지막 결과와 구분하고 SI-SDR·최약신호 악화도 함께 보고한다. 각 구간 LAST에는 model·optimizer·RNG·학습률 상태를 저장하고 재개/저장 일치를 검산한다. 전체 지표는 매구간 남기고 별도 가중치는5/10/20/30/40/50에 보존한다.

한GPU를 공유잠금으로 순차 사용한다. Sep50완료 및 저장 검산 → 2번50 → 3번50 → 4번50 → 5번50 순서다. 새 작업자의 CPU 재개 검사4건이 모두 통과해야 큐를 시작한다. 새4번은 기존 원규모 CPU 구조 검사에 더해 공통부모 tensor·0초기화 출력층·학습그룹을 확인하고, 실제 시작 시630개 초기DEV가 부모와 재현되는지 확인한다. 기존 guard 알고리즘을 그대로 재사용하고 각 실제 업데이트의 제약 만족을 검산한다.

완료한 공통 대조는 재학습하지 않는다. 50구간 대조가 없는 동안에는 후보의 학습곡선과 기존부모 대비 변화로 보고하며, 같은50학습량 대조 대비 구조 우월성은 주장하지 않는다. 반복적으로 살펴본DEV 결과이며 독립확인/기종일반화 결과가 아니다.50도 수렴이나 논문화 성공의 보장이 아니다.
