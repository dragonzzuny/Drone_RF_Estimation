# SepTDA를 참고한 복소 RF 분리부: 실행 전 규약

사용자의 2026-10-10 지시에 따라 시간 순서 문맥 실험을 완료·검산한 다음 수행한다. 실행 중인 이전 소스는 변경하지 않는다.

## 검증할 가설

구간 내부·구간 사이 처리로 혼합 특징을 만들고, 학습 query가 추정한 신호별 특징을 FiLM으로 분리한 뒤 시간·신호 사이 관계를 반복 처리하면, 원규모 U-Net에 비해 두·세 기여 파형의 복원이 개선되는가? 특징이 보조 손실에서만 학습되는 이전 친화도 실험과 달리 실제 복원 출력으로 연결한다.

[SepTDA 원문 2절·3.2절](https://arxiv.org/html/2401.12473v1)의 주요 규모를 따라 인코더 특징 256, 분리 특징 128, 방향별 LSTM hidden 256, attention head 4, attractor 2층, triple-path 8블록, chunk 96·50% 중첩을 사용한다. 기존 32,142,859파라미터 U-Net 전체를 보존한 병렬 분리 경로이며 축소 본체를 사용하지 않는다. 정확한 추가 파라미터 수는 코드 집계와 CPU 검사에 남긴다.

## RF 적용과 원형의 차이

- 입력은 같은 양측 복소 STFT의 실수·허수 512+512채널이다. 주파수를 평균하지 않고 학습형 선형 변환으로 임베딩한다. 이 변환은 압축이며 무손실 변환을 주장하지 않는다. 기존 U-Net의 고해상도 경로도 유지한다.
- 시간축은 100 MS/s, STFT hop 128표본으로 프레임 간격 1.28μs다. chunk 96프레임의 간격 기준 길이는 122.88μs이고 전체 복소창은 638.72μs다. 이는 RF에서 진단한 수십~백여 μs 지연을 검토하는 설정이지 물리 주기 정답에 맞춘 최적 길이는 아니다. 기존 긴 평균 전력 문맥 20.8896ms도 유지한다.
- 세 학습 query는 기종명·정답 개수를 입력받지 않는다. 항상 세 신호와 배경을 출력한다. 비활성 슬롯은 기존 PIT 파형 손실로 감독한다. 원문의 C+1 종료 query와 존재 BCE, 개수에 따른 동적 출력은 이번 첫 비교에 이식하지 않는다. 개수 추정은 기존의 별도 1/2/3 head를 유지한다.
- 원문의 시간영역 transposed-convolution 대신 각 신호의 복소 STFT 보정과 iSTFT를 사용한다. 세 번째 신호에도 직접 학습하는 출력 경로가 있다. 배경도 독립 보정을 출력하고 네 보정의 평균을 빼서 혼합 합 일치를 유지한다.
- 마지막 readout은 0으로 시작해 부모의 출력과 정확히 같다. 첫 역전파는 readout을 학습하고 내부에는 0 기울기가 전달된다. 그 이후 내부 학습 경로가 열리는지 검사한다. 이것을 이미 분리 특징을 학습했다고 해석하지 않는다.
- 상대 위치 bias, LSTM·attention, FiLM, chunk overlap-add, 8단계 신호 간 처리를 포함한다. 원문과 정규화·입출력·배경·손실·사전학습 조건이 다르므로 원형 SepTDA의 충실한 재현 또는 새 이론이라고 부르지 않는다. 원문 다단계 SI-SDR 감독 대신 기존 NMSE/coherence PIT와 개수 CE를 유지한다.

## 첫 비교

RFUAV 한 데이터셋·같은 원 RF 대역·native 수신 중심 간격·TRAIN 8/DEV 5 원기록 묶음·같은 부모·seed 0을 유지한다. 새 혼합 schedule3의 2,400예제(개수별 800), 실효 batch32/micro1, 75업데이트의 첫 epoch를 비교한다. 완료한 FRESH_SCHEDULE_RESULT가 같은 자료 일정의 부모 추가학습 대조다. 동일 업데이트·자료 예산이며 모델 크기와 FLOP는 다르다.

새 AdamW의 부모 lr=1e-5, 분리 경로 lr=1e-4, wd=1e-4, 전체 gradient clip1, FP32·TF32 off. 활성값 재계산으로 메모리를 줄이며 폭·깊이·입력 길이는 줄이지 않는다. 부모와 새 분리부를 함께 학습한다. 다중 신호 지표가 둘 다 좋아져야 하며, 기존 부모·같은 일정 대조 모두에 대해 각 개수의 NMSE 감소·복소 SI-SDR 증가·최약 NMSE 비증가를 확인한다. 선택과 무관하게 실제 e1과 모든 실패 행을 보존한다.

처음 75업데이트는 추가 분리부의 초기 적응 비교다. 이 결과만으로 원형 모델 계열의 우열이나 수렴 완료를 판단하지 않는다. 이후 학습량은 학습 곡선·실제 내부 기울기·DEV 오차를 보고 결정한다. 별도 녹음에 대한 최종 검증과 확인 자료는 계속 보류한다.

## 실행 조건과 검산

CPU에서 전체 8블록·원규모 모델·실제 TRAIN 1/2/3 혼합으로 시작 출력 일치, 합 일치, chunk 병합·기울기, 활성 readout 뒤 내부 gradient를 확인한다. optimizer 업데이트는 0회다. 이전 GPU 실험의 완료와 감사 PASS 이후 GPU에서 원규모 역전파 메모리·유한값 검사를 통과해야 본학습한다. GPU 검사 가중치는 업데이트하지 않으며 초기 상태에서 새 optimizer로 출발한다. 실제 75업데이트와 전체630개 DEV 행·체크포인트·선택·optimizer·소스 지문을 종료 후 검산한다.

코드 검토에서 실제 학습의 중첩 checkpoint 경로를 사전 검사와 동일하게 맞추라는 지적을 반영했다. GPU에서 readout을 일시적으로 활성화한 뒤 직접·중첩 재계산의 출력과 전체 gradient를 비교하고 초기 0으로 복구한다. 내부 query gradient도 비영임을 확인하며 optimizer 업데이트는 0회다.
