# 공통 특징에 묻힌 성분 차이: 입력 규모를 맞추는 대조

2026-10-10 02:02 KST. [실제 후보 e2의 내부 측정](SOURCE_HEAD_MECHANISM_KO.md)을 근거로 추가한 후속 진단이다. 현재 본 비교와 별도 학습률 검사는 변경하지 않는다.

## 바꾸는 한 가지

시간·주파수 위치별 공유 특징을 \(f\in\mathbb R^{64}\), 세 성분의 원시 I/Q를 \(r\in\mathbb R^{3\times2}\)라 하자. 추가층에만 다음 입력을 제공한다.

\[
\tilde f=\sqrt{66/(2\cdot64)}\,f/\sqrt{\operatorname{mean}(f^2)+10^{-12}},\qquad
\tilde r=\sqrt{66/(2\cdot2)}\,r/\sqrt{\operatorname{mean}_{i,c}(r_{ic}^2)+10^{-12}}.
\]

두 묶음의 차원 수를 고려한 규모 조절이다. 모든 성분 I/Q에 같은 양의 배율을 적용하므로 상대 진폭·위상은 유지된다. 원래 출력 경로와 학습 정답은 그대로다. 성분별 독립 전력 정규화가 아니며 정답 전력·기종·개수를 사용하지 않는다. 전체 32,180,747개 파라미터와 0 readout 초기화를 유지한다. 성분 출력이 모두 같을 때 보정이 0이 되는 대칭성은 유지하므로 모든 분리 문제를 해결하는 설계가 아니다.

## 대기열에 등록한 진단

| 항목 | 고정 조건 |
|---|---|
| 두 군 | 기존 성분 상호작용층 / 입력 규모를 맞춘 같은 층 |
| 시작 | 같은 native U-Net 부모, 새 추가층 0 readout |
| 학습 자료 | 앞선 진단과 같은 TRAIN4, 행 4·5·2·11 |
| 예산 | 각 64업데이트, 실효 batch 4·microbatch 1 |
| 기존 파라미터 학습률 | 두 군 모두 1e-5 |
| 추가 파라미터 학습률 | 두 군 모두 1e-3 |
| 손실 | 기존 PIT NMSE+coherence+비활성/배경 항, 0.1 개수 CE |
| 관측 | 0·1·8·16·32·64단계 전체 파형 지표와 마지막 추가층 on/off 차이 |
| 비교 기준 | 마지막 64단계에서 2/3성분 NMSE 감소 및 복소 SI-SDR 증가를 함께 확인 |

추가층 1e-3은 앞선 학습률 진단 결과가 나오기 전에 두 군 공통으로 고정했다. 최적 학습률이라고 선택한 값이 아니다. 이 진단은 기존 학습률 검사 완료 후 같은 GPU 잠금으로 실행된다. 모든 가중치를 폐기하고 개발검증·보류 자료는 읽지 않는다. 성공해도 반복해서 본 네 학습 혼합의 적합도이므로 새 기록의 개선을 별도로 확인해야 한다.

[CPU 검사](BALANCED_SOURCE_HEAD_CPU_CHECK.json)는 같은 파라미터 수, 초기 원래 예측의 정확한 보존, 비영 readout의 6순열, 보정 합 0, 배경 보존, chunk 기울기 일치, 0·극소·큰 입력의 유한 기울기, 실제 63,872복소표본 전체 U-Net 역전파를 확인했다. 실제 RF 성능 결과가 아니다.
