# 두 창 지도학습 대조와 일관성 후보: 조건부 실행 계획

2026-10-10, 두 축 U-Net의 학습률/본체 고정 비교 결과가 나오기 전에 정했다. 두 축 후속의 두 군 중 하나라도 사전 공동 개선 기준을 충족하면 이 비교는 실행하지 않는다. 모두 미충족이고 최종 검산을 통과한 경우에만 공유 GPU 잠금 아래 다음 두 군을 순차 실행한다. 첫 군 결과에 따라 둘째 군을 생략하지 않는다.

| 항목 | paired_supervision | paired_consistency |
|---|---|---|
| 전체 모델·시작점 | 기존 native 부모 U-Net 32,142,859개 파라미터 전체 | 동일 |
| 자료·seed | 기존 TRAIN epoch1의2400혼합·seed0 | 동일 |
| 창 | 원래 창과 ±16,384표본 옆 창 | 동일 |
| 원 손실 | 두 창의 원 파형 PIT+0.1개수CE를 각각0.5 | 동일 |
| 추가 항 | 없음 | 두·세 성분에서만 공통 구간 일관성0.1 |
| 예산 | 2400쌍=4800창,75업데이트 | 동일 |
| 계산 | 쌍마다3forward/2backward | 동일 |
| optimizer | 새 AdamW1e-5,wd1e-4,clip1,실효32쌍,micro1쌍,FP32/TF32off | 동일 |

원래 긴 구간의 혼합 이득·위상·주파수 간격과 문맥 특징은 그대로다. 옆 창의 이동 방향은 행 index 짝수/홀수로 결정하고 경계를 넘는 경우만 반전한다. 두 창의 실제 공통 표본·정답은 비트 단위 동일해야 한다. 원래 스케줄을 파일에 수정하지 않으며 행의 시작은 읽은 뒤 즉시 복원한다. 한 쌍은 원래 기록의 두 시야일 뿐 독립 기록 두 개가 아니다.

학습 손실의 정답 대응은 각 창 전체의 PIT에서 얻고 공통 구간에 적용한다. 정답·기종·실제 개수는 모델 forward에 들어가지 않는다. 추가 항의 성분별 분모는 공통 구간 정답 전력과 기존 바닥값이며, 비활동·배경은 혼합 전력으로 정규화한다. 단일 성분은 두 창의 원래 지도 손실만 사용한다. 수식과 미분 분할은 [방법 검토](PAIRED_WINDOW_METHOD_KO.md)에 있다.

새로운 학습 전 원래 DEV630의 부모 출력을 재현한다. 실제e1,선택e0/e1,optimizer75단계,난수 상태를 보존한다. 개발 평가의 창은 기존과 동일하며 평균 추론을 추가하지 않는다. 첫 대조군은 부모 대비 두·세 NMSE 감소·복소SI-SDR 증가·최약NMSE 비증가로 판정한다. 추가 항 후보는 **부모와 같은 두 창 대조 모두**에 대해 같은 기준을 충족해야 한다. 기존 단일 창 e1은 참고 수치로만 남긴다. 같은75업데이트여도 두 창 군의 계산량·관측량이 더 많으므로 이를 공정한 연산량 대조라고 부르지 않는다.

복소 MSE 항등식과 공유 가중치 순차 미분 검사는 통과했다. 원 규모 모델의 고정 TRAIN 두 성분 한 사례 CPU 역전파도 통과했으며 파라미터 업데이트는 없었다. 반복 계산한 두 번째 예측은 비트 단위로 같았다. 두 검사는 실행 가능성 검증이고 성능 증거가 아니다.

두 군을 모두 완료한 뒤 모든630행·실제/선택 가중치·AdamW를 CPU에서 다시 검산한다. 한seed·반복DEV의 개발 비교다. RFUAV 한 데이터셋, 같은 원 RF 대역, 원기록 그룹 분할, 조종기 제외, Autel·확인6파일 미개봉을 유지한다. 이미 진행 중인 다른 학습의 코드·규약은 바꾸지 않는다.
