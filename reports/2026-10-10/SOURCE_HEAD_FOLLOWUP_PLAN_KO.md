# 추가층의 학습 속도와 대칭성: 후속 검사 규약

2026-10-10 01:33 KST. [e1 파형·학습 적합도 진단](SOURCE_INTERACTION_E1_DIAGNOSIS_KO.md)의 관찰을 바탕으로 작성했다. 현재 각 3 epoch 본 비교는 그대로 진행한다.

## 대기열에 등록한 학습률 검사

원 규모 U-Net과 같은 성분 상호작용 출력층을 두 군에 모두 사용한다. 구조·부모·입력·손실·원기록·자료 순서·seed·업데이트 수는 같다. **변경하는 것은 추가된 파라미터의 학습률 하나다.**

| 항목 | 동일 조건/변경 |
|---|---|
| 기존 파라미터 | 32,142,859개, 양쪽 모두 lr 1e-5 |
| 새 파라미터 | 37,888개, lr 1e-5 대 1e-3 |
| 학습 대상 | 두 군 모두 전체 32,180,747개 파라미터 |
| 초기화 | 같은 보존 부모, 새 readout 0, 초기 예측 동일성 확인 |
| 자료 | 이전 사전 검사와 같은 TRAIN4, 행 4·5·2·11 |
| 예산 | 각 32업데이트, 실효 batch 4·microbatch 1 |
| 최적화 | 새 AdamW, weight decay 1e-4, gradient clip 1, FP32, TF32 비활성 |
| 관측 시점 | 단계 0·1·8·16·32의 2/3성분 NMSE·복소 SI-SDR |
| 직접 효과 | 마지막 모델에서 추가층만 켜고 끈 출력 변화 에너지 |

학습률 100배 변화는 작은 새 층이 실질적으로 학습되는지 확인하는 진단이다. 최적 학습률을 찾았다고 주장하지 않는다. 두 군의 파라미터 그룹이 빠짐없이 겹치지 않도록 나뉘고, 원래 출력층은 기존 학습률을 유지하는 것을 [CPU 검사](HEAD_LR_PROBE_CPU_CHECK.json)에서 확인했다. 이 검사는 I/Q를 읽거나 학습하지 않았다.

현재 본 비교와 최종 검산이 성공해야 실행된다. 같은 GPU 잠금을 사용한다. 검사에서 얻은 가중치는 폐기하며 개발검증·확인 자료는 읽지 않는다. 결과가 좋아져도 고정 TRAIN4의 적합도일 뿐이고, 전체 자료의 같은 예산 대조가 필요하다. [실행 코드](../../experiments/source_interaction_20261010/head_learning_rate_probe.py).

## 수식에서 확인한 대칭성

각 시간·주파수 위치의 공유 특징을 \(f\), 세 원시 출력 쌍을 \(r_i\)라 하면 추가층의 첫 표현은 \(h_i=A f+B r_i+b\)다. 세 \(r_i\)가 모두 같으면 공유 LayerNorm·attention·MLP의 출력도 같고, 평균을 뺀 최종 보정은 0이다. 이때 공유 특징이 풍부하다는 사실만으로 새 층이 서로 다른 세 보정을 만들지는 못한다.

세 슬롯이 가까운 국소 상황 \(r_i=r_0+\epsilon d_i\)에서 정규화가 매끄럽다고 하자. LayerNorm은 실제 구현의 양의 epsilon을 포함한다. 그러면 query·key·value의 슬롯 간 차이는 \(O(\epsilon)\)다. 두 query 행의 logit 차이에서 softmax에 영향을 주지 않는 공통 항을 제거하면

\[
(q_i-q_\ell)^T(k_j-\bar k)=O(\epsilon^2)
\]

이다. 따라서 attention 가중치 행의 차이는 \(O(\epsilon^2)\)이고, 각 행의 합이 1이므로 value의 공통 항도 사라진다.

\[
\sum_j(a_{ij}-a_{\ell j})(v_j-\bar v)=O(\epsilon^3).
\]

**attention 결과의 슬롯 간 차이**가 작아질 수 있다는 국소 성질이다. 전체 추가층에는 residual·MLP 경로가 있으므로 최종 보정 전체가 3차라는 뜻은 아니다. 기존 본체의 독립 출력층까지 포함한 모델 전체가 분리 불가능하다는 주장도 아니다.

합성 float64 검사에서 슬롯 차이를 절반으로 줄였을 때 attention 차이의 감소 차수는 마지막 단계 3.00045, 전체 추가층은 1.00010이었다. 서로 같은 슬롯의 최대 보정은 약 2.78e−17이었다. 이 검사는 읽기 전용 수학 진단이며 실제 I/Q·학습된 가중치를 사용하지 않았다. 0 readout이면 모든 출력이 자명하게 0이므로, **이 검사에서만 합성 비영 readout**을 사용했다. [검산 수치](SOURCE_AXIS_SENSITIVITY.json), [코드](../../experiments/source_interaction_20261010/check_source_axis_sensitivity.py).

실제 드론 자료에서 세 원시 슬롯이 이 국소 상황에 얼마나 자주 있는지는 아직 측정하지 않았다. 따라서 이를 e1 실패 원인으로 확정하지 않는다. 새 층 학습률을 올려도 효과가 작다면, 원시 출력의 차이에만 의존하지 않는 성분별 표현을 후속 후보로 검토할 근거다. 학습 query·서로 다른 성분 decoder를 넣는 경우에는 출력 순열과 파라미터 수가 달라지므로 별도 대조가 필요하다.
