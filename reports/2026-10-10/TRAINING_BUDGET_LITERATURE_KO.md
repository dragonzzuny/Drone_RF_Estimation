# 선행 원문의 학습량과 현재 실험의 해석

확인: 2026-10-10. 총 학습 상한, 실제 수렴 관찰, 학습률 감소의 대기 기간을 구분했다.

| 선행 | 원문에서 확인한 학습 기간 | 배치·학습률·판단 조건 | 근거 위치 |
|---|---|---|---|
| SepFormer | 최대 200 epoch | batch 1, Adam 1.5e-4. 일반 학습은 65 epoch 이후 3회 연속 검증 개선 부재 시 학습률 절반; 동적 혼합은 100 epoch 이후 5회 기준 | [§3.2](https://arxiv.org/html/2010.13154) |
| MossFormer2 | 최대 200 epoch | batch 1, Adam 1.5e-4. 초기 85 epoch 동안 학습률 유지 후 감소 | [§3.2](https://arxiv.org/html/2312.11825v2) |
| SepNetEDCI | 60 epoch | Adam 3e-4, 2 epoch마다 0.96배; 8 kHz·4초 입력 | [원문 3쪽](https://www.isca-archive.org/interspeech_2025/yang25_interspeech.pdf) |
| SepTDA | **총 epoch 미기재** | batch 2, AdamW 4e-4, 검증 손실이 5회 연속 개선되지 않으면 학습률 절반. 처음부터 학습 | [§3.1–3.2](https://arxiv.org/html/2401.12473v1#S3) |
| IQUMamba-1D | 학습 곡선에서 약 130 epoch 수렴 보고; Huber 비교에서는 131±6 보고 | batch 32, Adam 1e-3. 본문은 4 epoch 정체 시 감소 규칙을 설명. 최대 epoch와 실제 수렴을 동일하게 표시하지 않음 | [§5.3, §6](https://link.springer.com/article/10.1007/s44443-025-00440-5) |
| RF Challenge U-Net/WaveNet | 고정 총 epoch를 본문에서 확인하지 못함 | 검증 MSE의 실질적 감소가 멈추면 조기 종료한다고 설명 | [§III.B](https://arxiv.org/html/2409.08839v3) |

SepTDA의 **5 epoch는 학습 종료 횟수가 아니다.** 검증 정체에 대한 학습률 조정 대기 기간이다. 원문 PDF와 저자 데모 페이지에서도 총 학습 기간을 확인하지 못했으므로 60 또는 200 epoch로 추정해 채우지 않는다. IQUMamba의 출판사 표 3 별도 페이지는 이번 도구로 열리지 않았으며, 본문에서 확인한 설정만 기록했다.

## 우리 실험과의 차이

현재 한 학습 구간(기존 로그의 epoch)은 2,400혼합, 실효 batch32, optimizer 75회다. 따라서 5구간은 375회, 50구간은 3,750회다. SepTDA의 개별 WSJ0-mix 학습 집합은 20,000혼합이고 batch2다. 이를 한 번씩 처리한다고 가정하면 단일 집합 한 순회는 약10,000업데이트라는 **산술 추정**이다. 복수 집합의 sampling 정책과 실효 배치 구현까지 확인한 실제 실행 횟수는 아니다.

따라서 epoch 숫자를 같게 맞춰도 자료량·갱신 횟수·계산량이 같지 않다. 음성 초와 RF 초는 표본률·신호 구조가 다르므로 그대로 대응시키지 않는다. 기존 부모의 사전학습 이력과 새 22,453,248파라미터 경로의 무작위 초기화도 구분해야 한다.

첫 SepTDA 참고 RF 구간의 75업데이트는 초기 적응 결과다. 실제 DEV NMSE2/3는0.479020/0.690769이며, 현재 최선 가중치의 대체 기준을 만족하지 않았다. 이것으로 구조 계열이 효과 없거나 충분히 수렴했다고 결론내리지 않는다. 고정 TRAIN48에서 경로를 끈 경우와 켠 경우의 세 성분 NMSE도0.569037/0.569087로 비슷했다. 이 진단은 초기 경로 기여가 작음을 보여줄 뿐, 충분히 학습한 뒤의 한계는 보여주지 않는다.

## 계획 변경

1. 모델 구조를 유지하고 실제 e1의 가중치·optimizer·RNG를 이어간다. 선택 e0로 되돌려 재시작하지 않는다.
2. 같은 U-Net 대조와 같은 혼합 일정·업데이트 수에서 곡선을 비교한다. 각 구간의 NMSE·복소 SI-SDR·최약 NMSE·개수 지표와 훈련 손실을 모두 남긴다.
3. 5구간은 중간 점검이다. 더 긴 자원 예산과 학습률 조정 규약을 사전에 기록하고, 수렴 여부는 곡선으로 판단한다. 자원 상한에 도달한 것을 수렴 완료로 부르지 않는다.
4. 새 구조 추가와 소수 혼합 반복학습 후보는 우선순위를 내린다. 마지막 후보는 구현·실행하지 않았으며 이번에는 장기 학습량을 먼저 검증한다.
