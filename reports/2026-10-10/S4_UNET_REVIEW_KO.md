# S4-UNET 본문 검토와 적용 판단

2026-10-10. Gao 등, *S4-UNET: A Long-Sequence Modeling Blind Source Separation Method for Single-Channel Co-Channel Overlapped Communication Signals*, Journal of Electronics & Information Technology 48(6), 2384–2395 (2026). [출판사 원문](https://jeit.ac.cn/cn/article/doi/10.11999/JEIT251144), [서지](https://doi.org/10.11999/JEIT251144).

출판사 공개 HTML 본문을 내려받아 2–5절과 표 1–8을 확인했다. PDF 미리보기 요청은 실패했지만 웹페이지의 정상 본문 열기 경로로 원문을 확보했다. 본문 검토본은 로컬에만 보존한다.

## 확인한 근거

- **두 신호 분리** 연구다. 세 신호·미지 개수 처리는 결론의 후속 과제다.
- I/Q 두 실수 채널을 처리하는 1D U-Net에 TSEM 잔차 블록과 S4를 결합한다. 인코더 여러 해상도에서 시간 관계를 처리한다.
- RML과 PSK/APSK 합성·실측 조건을 사용한다. 표본 길이는 조건별 128/1024/4100/8200이며, 표본 수를 RFUAV의 관측 시간으로 그대로 해석하면 안 된다.
- 4.2절의 최적화 설정은 Adam, batch 50, 초기 학습률 0.001, 음의 SI-SDR이다. 학습률 감소·종료 문장은 기준값 설명이 불명확해 정확한 재현 규약으로 채택하지 않는다.
- **4.3.2절은 절대 크기를 강제하지 않으며 부호 반전도 가능하다고 설명한다.** 파형 모양 지표 향상을 절대 복소 I/Q 오차 해결로 바꾸어 해석하지 않는다.
- 표 8의 SI-SDR은 S4 없음 17.14, 홀수 단계+GLU 17.98, 짝수 단계+GLU 18.34, 홀수 단계+ReLU 19.22 dB다. 논문의 권장 구성이 모든 지표에서 최고인 것은 아니다. 드론 분리 수치가 아니며 원래 실험 조건에 한정한다.

## 우리 연구에서의 판단

가져올 후보는 **여러 해상도의 시간 특징 처리**다. 현재 성분 상호작용 출력층의 결과와 분리해 평가해야 한다. 원파형의 절대 크기·위상이 목표이므로 기존 raw NMSE를 유지하고, 논문의 SI-SDR만을 성공 기준으로 삼지 않는다. 사용자가 속도보다 성능을 우선했으므로 연산량 절약을 이유로 GLU 구성을 미리 최선으로 정하지 않는다.

현재 모델의 긴 전력 특징은 시간 평균을 거쳐 호핑 순서를 잃는다. 다만 긴 복소 입력을 받았던 이전 후보도 실패했다. 따라서 단순한 입력 확대와 유용한 시간 구조의 학습을 구분해야 한다. 이번 본문은 설계 후보의 근거이며 **S4-UNET을 이미 구현·학습했다는 보고가 아니다.**

## 추가 탐색 기록

NES²Net(ICAACE 2024, [DOI](https://doi.org/10.1109/ICAACE61206.2024.10549012))은 [학회 논문집 목차](https://www.proceedings.com/content/074/074978webtoc.pdf)에서 제목·저자를 확인한 추가 탐색 대상이다. 출판사 본문은 확보하지 못했다. 2차 요약만으로 신호 수·복소 복원 성능·반복 분리 구조를 검증했다고 표시하지 않는다. 같은 이름의 음성 위변조 탐지 GitHub 프로젝트와 혼동하지 않는다.

기존에 검토한 [UJM 연구의 본문 2·4절](https://arxiv.org/html/2602.04650v1)을 다시 확인했다. 간섭 후보가 여러 종류라는 것은 여러 간섭을 동시에 각각 출력했다는 뜻이 아니다. SOI와 한 간섭의 혼합을 다루므로 세 드론 분리의 직접 검증 자료로 올려 쓰지 않는다.
