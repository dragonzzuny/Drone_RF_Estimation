# 성분 사이의 정보를 사용하는 U-Net 출력층: 사전 검사

2026-10-10. 상태: 원 규모 CPU 검사 통과. GPU TRAIN4 사전 검사는 대기열에 등록했으며 현재 낮은 학습률 비교와 최종 검산이 끝난 뒤 실행한다. 새 구조의 본학습·개발검증 결과는 아직 없다.

## 검증할 가설

현재 최선 U-Net의 국소 복소 특징을 유지하면서, 세 출력에 대응하는 특징을 따로 만들고 성분 사이의 정보를 교환하면 파형 배분을 개선할 수 있는가?

[SepTDA](https://arxiv.org/pdf/2401.12473)의 성분축 처리에서 얻은 가설이다. 이번 구현은 **기존 공유 decoder 뒤의 출력 단계에 한정한 변경**이다. 논문의 attractor·가변 query·triple-path 전체를 재현하지 않는다. 긴 시간 문맥이나 새로운 개수 추정기도 추가하지 않는다. 그 변경들의 효과와 섞지 않기 위한 첫 대조다.

## 구현과 수식

공유 decoder 특징을 \(f\in\mathbb R^{64}\), 기존 세 복소 출력의 실수·허수 쌍을 \(r_j\in\mathbb R^2\)라 한다. 각 시간–주파수 위치에서 공유 함수로 성분별 특징을 만든다.

\[
h_j=W[f;r_j]+b,\qquad
A=\operatorname{softmax}(QK^T/\sqrt{64}),\qquad
v=h+W_oAV.
\]

공유 feed-forward 층과 두 채널 출력층을 거친 값을 \(c_j\)라 하면 추가 보정은

\[
\delta_j=c_j-\frac13\sum_{k=1}^3c_k,
\qquad r'_j=r_j+\delta_j.
\]

따라서 세 복소 보정의 합은 0이다. 기존 배경 출력은 직접 바꾸지 않고, 원래의 혼합 합 일치 투영도 유지한다. 추가층 자체는 세 성분 사이의 재분배만 담당한다. 본체까지 학습하므로 전체 네트워크가 배경 출력을 학습하는 경로는 남는다.

성분별 기종 embedding이나 정답 개수는 사용하지 않는다. 입력의 세 예측 쌍을 순열로 바꾸면 추가 보정도 같은 순열로 바뀐다. 이는 추가층의 성질이며 전체 모델의 기종 일반화를 증명하지 않는다. attention은 성분축에 적용하며 서로 다른 시간 표본 사이의 attention을 추가하는 구조가 아니다.

마지막 보정 출력 가중치는 0으로 초기화한다. 따라서 시작 파형과 개수 logits는 원래 모델과 정확히 같다. 첫 단계의 내부 attention 기울기는 0이고 마지막 출력층에는 기울기가 전달된다. 출력층이 변한 다음 내부 attention에도 기울기가 전달되는지 GPU 검사에서 확인한다. 보정 후 공통 bias는 상쇄되므로 불필요한 마지막 bias는 두지 않았다.

## 통과한 CPU 검사

- 원래 U-Net 32,142,859개 파라미터를 모두 유지했다. 후보는 32,180,747개로 37,888개가 추가된다.
- 실제 입력 길이 63,872 복소 표본에서 초기 파형·개수 logits의 완전 동일성을 확인했다.
- 보정이 0이 아닌 상태에서 여섯 성분 순열, 보정 합 0, 배경 유지, attention으로의 기울기를 검사했다.
- 메모리 절약용 위치별 분할과 checkpoint 재계산이 전체 계산의 출력·기울기와 일치했다. 분할은 시간 문맥을 바꾸지 않는다.
- 전체 모델의 순전파·역전파에서 유한 기울기와 혼합 합 일치를 확인했다. 원 I/Q·모델 체크포인트를 읽지 않았고 optimizer 업데이트는 0회다.

## GPU 사전 검사 규약

| 항목 | 고정 조건 |
|---|---|
| 시작점 | 보존 중인 native RF U-Net 선택 e2. 두 군 모두 같은 가중치 |
| 비교 | 기존 전체 U-Net / 성분 상호작용 출력층을 추가한 전체 U-Net |
| 자료 | 기존 TRAIN 일정 1의 앞선 두 성분 2개·세 성분 2개, 총 4개 |
| 학습 | 각 32업데이트, 실효 batch 4, microbatch 1, seed 0 |
| 최적화 | 두 군 모두 새 AdamW 1e-4, weight decay 1e-4, clip 1, FP32·TF32 끔 |
| 손실 | 기존 PIT NMSE·coherence·비활성/배경 및 0.1 개수 CE 유지 |
| 검사 | GPU에서 초기 예측 동일성, 유한 기울기, attention의 학습 경로, 두 성분 수의 TRAIN NMSE 감소 |
| 평가 범위 | 고정 TRAIN 적합도만 검사. 개발검증·보류 자료를 읽지 않음 |
| 가중치 | 검사 후 폐기. 본학습에 이어 쓰지 않음 |

전체 모델과 입력 크기의 실행 가능성·최적화 검사다. 4개 예제를 잘 맞춘 것으로 새 기록 일반화나 구조 우월성을 주장하지 않는다. 두 군 모두 같은 부모와 학습량을 사용하며, 추가층의 파라미터·계산량은 공개한다. 현재 최선의 네 위상 평균과 단일 추론을 섞어서 비교하지 않는다.

CPU 검사를 통과했더라도 본학습 비교의 예산·손실·시작점을 자동 변경하지 않는다. 현재 연속 학습의 완료 결과와 이 GPU 검사 결과를 본 뒤 별도의 대조 규약을 고정한다.
