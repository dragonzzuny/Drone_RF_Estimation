# 시간 순서가 보존된 문맥 경로의 동일 예산 비교

2026-10-10. 새 혼합 일정의 완료 결과를 확인한 뒤 정한 후속 비교다. 새 일정은 재사용 일정 대조보다 다중 신호 지표가 좋았으나 부모 모델을 넘지 못했다. 기존 자료에서 문맥의 시간 순서를 복원 경로에 전달하는 효과를 먼저 분리한다.

현재 평균 문맥은 긴 전력 특징 C의 시간 변동을 없앤다. 국소 복소 파형과 U-Net skip에는 시간·위상 정보가 남는다. 모델 전체가 시간 정보를 잃었다는 주장은 하지 않는다. SepFormer/SepTDA의 시간 처리와 우리 평균 경로의 차이가 검증 동기이며, 이번 변경을 해당 모델의 재현이나 새로운 이론으로 부르지 않는다.

후보는 32,142,859개 부모 파라미터 전체를 유지하고 특징별 게이트 65개만 추가한다. 입력은 `mean(C) + tanh(g) * (C - mean(C))`이며 g=0으로 시작한다. 따라서 시작 출력은 부모와 같다. 이후 시간 변동이 TCN, 창 위치 정렬, U-Net 병목, 세 개별 복소 출력까지 전달된다. 음성처럼 실수 신호로 바꾸지 않으며 긴 경로는 여전히 전력 특징이므로 긴 구간의 복소 위상을 제공하는 모델은 아니다. tanh(g)는 부호를 갖는 계수이며 확률·신호별 중요도로 해석하지 않는다.

이전 ordered TCN·긴 복소 경로·국소 게이트 비교는 보존한다. 이번에는 현재 native RF 부모의 함수에서 출발해 시간 변동의 전달만 점진적으로 열며, 이전 비교의 단순 재실행이나 전역 최초 시도라고 주장하지 않는다.

- RFUAV, 같은 원 RF 대역, native 100 MS/s, TRAIN 8/DEV 5 원기록 묶음, 고정 DEV 630개를 유지한다. 보류 확인 자료는 열지 않는다.
- 부모와 원 손실, seed 0, 새 혼합 schedule 3의 2,400예제(개수별 800), microbatch 1, 실효 batch 32, 75업데이트를 사용한다. 완료한 새 일정 비교가 동등한 부모 추가학습 대조다.
- 부모 파라미터의 새 AdamW lr=1e-5, wd=1e-4. 새 게이트만 lr=1e-2, wd=0. 전체 gradient norm은 1로 제한한다. 따라서 결과는 게이트 구조와 명시한 새 파라미터 학습 설정의 효과이며 구조만의 순수 인과 추정은 아니다. 추가 학습률 탐색은 예약하지 않는다.
- FP32, TF32 off, non-reentrant activation checkpoint를 사용한다. 업데이트·자료 예산을 맞추며 FLOP 일치를 주장하지 않는다.
- CPU에서 원규모 TRAIN 1/2/3개 첫 사례로 부모와 초기 출력 일치, 게이트 gradient, 시간 순서 교란의 전달 여부, 합 일치를 검사한다. gradient 검사 중 optimizer 업데이트는 0회다. 시간 교란의 성능은 평가하지 않는다.
- 실제 e1 및 e0를 모두 보고한다. 두·세 성분 각각 NMSE 감소, 복소 SI-SDR 증가, 최약 NMSE 비증가가 부모와 같은 일정 대조 모두에 성립할 때만 채택한다. 단일 성분 및 개수 정확도도 함께 보존한다.
- 추가 75업데이트로 시간 구조 활용의 충분한 수렴이나 모델 계열의 우열을 주장하지 않는다. 다음 설계는 결과에 따라 정하며 성분별 시퀀스 디코더·원혼합 공동 정제는 자동 실행하지 않는다.
