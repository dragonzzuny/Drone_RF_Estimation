# 추가 1 epoch와 CPU 진단: 현재 판단

2026-10-10 01:24 KST. 각 3 epoch GPU 비교는 진행 중이며 아래 결과는 **추가 e1까지**다. 같은 native RFUAV 분할·부모·자료 일정·원 손실·AdamW 1e-5·seed 0을 사용했다. 긴 구간에서 전력·위상을 정하고 같은 원 RF 대역에서 수신 중심 간격을 유지한다. 정답은 모델 추론에 들어가지 않는다.

## 현재 구조 변경은 개선하지 않았다

| 모델 | 개발 NMSE 2/3 ↓ | 개발 복소 SI-SDR 2/3 ↑ dB |
|---|---|---|
| 보존 부모 e0 | 0.466896 / 0.690253 | 3.777 / −3.109 |
| 기존 U-Net 추가 e1 | 0.488902 / 0.699657 | 3.366 / −3.518 |
| 성분 상호작용 출력층 추가 e1 | 0.488915 / 0.699675 | 3.365 / −3.521 |

두 군 모두 선택은 e0다. 630 개발 혼합은 다섯 원기록 묶음에서 나온 창이며 독립 기록 630개가 아니다. 세 성분은 한 기종 조합에 제한된다. 새 기종·예약 확인 파일은 열지 않았다. [모든 완료 epoch](SOURCE_INTERACTION_PROGRESS.md), [같은 혼합의 대응 비교](SOURCE_INTERACTION_PAIRED_DIAGNOSTICS.md), [학습 곡선 PDF](SOURCE_INTERACTION_EPOCHS.pdf).

## 학습 사례에서의 적합도

학습 e1의 기종·명목 전력 조합별 첫 두 행으로 고정한 TRAIN48을 세 모델에 똑같이 넣었다. 추가 학습·모델 선택은 하지 않았다. 부모 및 두 추가 e1의 CPU/GPU 재현 9건, 총 144건의 추론, 지표 재집계·가중치·소스 해시 검사를 통과했다. [전체 결과](SOURCE_INTERACTION_TRAIN_FIT.md), [독립 검산](SOURCE_INTERACTION_TRAIN_FIT_AUDIT.json).

| 모델 | TRAIN NMSE 2/3 ↓ | TRAIN SI-SDR 2/3 ↑ dB | 세 성분 약신호 NMSE ↓ |
|---|---|---|---:|
| 부모 | 0.322719 / 0.582800 | 8.886 / −1.613 | 0.994676 |
| 기존 U-Net e1 | 0.314960 / 0.565258 | 9.114 / −1.171 | 0.985600 |
| 추가층 e1 | 0.314973 / 0.565268 | 9.114 / −1.172 | 0.985605 |

학습 사례의 개선이 개발 기록의 개선으로 이어지지 않았다. 학습 사례도 정밀하게 맞추지 못하므로 과적합만으로 전체 실패를 설명하지 않는다. 다만 TRAIN48의 세 성분 14혼합에서 약신호 SIR 중앙값은 −22.997 dB, 개발 210혼합에서는 −13.294 dB다. 평균 차이를 일반화 격차의 추정값으로 사용하지 않는다. 여기서 SIR은 해당 성분 전력/나머지 정답 전력 합이며 수신 SNR이 아니다.

## 새 출력층은 학습됐지만 직접 영향이 작다

추가층의 readout 가중치 norm은 0에서 0.000493으로 변했다. QKV 가중치도 변했다. 이어서 기존 사전 검사와 같은 TRAIN4에서 **학습된 본체를 고정한 채 추가층만 켜고 껐다.** 세 원시 출력의 변화 에너지는 각각 혼합 에너지의 약 1.5e−9~1.1e−8이었다. 두 세 성분 혼합에서는 추가층을 켰을 때 NMSE·SI-SDR이 모두 소폭 악화했다. 두 두 성분 혼합에서는 소폭 개선했다. [출력 개입 결과](SOURCE_INTERACTION_HEAD_EFFECT.json).

이 결과는 추가층이 연결되지 않았다는 뜻이 아니다. 또한 TRAIN4의 효과가 전체 개발 기록에서 같은 방향이라는 뜻도 아니다. 현재 작은 학습률·0 readout 초기화·짧은 예산에서 추가 경로의 영향이 작다는 관찰이다. 37,888개 파라미터가 있다는 사실만으로 충분히 학습됐다고 간주하지 않는다.

세 보정량의 합이 0이므로 추가층은 합 일치 투영에 의해 소거되지 않는다. 반면 세 원시 슬롯이 완전히 같으면 공유 처리의 대칭성 때문에 세 보정량은 모두 0이다. 본체의 기존 독립 출력층까지 포함한 모델 전체가 분리할 수 없다는 증명은 아니다.

## 정답 전력 비율을 알면 개선 여지가 남는다

TRAIN48 중 두 성분 24혼합과 세 성분 14혼합에서 정답 STFT의 전력 비율을 혼합 STFT에 곱했다. **정답과 개수를 사용하는 비배포 진단**이며, 기존 모델의 성능으로 합산하지 않는다. 정답 구성 순서를 그대로 사용했고 bin별 PIT나 정답 배율 피팅은 하지 않았다.

| 진단 | NMSE 2/3 ↓ | 복소 SI-SDR 2/3 ↑ dB | 약신호 NMSE 2/3 ↓ |
|---|---|---|---|
| 정답 전력 비율 마스크 | 0.074709 / 0.262007 | 19.383 / 9.108 | 0.134567 / 0.562079 |
| 정답 크기 비율 마스크 | 0.098596 / 0.354040 | 18.233 / 7.232 | 0.178556 / 0.762309 |
| 정답 위상 포함 실수 simplex 마스크 | 0.058383 / 0.198045 | 20.789 / 11.493 | 0.104259 / 0.420571 |

마지막 행은 각 STFT bin에서 음이 아닌 실수 마스크들의 합이 1인 조건 아래 제곱 오차를 최소화한다. **중첩 합성 후 파형 NMSE의 최적값이나 자유로운 복소 모델의 성능 한계가 아니다.** 정답 비율을 혼합만으로 추정할 수 있음도 아직 증명하지 않았다. 다만 현재 잔차를 불가피한 오차로 확정하거나 상수 진폭 보정만으로 해결된다고 주장할 근거는 부족하다. [진단 전체](SOURCE_INTERACTION_ORACLE_ALLOCATION.md).

첫 진단 실행은 feature cache를 비활성화한 로더 설정으로 시작 전에 실패했다. 두 번째는 float32 혼합 합산의 반올림 잔차를 무시한 bin별 비교에서 실패했다. 실패 코드·규약·오류를 로컬에 보존하고 세 번째 독립 실행에서 수정했다. 실제 합산 잔차 NMSE의 최대는 1.38e−15, 그 잔차를 명시적으로 뺀 STFT 선형성 오차는 5.58e−32 미만이다. 자료·GPU 학습·평가 지표는 바꾸지 않았다.

## 다음 판단의 우선순위

1. 진행 중인 각 3 epoch를 같은 예산으로 마친다. 작은 e1 차이로 채택하지 않는다.
2. 추가층을 평가할 때 본체와 새 파라미터의 학습 속도를 구분한다. 다음 후보는 본체 학습률을 유지하면서 **새 층 학습률만 비교하는 고정 TRAIN 사전 검사**다. 성공해도 일반화 성과가 아니며 본 비교 가중치로 재사용하지 않는다. 현재 이 후속 검사는 아직 대기열에 등록하지 않았다.
3. 정답 전력 비율의 진단 이점을 실제 예측으로 옮기려면 배분 예측 자체가 학습되는지 측정해야 한다. 기존 파형에서 계산한 전력 비율 KL 추가는 이미 시험했으며 약신호 NMSE를 개선하지 못했다. [이전 완료 대조](../2026-10-09/POWER_ALLOCATION_FINAL.md). 이번 native RF 조건과 당시 중심 정렬 조건도 구분한다. 같은 보조 손실을 이름만 바꿔 새 방법으로 제시하지 않는다.
4. 여러 해상도의 시간 처리는 별도 구조 후보로 남긴다. [S4-UNET 본문 검토](S4_UNET_REVIEW_KO.md)의 단서는 두 신호 연구이며, 세 드론 파형의 검증 성과로 사용하지 않는다.

원기록 기여 파형 복원이 물리 드론 대수 추정·기종 식별 성과를 대신하지 않는다. 현재 진단은 다음 실험을 고르는 근거이며 논문 성능의 추가 성공 사례가 아니다.
