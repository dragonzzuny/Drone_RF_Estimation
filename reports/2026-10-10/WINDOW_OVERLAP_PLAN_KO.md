# 같은 I/Q 표본의 창 위치 의존성: CPU 진단

학습된 native 부모 U-Net을 바꾸지 않고 기존 TRAIN48에서 미리 정한 개수별 첫 두 사례, 총 여섯 사례를 검사한다. 이는 실제 모델 용량을 줄인 학습이 아니라 원 규모 모델의 추론 진단이다. 새로운 GPU 학습과 보류 자료 접근은 없다.

같은 긴 합성의 이득·위상·RF 주파수·문맥 특징을 유지하고 국소 창 시작만 0, −16,384, +16,384표본 이동한다. 100MS/s에서 ±163.84μs다. 세 창이 공유하는 중앙 31,104표본(311.04μs)의 혼합과 정답이 비트 단위로 같음을 확인한다. 새 창의 실제 위치를 기존 문맥 경로에 제공한다. 창별 전력 정규화와 위치 조건도 함께 달라지므로 padding만의 인과 효과로 해석하지 않는다.

세 예측의 원신호 슬롯은 공통 표본에서 중앙 창의 **예측**에 대해 여섯 순열을 비교해 정렬한다. 정답과 실제 개수는 추론·정렬·평균 가중치에 사용하지 않는다. 배경 슬롯은 고정한다. 중앙 창, 이전 창, 이후 창, 단순 평균, 창 중앙을 강조하는 양의 sin² 가중 평균의 다섯 조건을 모두 보고한다. 정규화한 가중치 합은 표본마다 1이므로 네 출력의 합 일치를 보존한다.

평가에서는 중앙 예측과 정답의 PIT 대응을 한 번 정한 뒤 다섯 조건에 동일하게 적용한다. 각 조건의 독립 PIT 대응도 기록해 순열 차이를 확인한다. 같은 공통 표본·정답 전력으로 NMSE와 복소 SI-SDR, 최약 성분 NMSE를 집계한다. 중앙 원래 전체 창의 출력은 기존 TRAIN48 진단값을 재현해야 한다.

총 18회 CPU 추론이다. 창 이동에 따른 예측 변화가 큰지, 중심에서 본 예측이 나은지, 합치면 두·세 성분 지표가 함께 좋아지는지를 관찰한다. 결과로 DEV 우월성이나 경계가 주된 실패 원인임을 확정하지 않는다. 개선이 관찰되면 별도의 고정 DEV 추론 비교 또는 동일 예산의 겹침 일관성 학습을 설계할 근거로만 쓴다. 실행 전 코드·부모·자료 준비 해시와 이 계획을 기록한다.
