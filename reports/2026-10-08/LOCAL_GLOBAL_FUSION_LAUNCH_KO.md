# 국소 복원과 긴 복소 문맥 결합: GPU 실행 확인

2026-10-08. 사용자의 계속 실행 요청에 따라 후속 가설을 구현하고 native CUDA에서 학습을 시작했다. 구현과 연결 검사를 통과했다는 사실을 분리 성능 개선과 구분한다.

두 군 모두 33,734,467파라미터다. 기존 짧은 복소 문맥 모델의 선택 e5를 공통 부모로 사용하고, 추가 문맥 인코더와 두 특징 조절기를 같은 seed 0 가중치로 초기화했다. 짧은 0.63872ms 복원 입력은 같다. 추가 경로가 보는 입력만 채점 창 밖 가림(`local_only`)과 10.48576ms I/Q 제공(`local_global`)으로 나뉜다. 별도 문맥은 256개의 시간 순서 토큰과 dilated TCN으로 처리하고, 실제 표본 시간 좌표에 맞춰 세밀한/압축된 국소 특징을 조절한다.

양쪽 모두 같은 약 21ms 시간 평균 전력 특징을 보조 입력으로 받는다. 개수 헤드도 기존 전력 특징을 유지한다. 새 분기 자체로 물리 드론 수 추정을 구현했다고 주장하지 않는다.

같은 RFUAV 원기록 그룹 분할·같은 대역·같은 중심 정렬 합성을 유지했다. 원 중심주파수 간격은 보존하지 않는다. 기존 학습 12,000혼합 목록을 다시 사용하며, 새 녹음·기종을 추가한 것이 아니다. 부모 학습 1,500업데이트 이후 양쪽에 추가 5 epoch/1,500업데이트를 제공한다. effective batch 8, microbatch 4, float32, TF32 off다. 기존 경로 LR은 cosine 1e-5→1e-6이고 추가 경로는 그 10배다. 전체 규모와 두 군의 조건을 맞췄다.

## 완료한 검사

- CPU 검사 3개 통과: native 표본 좌표 정렬, 두 군의 전체 초기 가중치·부모 가중치 정확 일치, optimizer의 전체 파라미터 포함과 학습률 예산.
- native GPU 검사: 1/2/3성분과 실제 microbatch 4에서 순전파·역전파·AdamW 통과. 검사 업데이트는 폐기했다.
- 문맥 조절을 끄면 공통 부모 출력이 정확히 일치한다. 대조군은 창 밖 위상 변화에 불변이고 실험군 출력에는 변화가 있다.
- 정답 파형·개수 라벨 변경이 추론 출력에 영향을 주지 않는다. 출력 합의 상대 오차는 약 2.8e-15다.
- 문맥 인코더와 두 조절기의 gradient가 유한하고 0이 아님을 확인했다. 압축된 특징 조절기의 초기 gradient는 약 2.7e-7로 세밀한 조절기 약 0.018보다 작다. 둘의 실질 기여가 입증된 상태는 아니다.
- 사전 검사 최고 GPU 할당량은 약 2.96GB다. 본 학습 실험군 e1의 최고 할당량은 약 3.35GB였다.

## 첫 완료 epoch

긴 문맥 결합군의 추가 e1/300업데이트를 완료했다. 2/3성분 NMSE는 5.630497 / 1.274130, 복소 SI-SDR은 −2.490 / −7.218dB다. 이 보고 시점에서 대조군의 같은 추가 예산 평가가 끝나지 않아 결합 효과를 판정하지 않는다.

선택은 추가 epoch 0을 포함한 2·3성분 평균 NMSE 최솟값으로 고정했다. 채택에는 각 성분 개수에서 NMSE 감소와 복소 SI-SDR 증가를 요구한다. 실패 조건과 작은 참조 전력도 모두 남긴다. Autel과 기존 보류 원기록을 열지 않았다.

특징의 affine conditioning은 [Perez 외의 FiLM](https://arxiv.org/abs/1709.07871)을 참고한 응용이다. 원 논문은 시각 추론 연구이므로 드론 분리 개선의 증거로 사용하지 않는다. 절차는 기존 experimental-design 지침을 참고했다: Kassis 외(2026), [Scientific Agent Skills](https://doi.org/10.48550/arXiv.2609.00065).
