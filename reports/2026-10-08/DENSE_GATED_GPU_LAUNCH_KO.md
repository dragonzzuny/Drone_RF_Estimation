# 확대 RFUAV 기준 U-Net·게이트 U-Net GPU 실행 확인

기록 시각: 2026-10-08T13:54:09.803643+09:00

사용자가 실행 권한을 변경한 뒤 RTX 4070 Laptop GPU와 호스트 프로세스 접근을 확인했고, PyTorch CUDA 실제 계산을 통과했다. 현재 새 비교의 학습 PID는 2768554이며, 기록 시점 기준 U-Net의 1 epoch에서 480개 혼합 / 15업데이트가 완료됐다. 성능 개선 결과는 아직 나오지 않았다.

## 전환과 보존

기존 대역 간 탐색 비교는 두 군 46 epoch / 3,450업데이트의 LAST 체크포인트와 optimizer·RNG를 검산해 별도 보존했다. 진행 중이던 47 epoch의 미저장 계산은 중단했다. 기존 큐를 먼저 종료해 뒤의 legacy 실험이 자동 실행되지 않도록 했다. 원격 화면 RustDesk는 정확한 신원과 256MiB 한도 내 공존만 허용했으며 종료하지 않았다.

첫 백그라운드 실행은 GPU 사전 검사 후 프로세스가 종료 영수증 없이 사라졌다. 원인을 확정하지 않았다. 이전 작업 종료와 백업 해시·원래 잠금들을 재확인한 뒤 지속되는 전경 감독 실행으로 연결했다. 실제 학습 업데이트를 관찰했으며, 활성 학습 코드는 변경하지 않았다.

## 비교 조건

- 같은 RFUAV 자료의 학습 원파일 83개, 학습 문맥 3,902개. 기존 5범주이며 새로운 독립 수집 기록이나 기종 추가가 아니다.
- 같은 원 RF 대역 안의 중심 정렬 합성. 실제 RF 중심주파수 간격을 유지한 실험은 아니다.
- 동일 초기 체크포인트 e22, seed 0, LR 1e-5, 각 5 epoch / 375업데이트 / 12,000혼합. 검증 630혼합.
- 1·2·3개 기여 파형 및 별도 배경 출력, PIT 복원 손실과 합성 성분 개수 보조학습.
- 기준 32,142,859파라미터, 게이트 34,769,675파라미터. 업데이트 예산은 같고 파라미터 수는 다르다.
- 병목 시간축 gated residual 블록을 추가하며, 출력 0 초기화로 초기 파형이 일치한다. 전체 복소 입력은 63,872표본(0.63872ms), 기존 평균 전력 문맥은 20.97152ms로 유지한다. 관측 시간을 더 길게 늘린 비교는 아니다.

## 확인한 것

두 모델 모두 원 입력 길이에서 1·2·3성분 순전파·역전파와 optimizer 단계가 통과했다. 이 사전 검사 가중치는 버렸다. GPU 최대 tensor 할당량은 기준 약 2.04GiB, 게이트 약 2.08GiB였다. GPU 전체 사용량과는 다른 지표다.

공통 초기 모델의 검증 2·3성분 평균 NMSE는 0.580626395로 기존 e22 선택 결과와 일치했다. 이는 새 개선 결과가 아니라 초기 가중치·평가 조건 확인이다. 새 비교는 두 군이 같은 epoch를 마친 시점에 NMSE·약성분 NMSE·SI-SDR·합성 개수 정확도를 함께 보고한다. 재사용한 개발 검증, seed 1개이며 독립 테스트·실제 드론 대수·범용 분리 성과로 해석하지 않는다.
