# 확대 자료 U-Net 비교: 공통 2 epoch 중간 결과

확인 시각: 2026-10-08T14:59:59.738669+09:00. 두 군 모두 추가 2 epoch / 150업데이트를 완료했다. 기준군 3 epoch 완료·게이트군 3 epoch 학습 중이며, 수치 비교에는 공통 완료한 2 epoch까지의 자료만 사용했다. 예정 예산은 각 5 epoch/375업데이트로 유지한다.

## 사전에 정한 규칙으로 선택한 결과

1·2·3성분 macro NMSE 최소값으로 선택했다. 두 군 모두 이번 추가 학습의 1 epoch가 선택됐다. 동일 검증 630혼합이며 아래 2·3성분 집계는 각 210혼합의 성분별 NMSE 평균이다. 낮을수록 좋다.

| 조건 | 2성분 NMSE | 3성분 NMSE | 2·3성분 평균 |
|---|---:|---:|---:|
| 공통 초기 e22 | 0.502123 | 0.659130 | 0.580626 |
| 확대 자료 + 기준 U-Net | 0.494315 | 0.660468 | 0.577392 |
| 확대 자료 + 게이트 U-Net | 0.494239 | 0.660577 | 0.577408 |

공통 초기 대비 선택 결과의 2·3성분 평균 NMSE는 기준군 0.557%, 게이트군 0.554% 낮다. 두 구조 간에는 게이트군의 오차가 오히려 0.0027% 높으며, 현재 구조 우월성을 뒷받침할 차이는 관찰되지 않았다.

개선은 주로 2성분 NMSE에 나타났고 3성분 NMSE는 초기보다 소폭 높다. 약성분 NMSE는 기준군의 2성분에서 0.842075→0.824921로 낮아졌으나, 3성분은 0.956907→0.957351이다. 게이트군도 유사하다.

절대 복소 SI-SDR은 초기 2성분 3.084dB / 3성분 -2.692dB, 기준군 2.870 / -2.670dB, 게이트군 2.868 / -2.669dB다. 2성분에서 NMSE 감소와 SI-SDR 감소가 함께 발생했으므로 전반적 복원 개선으로 결론내리지 않는다.

## 최근 epoch와 해석

선택된 결과만 제시해 변동을 숨기지 않는다. 추가 2 epoch 자체의 2·3성분 평균 NMSE는 기준군 0.591677, 게이트군 0.591562로, 두 군 모두 선택 epoch와 공통 초기보다 나빠졌다. 기준군만 완료한 3 epoch는 두 군 대조에 포함하지 않는다.

현재 결론은 **검증 최선 NMSE의 소폭 감소는 있으나 게이트의 추가 이점은 확인되지 않았다**이다. 추가 미세조정·자료 변경을 함께 적용한 전후 관찰이므로 감소 원인을 자료 확대만의 효과로 분리하지 못한다. 새 문맥은 기존 기록의 시간 범위를 확대한 것이며 새 독립 기록이나 기종 추가가 아니다. seed 0 한 번, 재사용한 개발 검증이며 독립 테스트 성과·완벽 분리·물리 드론 대수 검증이 아니다.
