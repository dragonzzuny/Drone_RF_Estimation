# 통합 e1 후속: 고정 절반 보정 검사

통합 e1은 두·세 신호 SI-SDR을 높였지만 NMSE는 증가했고 두 신호 최약NMSE도 증가했다. 사용자 규칙에 따라75업데이트에서 종료했다. 원본 모델의131개 tensor 불변과 새 층의 실제 갱신은 CPU 검산을 통과했다.

후속 가설은 기존 출력에서 통합 출력으로 이동한 정도를 줄이면 두 지표의 동시 개선을 얻을 수 있는가이다. 기존 출력과 통합 출력을 혼합 I/Q만으로 각각 구하고, 세 슬롯의 대응은 두 예측 간 복소 제곱오차로 결정한다. 정답이나 실제 합성 개수는 대응에 사용하지 않는다. 배경 슬롯은 유지한다. 대응한 두 예측을 고정0.5:0.5로 평균한다. 이는 두 모델의 추론 앙상블이며 가중치 보간이나 새 학습이 아니다. 단순 연산으로 합 일치도 유지된다.

원 규모 모델·native100MS/s·RF 중심 간격·RFUAV TRAIN8/DEV5 분할을 유지한다. 부모 선택e2와 종료된 통합e1을 고정하고 DEV630개 전체에서 한 조건만 검사한다. 0.5는 결과 전에 고정하며 다른 배율을 탐색하지 않는다. 두 입력 모델의 저장된 단일 추론 결과를630개 모두 재현하고, 같은 참조 전력·기록 정체성·합 일치를 검산한다. 참조 파형은 채점과 재현 확인에만 사용한다.

채택 방향 기준은 부모 단일 추론 대비 두·세 신호 모두 NMSE감소·복소SI-SDR증가·최약NMSE비악화다. 기존 네 위상 평균의 저장 결과도 별도 비교하되 계산량이 다름을 표시한다. 두 번의 순전파가 필요하고 개수 예측은 이번 검사에서 부모 출력을 유지한다. 개수 성능 향상이나 새로운 모델 이론을 주장하지 않는다.

한 epoch 후 가중치를 이용한 적응적 개발 검사다. 개선되더라도 두 예측의 평균 효과인지 보정 크기 자체의 원인인지 단독 확정하지 않는다. 개선이 없으면 이 고정 조건을 비채택하고 저장 결과를 보존한다. 추가 optimizer업데이트는0회이며 보류/독립 확인 자료는 열지 않는다.
