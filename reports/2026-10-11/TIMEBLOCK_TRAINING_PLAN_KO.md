# 동일 10 MHz 시간 구간 분리: 새 초기화 U-Net 50 epoch

사용자는 2026-10-11 새 학습과 **50 epoch 전체 수행, 매 epoch 보고**를 지시했다.
성능 정체에 따른 조기 종료는 사용하지 않는다. 수치 오류·자료 무결성 실패·자원
장애 또는 사용자의 별도 지시가 있는 경우에만 보존된 저장점과 함께 중단한다.
이 계획은 새 B 진단에 적용한다. 기존 C 규약·결과를 수정하지 않는다.

## 질문과 해석 범위

학습과 검증 모두 명목 VTSBW=10 MHz일 때, 서로 겹치지 않는 시간 구간의
1·2·3개 원기록 기여 파형을 얼마나 복원하는가? 기존 C는 미학습 20 MHz와
별도 녹음을 동시에 검증했다. B는 같은 녹음의 시간 분리이므로 별도 녹음
일반화를 입증하지 않으며, C와 자료·초기화·학습 예산이 달라 대역폭의 단독
인과 효과를 입증하는 비교도 아니다. 새로운 물리 드론 대수·기종 식별 실험이 아니다.

## 자료와 혼합

- RFUAV의 기존 TRAIN 10 MHz만 사용한다. Avata 2, FPV Combo, Mavic 3 Pro,
  Mini 3, Mini 4 Pro의 5개 범주다. 별도 조종기·결합 라벨·Autel·DEV20·최종 확인 자료를 제외한다.
- 기체별 동일 원녹음의 앞부분 1,296개 context를 학습에, 뒷부분 724개를
  진단 검증에 사용한다. 240개는 간격 때문에 제외한다. 원시 입력·필터 경계·긴
  context 전부를 포함해 양쪽 사이 최소 1초 간격을 둔다. 파일명 시간에 근거한
  구분이며 통계적 독립성을 보증하지 않는다. 짧은 창만 나눈 누출 검사는 아니다.
- 원 표본률 100 MS/s, context 2,088,960표본(20.8896 ms), 출력 창
  63,872표본(0.63872 ms). 기존의 결정론적 RF 필터·중심주파수 차이를 유지한다.
- 2.4 GHz: Mini 3 + Mini 4 Pro. 5.8 GHz: Avata 2/FPV Combo/Mavic 3 Pro의
  세 쌍과 세 신호 조합 한 개. 2.4와 5.8 GHz는 합치지 않는다.
- 긴 context의 전력으로 성분을 조절한 뒤 잘라서 사용한다. 짧은 창별 전력
  재정규화는 하지 않는다. 성분별 독립 위상은 균등 무작위다. 두 신호의 명목
  전력차는 -10/0/+10 dB, 세 신호는 동일 전력과 각 하나를 ±10 dB 바꾼 7조건이다.
- 매 epoch 2,400혼합(개수별 800), 서로 다른 50개 일정을 사전에 생성한다.
  검증은 고정 630혼합(개수별 210). 범주·전력 조건을 순환 균형 배정한다.
  원기록의 수신 잡음도 해당 성분의 복원 정답에 남는다.
- 캐시 2,020개 전체 해시·유한값·전력을 검사한다. 전체 원표본 구간 중첩과
  역할 간 정확히 같은 캐시는 배제한다. 임의 시차·주파수 이동 복사본까지 검사했다는
  주장은 하지 않는다. Mini 3의 XML/파일 pack 번호 불일치는 기존 기록대로 남긴다.

## 모델·학습 예산

- 기존 최선의 전체 크기 `unet_mean`: 64/128/256/512/1024 U-Net과 128폭
  TCN context 및 개수 head, 총 32,142,859개 파라미터를 모두 새로 학습한다.
  seed=0. 이전 프로젝트 체크포인트는 **어떤 것도 불러오지 않는다**.
  GPU 사전 점검에서 갱신한 가중치도 버린 뒤 다시 seed0으로 초기화한다.
- 입력 I/Q를 복소 STFT(n_fft=512, hop=128)로 변환해 실수·허수 채널로
  처리하고 복소 I/Q로 역변환한다. 장기 context의 시간 평균을 쓰는 기존
  구조다. 새로운 시간 구조 모델 또는 복소수 가중치 신경망으로 부르지 않는다.
- 기존 PIT 파형 손실: 성분별 NMSE+coherence, 비활성·배경 출력 벌점,
  합성 개수 CE 가중치 0.1. 모델은 세 비순서 성분 슬롯과 배경을 출력한다.
  정답 파형·기체명·정답 개수는 모델 추론 입력에 들어가지 않는다.
- 이번 fresh 학습에는 검증 개선이 확인되지 않은 추가 C8 일관성 손실을
  넣지 않는다. 무작위 성분 위상 학습과 **8위상 평균 추론**은 유지한다.
  따라서 기존 C8 추가 학습과 한 변수만 다른 대조라고 주장하지 않는다.
- AdamW 초기 lr=1e-4, weight decay=1e-4, FP32/TF32 off, gradient clip=1,
  microbatch=1, 유효 batch=32, epoch당 75업데이트, 전체 3,750업데이트.
  검증 NMSE 정체 5 epoch 이후 lr을 0.5배로 조정(최저 1e-6)한다. 이 조정은
  학습률만 낮추며, 사용자가 지정한 **50 epoch를 단축하지 않는다**.

## 검증·선택·보고

epoch0와 매 학습 epoch에 같은 630혼합을 8위상으로 추론한다. 입력 위상 회전
후 역회전하고, 정답 없이 예측끼리 슬롯을 맞춰 평균한다. 정답은 평가에만 쓴다.
선택 지표는 두·세 신호의 macro 평균 NMSE 최솟값이며 epoch0도 포함한다.
복소 SI-SDR·최약 NMSE를 함께 보고해 상충을 숨기지 않는다. 모든 지표의 우월성이
확인되지 않으면 NMSE 기준 선택을 전체 지표의 우월성으로 표현하지 않는다.

매 epoch 단일/두/세 신호 NMSE, 복소 SI-SDR, 최약 NMSE, 합성 개수 정확도,
이전 epoch 대비 변화, 선택 epoch, 학습률, 시간을 기록한다. 저장된 개별 630행의
역할·조건·집계, 모델 유한값, optimizer 업데이트 수를 CPU에서 감사한 후 보고한다.
이전 C의 CURRENT_BEST는 변경하지 않는다. B와 C의 수치는 별도 표에 둔다.

## 실행·재개·정리

코드·자료 규약·계획을 해시로 봉인하고 소스 사본을 저장한다. 학습은 GPU,
다음 epoch의 특징 생성과 완료 결과 검산은 제한된 CPU에서 병행한다.
5업데이트마다 optimizer/RNG/부분 epoch 복구점을 저장한다. 매 epoch 모델 저장점과
감사 영수증을 남긴다. 완료된 epoch의 재생성 가능한 특징 배열만 삭제 장부와 함께
정리하며 원시 자료·캐시·최선/최신/재개 모델은 보존한다.

기존 C8 실행은 새 파이프라인 검사가 끝난 뒤 가장 최근 유효 복구점을 보존하고
별도 전환 영수증과 함께 중지한다. 미완료 epoch를 완료 결과에 포함하지 않는다.
기존 실행의 코드를 고치거나 가중치를 새 B 실행에 넘기지 않는다.
