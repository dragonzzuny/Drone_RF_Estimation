# 보존 U-Net + 별도 시간 변화 인코더: 추가1epoch

GPU 구현 검사 통과 후, 성능 학습 전에 고정한 적응적 개발 실험이다.
가설: 이미 학습한 평균 문맥과 I/Q 복원기를 보존하면서 별도 시간 변화 경로를
학습하면 기록이 다른 DEV에서 파형 오차를 줄일 수 있다. 개선은 아직 확인 전이다.

## 변경과 재사용

native e2 U-Net32,142,859개 파라미터와131개 state tensor를 모두 고정한다.
같은 구조로 복제한 TCN·투영 및1024차원 gate735,232개를 학습한다.
전체32,878,091개다. 기존64/128/256/512/1024 U-Net 폭을 유지한다.
새 기여는 `tanh(gate) * .1 * projection(align(E(context)-E(mean(context))))`다.
gate=0에서 시작하므로 기존 출력과 정확히 같다. 상수 문맥에서는 새 기여가0이다.
전체20.8896ms의65×255 전력 문맥을 순서대로 처리하여0.63872ms 복원창의
위치에 맞춘다. 긴 문맥에는 복소 위상이 없고, 짧은 경로는 복소 I/Q를 유지한다.
이는 호핑 주기를 배웠다는 증거나 최초 시간 구조 활용 주장이 아니다.

기존 ordered_context 실험은 본체·TCN 전체와 gate를 함께 학습했다.
integrated 실험은 본체·TCN을 고정하고 다른 adapter와 gate를 학습했다.
이번에는 원 모델을 고정한 채 별도 TCN 자체를 학습한다. 동일 원기록을 다시
사용하므로 기존 실험과 독립적인 재현성 확인으로 표현하지 않는다.

## 학습·평가 예산

- TRAIN schedule3 원래 순서0..2399: 합성1/2/3성분 각800개, 총2400개.
  추가 shuffle 없음. 원 e2가 학습한 schedule1/2와 정확한 합성 recipe는 다르지만
  같은 TRAIN8기록 묶음이고 다른 개발 실험에서 이미 사용한 schedule이다.
- 추가1epoch,75업데이트,유효batch32/micro1,seed0,FP32/TF32 off.
- 새 encoder/projection AdamW lr1e-4·wd1e-4, gate lr1e-2·wd0,clip1.
  optimizer는 새로 시작한다. 원 PIT NMSE+coherence+inactive/background 및
  0.1개수CE를 유지한다. 고정 count 경로의 CE는 학습 기울기를 만들지 않는다.
- GPU 사전 검사 가중치는 폐기한다. 두 번 학습했던 기존 대조를 재학습하지 않는다.
  기존 fresh_schedule의 동일2400개/75업데이트 결과를 참고값으로 재사용하지만
  학습 대상·학습률이 다르므로 시간 경로만의 엄밀한 인과 대조라고 부르지 않는다.
- e0 DEV는 정확한 초기함수 보존 검사와 기존 저장된630행으로 재사용한다.
  e1에서 같은 DEV630을4회씩 추론해 단일 및4위상 결과를 함께 저장한다.
  정답은 점수 계산에만, 위상 간 출력 대응은 예측끼리만 한다.
- 채택은 단일과4위상 각각에서 두·세 성분 NMSE 감소, 복소SI-SDR 증가,
  최약 NMSE 비악화를 모두 만족할 때만 한다.1성분/개수/중앙값/모든행도 공개한다.
  통계적 유의성 검정이 아닌 사용자의 빠른 선별 규칙이다. 첫epoch에서 실패하면
  중지하고 e0를 유지한다. 성공하더라도 후속은 별도 판단, 자동 다음epoch 없음.
- 학습·평가 GPU 합45분 상한. 상태는 매 업데이트와 평가25사례마다 기록한다.
  CPU는 기존131tensor·optimizer75steps·모든630행·집계·선택을 검산한다.

RFUAV 한 자료의 같은 RF 대역·native100MS/s·수신 중심 간격·원기록 분할과
공통 관측 대역을 유지한다. 원자료를 다시 섞거나 DEV를 TRAIN으로 옮기지 않는다.
heldout Autel·별도 확인 자료는 미개봉. repeated DEV,seed1개,DEV VTSBW20이
TRAIN에 없는 수집 조건 변화, 세 성분 기종 조합1개를 한계로 기록한다.
실제 동시 수신·물리 기체 수·식별 개선·범용 복원은 이번 실험의 검증 대상이 아니다.
