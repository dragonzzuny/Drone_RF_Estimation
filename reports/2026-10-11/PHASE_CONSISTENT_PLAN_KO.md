# 8위상 평균 복원과 위상 일관성을 함께 학습하는 U-Net

## 질문과 변경

현재 최선인 native e2 U-Net의8위상 추론을 실제 학습 목적에 포함하면,
별도 녹음의 두·세 성분 복원 오차와 약신호 오차를 더 줄일 수 있는가?
사용자가8위상 U-Net의 추가 학습과 위상별 복원 차이 감소를 명시적으로
요청했다. 기존 종료된 실험의 재개가 아닌 새 추가 학습이다.

8개의 공통 위상0/45/90/135/180/225/270/315도를 매 혼합마다 **모두**
사용한다. 각 출력은 위상을 되돌린 뒤0도 출력에 예측끼리 순서를 맞춘다.
세 성분 슬롯은 전체 창에서 하나의 순열을 사용하고 배경 슬롯은 고정한다.
추론·위상 간 순서 대응에는 정답·기체명·실제 합성 개수가 들어가지 않는다.

`z_k = align(exp(-jθ_k) f(exp(jθ_k)x))`, `m = mean_k z_k`로 두면,

`L = L_original_PIT(m, s) + 0.1 L_consistency(z, m, s) + 0.1 CE_count`.

원 파형 손실은 기존 NMSE+coherence+비활성/배경 오차를 그대로 쓴다.
일관성 항은 위상별 출력과 평균 출력의 복소 오차 제곱이다. 평균 출력의
학습용 PIT 순서로 정답 성분과 대응하고, 활성 성분은 정답 전력, 비활성·
배경은 혼합 전력으로 정규화한다. 기존과 같은1e-6 혼합 전력 하한을
사용한다.0.1은 사전 고정한 실험값으로 최적값이나 개선 보장이 아니다.

평균 파형의 정답 손실을 유지해 출력끼리만 같아지는 것을 성공으로
채택하지 않는다. 일관성 감소는 원인 진단이며 최종 성공 지표는 I/Q
복원 성능이다. 이 변경은 canonical phase 한 방향 정렬과 다르며,
8위상 평균 자체의 미분과 위상 간 분산 벌점을 함께 추가하는 실험이다.
두 변경의 개별 기여를 입증하는 ablation은 아니다.

## 규모와 예산

- 동일한 전체32,142,859파라미터를 모두 학습한다. 새 축소 모델이나
  잔차망은 없다. 시작점은 기존 native SELECTED_005.pt 안의 e2다.
- 초기 예산 **추가10epoch**,epoch당2400혼합·75업데이트,유효batch32,
  microbatch1,총750업데이트다.8위상은8개 독립 녹음으로 세지 않는다.
- 고정 TRAIN schedule1~5를 두 번 순환한다. 새로운 원기록이나 새로운
  합성12000개가 추가된다는 뜻은 아니다. 매epoch1/2/3성분 각800개다.
- 새AdamW,lr1e-6 고정,weight decay1e-4,clip1,seed0,FP32/TF32off.
  기존 추가 학습의 악화를 고려한 보수적인 시작값이며 최적값은 미확인이다.
- 모든epoch의 전체DEV630을 단일·8위상으로 함께 평가한다.1epoch의
  악화만으로 종료하지 않고10epoch 곡선을 보존한다. 비유한 손실·기울기,
  자료/소스 불일치·자원 오류 또는 사용자 중지 지시는 즉시 중단 사유다.
  완료 뒤에도 개선 추세라면 별도 기록을 남겨 연장을 판단한다.
- 학습 속도보다 성능을 우선한다.8개 출력의 손실 기울기를 먼저 구하고,
  동일 가중치에서 각 위상을 다시 계산하여 역전파한다. 정확한 chain
  rule을 사용해8개의 전체 U-Net 계산 그래프를 동시에 보관하지 않는다.
  혼합당16forward(8 no-grad+8 replay),8backward다. 모델·입력은 축소하지 않는다.
- 모델에 Dropout/BatchNorm 및 갱신되는 buffer가 없는지 검사한다.
  작은 복소 시험에서 전체 그래프와 재계산 기울기를 대조하고, 실제
  전체 크기의1/2/3성분 TRAIN 입력에서 replay 일치·기울기·메모리를 확인한다.
  사전 검사에서 갱신한 가중치는 폐기하고 원 시작점을 다시 불러온다.

## 평가와 선택

현재8위상 DEV 결과를 고정 대조로 사용한다:NMSE2/3=0.444601135634/
0.688947604167,복소SI-SDR4.249089/-2.735627dB,최약NMSE0.734315863134/
0.948643577502. 기존 대조를 재학습하지 않는다. 따라서 추가 학습 예산과
새 손실이 동시에 달라지며, 추가 학습만의 효과와 일관성 항의 효과를
분리한 인과 비교는 아니다. 각epoch는 시작점과 이전epoch 모두에 비교한다.

새 방법 채택은 두·세 성분 각각의 평균NMSE 감소,복소SI-SDR 증가,
최약NMSE 비증가를 모두 요구한다. 통과한epoch 중2/3평균NMSE 최소를
연구 내부 BEST로 보존한다. 전체 평균만 가장 낮은epoch는 별도 진단으로
표시하고 현재 최선을 자동 대체하지 않는다. 독립 CPU의 저장점·optimizer·
행/집계 감사 뒤 연구자가 채택한다. 단일 추론 및1성분·개수·기종/전력별
회귀도 공개한다. 기존현재최선 파일을 학습 도중 덮어쓰지 않는다.

RFUAV 동일 데이터셋·동일 RF 대역·native100MS/s·중심 간격·긴 구간
전력 설정을 유지한다. TRAIN8기록묶음/DEV5기록묶음을 유지하고,Autel·
예약 확인 자료는 열지 않는다. 현재5기종·두 기종4조합·세 기종1조합,
DEV에만 존재하는VTSBW20의 한계를 보존한다. 반복 개발검증이며630창을
독립 녹음630개로 해석하지 않는다. 공통 위상 일관성은 독립 송신기 위상,
주파수 오차,호핑 반복 구조에 대한 범용성을 입증하지 않는다.

## 보고와 보존

GPU에서 저장된 업데이트·epoch·평가 상태를 보고한다. 파일 알림은 자동
채팅이 아니다. 소스·규약·정답 분할·초기 가중치 지문을 고정한다.
각epoch의실제가중치·LAST optimizer/RNG·전체검증행을 보존한다.
실패·미채택 수치도 남기며, 개선을 미리 주장하지 않는다.
