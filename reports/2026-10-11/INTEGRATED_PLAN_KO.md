# 통합 모델 우선 실험 규약

사용자는 개별 후보를 차례로 오래 학습하는 대신 변경을 결합해 빠르게 성능을 확인하도록 지시했고, 개선되지 않는 SepTDA의 즉시 중지도 지시했다. SepTDA는26구간 저장 후27구간72/75업데이트 상태에서 중지했다. 저장 전72업데이트는 새 결과로 세지 않는다. 이전 체크포인트·코드·결과를 보존하며 네 개별 후보 대기열도 중지했다.

출발점은 기존 최선 native U-Net e2다. 같은 RFUAV 원기록 분할(학습8묶음/83파일, DEV5묶음/48파일), 같은 RF 대역·native100MS/s·실제 중심주파수 차이·기존12,000합성·DEV630을 유지한다. 현재 검증은 학습에 없는 VTSBW=20 조건을 포함한다. Autel과 확인 자료는 열지 않는다.

원 규모 U-Net에 긴20.8896ms 전력 문맥의 순서 게이트, 국소 복소STFT의 시간/주파수 LSTM 블록, 특징 규모를 맞춘 성분 상호작용 보정을 함께 결합한다. 전체37,444,428파라미터를 유지하고, 원래32,142,859개는 고정한다. 추가5,301,569개만 학습한다. 추론에는 혼합 I/Q와 그 혼합에서 만든 특징만 들어가며 정답·기종·실제 합성 개수는 들어가지 않는다. 기체 전용 송신이나 실제 드론 대수 정답이 확인된 자료로 표현하지 않는다.

세 변경은0게이트/0최종 readout으로 초기화해 기준 파형을 그대로 보존한다. GPU에서 원 길이63,872표본의1/2/3신호 TRAIN사례 각각에 대해 초기 출력의 정확한 일치, 합 일치, 유한 기울기와 세 경로의 연결, 고정 본체의 가중치 불변을 검사한다. 임시3업데이트 검사 가중치는 버리고 같은 초기화에서 본 학습한다. 구현 검사 결과를 일반화 성능으로 주장하지 않는다.

원래 PIT 파형 손실과0.1개수 교차엔트로피를 유지한다. 세 학습률은 기존 후보 설정을 따른다: 시간 게이트1e-2, 시간/주파수1e-4, 성분 보정1e-3. AdamW, seed0, FP32/TF32 off, 실효batch32·microbatch1이다. 각32예제의 두/세 신호 파형 기울기로 실제 AdamW 변위를 보정한다. 개수 손실 기울기는 빼고 새 학습 파라미터에만 적용한다. 이는 해당 TRAIN배치의1차 근사 제약이며 다음 DEV 개선을 보장하지 않는다. 본체의 자동 해제·공동 학습은 이번 규약에 포함하지 않는다.

1로그epoch=2,400합성·75업데이트다. 첫epoch 후 전체DEV630의 I/Q NMSE·복소SI-SDR·최약NMSE를 먼저 보고한다. 기존 공통 대조와 기준 결과를 재사용하며 새로운 대조를 반복하지 않는다. 순수 구성별 기여, 같은 예산의 인과적 우월성, 독립 시험의 통계적 유의성을 주장하지 않는다.

최대50구간이지만 무조건 끝까지 실행하지 않는다. 다음 자원 배분 규칙을 결과 확인 전에 고정한다.

- 후보 선택은기존처럼 두/세 성분 평균NMSE 최저점이며 e0도 포함한다. 채택 판단은 별도로 두/세 성분 모두 NMSE감소·복소SI-SDR증가·최약NMSE비악화를 요구한다.
- e5까지 위 공동 개선을 보인epoch가 없으면 중지하고 원인을 검토한다. 5구간은 충분한 수렴의 증거가 아닌 빠른 자원 배분 기준이다.
- e5이후에도 선택NMSE의1e-5이상 개선이5구간 없으면 중지한다. 연속3구간 개선이 없으면 모든 학습률을반감하고 optimizer상태는 보존한다.
- 어느epoch든 두/세 성분NMSE가 모두기준의1.25배를 넘으면 즉시 중지한다. 숫자는 통계적 유의성 경계가 아닌 사전 자원 관리 기준이다.

학습 중 새 소스를 수정하지 않고 스냅샷·입력 지문을검산한다. 매epoch 모든630행·체크포인트·보호 변위·학습률·실제/선택 성능을 저장하고 실패도 남긴다. 현재 새로운 최선 성능이 확인된 것은 아니다.

설계 절차에는 로컬 experimental-design 스킬의 사전 비교 조건·독립 원기록 단위·탐색적 중간 판단 원칙을 참고했다. 모델 방법의 근거나 성능 검증을 대신하지 않는다.
