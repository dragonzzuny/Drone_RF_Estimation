# 별도 시간 변화 경로: GPU 구현 검사

성능 학습 전 등록. 기존 native e2 U-Net 32,142,859개 파라미터를 고정하고
복제한 시간 인코더·투영과 1024개 gate만 학습하는 구조를 검사한다.
전체 32,878,091개, 학습 대상735,232개다. 축소 모델이 아니다.

TRAIN schedule3에서 합성 개수1/2/3의 첫 사례를 사용한다. 각각 원 길이
63,872 복소 표본 및65×255 문맥을 유지한다. GPU FP32/TF32 off.
gate=0일 때 기존 모델과 복원값·개수 logits가 정확히 일치해야 한다.
첫 사례에서 원 파형 손실을 역전파할 때 gate 기울기는 유한·비영이고,
새 인코더의 기울기는0이어야 한다. 이어 임시 gate=.01에서 역전파해
gate·인코더·투영 모두 유한·비영인 기울기를 받는지 검사한다.
AdamW 한 번 후에도 기존131개 state tensor가 원본과 정확히 같아야 한다.
각 출력의 합 오차는1e-9 미만이어야 한다. 이 검사는 성능 향상 판정이 아니다.

검사 가중치는 모두 폐기하고 본학습은 원 e2와 gate=0부터 새로 시작한다.
DEV와 heldout은 읽지 않는다. GPU 시간·메모리를 기록하며20분 상한이다.
CPU 검사에서 상수 문맥의 FP32 평균 오차로 실패했던 초기 기록도 보존한다.
