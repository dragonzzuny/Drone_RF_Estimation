# TF-GridNet32의 배경 출력 배정 진단: GPU 재검사

학습한4혼합에서 약신호의 복원 실패와 잘못된 출력 배정을 구분한다.
현재 세 신호 출력은 PIT로 순서를 맞추지만, 네 번째 배경 출력은 고정한다.
약신호가 배경 출력에 복원돼 있다면 세 출력 내부의 순서 교환만으로는
이 성분을 찾을 수 없다. 실제로 그런지는 아직 확인하지 않았다.

첫 CPU 검사는 index4에서 GPU 지표와 NMSE 약7.53e-6 차이를 보여
고정한 재현 허용 기준을 실패했다. 원 실패와 기준을 보존한다. CPU와
GPU 연산 차이를 모델 성능 저하나 배정 오류로 해석하지 않는다.
고정32회 가중치와 TRAIN index[4,5,2,11]만 원래 GPU에서 다시 추론한다.
같은 원 길이·전체 모델이며 optimizer 갱신과 DEV·보류 자료 접근은 없다.
네 출력 각각을 배경 역할로 가정한 네 경우를 모두 검사한다. 나머지 세
출력의 순서는 원래 PIT 손실로 결정한다. 전체 원 손실이 가장 작은
배정을 정답 이용 진단으로 보고한다. 원래 배정과 네 대안을 모두 남겨
좋은 지표만 골라 보고하지 않는다. 실제 추론 또는 새 최선으로 채택하지 않는다.

추가로 네 출력과 실제 성분의 복소 coherence 행렬 및 출력 전력을 기록한다.
전체 길이 GPU 원 배정의 NMSE·SI-SDR을 저장된 GPU32회와 대조한다.
rtol1e-5, NMSE atol1e-6, SI-SDR atol1e-4dB를 실행 전 고정한다.
공유 GPU 잠금에서 현재 연속 학습이 끝날 때까지 대기한다. 잠금 대기
상한60분, 실제 진단 상한15분이다. 현재 학습을 중단하거나 병렬 GPU
추론으로 자원을 경쟁하지 않는다. 수치 허용 기준은 원 검사와 동일하다.

출력 역할을 바꿔도 개선되지 않으면 단순 배정 오류 가설의 우선순위를
내린다. 개선되더라도 정답 없는 역할 결정 방법과 별도 녹음 검증이 필요하다.
이는 같은4개 학습 예제의 사후 기전 진단이며 통계적 일반화 증거가 아니다.
