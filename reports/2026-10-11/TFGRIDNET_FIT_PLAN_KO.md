# 전체 TF-GridNet 복소 RF 구조의 고정 TRAIN4 검사

2026-10-11. GPU 사전 검사 후, 새 학습 수치를 보기 전에 고정한다.

기존 balanced-head U-Net256 진단은 두·세 성분 NMSE0.027757/0.194550,
세 성분 최약NMSE0.298842로 끝났다. 세 성분 오차는 마지막까지 줄었으므로
수렴 불가능이나 완전한 정체를 입증하지 않는다. 이 규약은 구조를 먼저
불가능하다고 선언하지 않고, 시간·주파수 전체 해상도에서 반복적으로
성분 관계를 처리하는 다른 귀납적 편향의 학습 가능성을 검사한다.

기존 TF 후보는 U-Net의32×31 병목에서 두 축 RNN을 적용했고 cross-frame
attention이 없었다. 새 후보는 저자 TF-GridNetV2의6블록·D128·양방향
LSTM192·4개 attention head를 그대로 쓰며512×500 격자에서 처리한다.
전체9,004,297파라미터이고 기존 U-Net32,142,859개와 크기가 다르다.
축소한 TF-GridNet이 아니지만 U-Net의 추가층이나 같은 파라미터 대조도 아니다.

원 논문은 음성·단측 STFT128/64·SI-SNR 손실이다. 이번은 복소 RF 양측
STFT512/128·기존 sqrt-Hann·세 성분+배경·기존 합 일치·NMSE/coherence
손실의 명시적 이식이다. 공개 음성 성능 재현 또는 드론 효능 검증으로 부르지 않는다.
긴20.8896ms 문맥의 평균 전력 특징은 그대로 유지한다.0.63872ms 복소 창
안에서 시간 전체를 처리하지만 긴20.8896ms 복소 위상을 보는 구조는 아니다.

- 자료: 동일 TRAIN schedule1의 index[4,5,2,11],2성분2개와3성분2개.
  native100MS/s·같은RF대역·실제 중심 간격·63,872복소 표본 그대로.
- 초기화: seed0 새 초기화. 부모 또는 사전 검사 가중치를 가져오지 않는다.
  공개 recipe의 Xavier 규칙을 적용하며 출력층은 비영으로 둔다.
- 학습: AdamW5e-4,wd1e-4,clip1,실효batch4/microbatch1,FP32,TF32off.
  원래 PIT NMSE+coherence+비활성/배경+0.1개수CE를 유지한다.
- 한도: 최대32업데이트 또는 학습45분. 시간 한도는 업데이트 완료 시 검사한다.
  0/1/4/8/16/24/32 및 시간 한도 종점에서 모든10성분을 기록한다.
  이 짧은 검사는 학습 가능성과 처리량 판단이며 최종 수렴 평가가 아니다.
- 성공 판단: 같은 모델 초기값보다 두·세 성분 NMSE가 모두 줄었는가를 먼저
  보고 SI-SDR·최약성분·최대 오차·모든 성분을 함께 공개한다. 모든10성분
  NMSE≤0.05면 자원 배분용 적합 목표로 종료한다. 기존 모델 우월성이나
  논문 채택 기준으로 해석하지 않는다.
- 기존 새 초기화 U-Net256의 저장 수치를 참고하고 대조를 재학습하지 않는다.
  모델 크기·초기화·계산량이 달라 순수한 단일 요인 구조 대조는 아니다.
- GPU 사전 검사: 원 길이3성분1사례,1 optimizer 업데이트,모든6블록
  유한·비영 기울기. 최대4,439,489,536바이트,12.799초. 임시 가중치 폐기.
- 독립 LSTM sequence batch를32개씩 처리하고 활성값을 재계산해 메모리를
  줄인다. 시간 길이·주파수 해상도·모델 파라미터는 줄이지 않는다.
- DEV·보류 I/Q를 읽지 않는다. 정답·기체명·실제 합성 개수는 모델 입력에
  전달하지 않는다. 현 최선 가중치와4위상 추론을 유지한다.

32회 결과의 성분별 개선·수렴 추세·시간을 확인한 뒤 더 긴 진단 또는
별도 녹음 평가가 필요한 학습을 등록한다. 성공한 조건만 추려 보고하거나
정해진 후보 대기열을 자동 재개하지 않는다.
