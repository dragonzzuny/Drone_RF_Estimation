# 현재 복원 문제: 확인한 관찰과 아직 남은 가설

2026-10-09 17:53 KST 기준이다. 두 문맥 비교군 모두 e2/150업데이트와 검증을 완료했다. 다음은 local e3이다. 다음의 서로 다른 비교를 한 모델의 연속 개선으로 합치지 않는다.

## 확인한 관찰

1. **이번 같은 예산의 세 구조 비교에서는 U-Net이 가장 좋았다.** 각 5 epoch/375업데이트 후 같은 개발 NMSE 규칙으로 선택한 U-Net e4의 2/3성분 NMSE는 0.522382/0.725482였다. 두 WaveNet의 실제 복소 입력 길이는 같은 0.63872ms였다. 파라미터와 계산량이 달라 계열 전체의 최적 성능 비교는 아니다. [완료 비교](ARCHITECTURE_FINAL.md).

2. **전체 복소 문맥을 보는 후속 모델도 첫 두 epoch에서 정밀 복원에 도달하지 못했다.** 공통 e2의 local NMSE2/3=32.332469/1.861575, SI-SDR=−2.986/−6.539dB로, 이 예산에서는 긴 문맥군보다 네 평균 지표가 모두 좋았다. 이는 32표본 재배열을 사용하는 별도의 WaveNet 비교다. long e1→e2에서 NMSE는 2성분 41.460482→32.515187, 3성분 2.185028→1.884051로 감소했지만 복소 SI-SDR은 −2.549→−3.134dB, −6.063→−6.637dB로 낮아졌다. NMSE 감소를 전체 분리 품질 개선으로 요약하지 않는다. [완료 epoch](PHASE_CONTEXT_PROGRESS.md).

3. **새 문맥 모델은 이미 학습한 사례도 충분히 맞추지 못했다.** e1 체크포인트를 고정해 실제 본 TRAIN48을 다시 평가했다. long의 1/2/3성분 NMSE는 0.483522/1.511499/11.050848이었다. 따라서 실패를 새 기록 일반화의 문제만으로 설명할 수 없다. 48개와 검증 630개는 구성과 전력 분포가 달라 평균 차이를 일반화 격차로 직접 계산하지 않는다. [CPU 재현과 학습 적합도](PHASE_CONTEXT_TRAIN_E001.md).

4. **큰 국소 전력차는 학습에도 있었다.** 이미 학습한 첫 epoch에서 20dB 이상은 2성분 199/800개, 3성분 359/800개였다. 전체 예정 TRAIN의 24,000개 기록 기여 중 손실 분모 바닥값 적용은 0개였다. 큰 전력차를 한 번도 보지 못했다거나 분모 보정이 약신호 손실을 없앴다는 설명은 이 자료와 맞지 않는다. 이것으로 기록·대역폭·활동 분포가 같다고 결론 내리지는 않는다. [전체 전력 검사](TRAIN_POWER_DISTRIBUTION.md).

5. **균등 합 일치 보정은 사례에 따라 오차를 늘리기도, 줄이기도 했다.** 극단 실패 6개의 사후 분해에서 부호 있는 교차항까지 포함해 이를 확인했다. 고정 U-Net e4에 추정 전력 가중 보정만 추가한 TRAIN48 추론은 오히려 악화했다. 따라서 단순히 보정을 없애거나 추론 가중치만 바꾸는 것을 해결책으로 채택하지 않았다. [오차 분해](PHASE_PROJECTION_E001.md), [전력 가중 추론 실패](PROJECTION_WEIGHT_TRAIN.md).

## 두 출력 모델에서의 설명을 그대로 옮길 수 없는 이유

현재 모델은 **세 기록 성분 슬롯과 고정 배경 슬롯**을 갖는다. 실제 활성 성분이 두 개여도 세 번째 슬롯과 배경 출력이 존재한다. 현재 합성에는 별도 배경 원신호를 더하지 않으며, 각 기록의 수신 잡음은 해당 정답에 포함돼 있다.

모든 출력의 오차 합은 0이지만, 두 활성 성분만 보면

\[
e_1+e_2=-e_{\mathrm{inactive}}-e_{\mathrm{background}}
\]

이다. 따라서 과거 두 출력 모델의 \(e_1=-e_2\) 또는 전력차 10dB에서 약신호 NMSE가 정확히 10배라는 관계를 현재 결과에 자동 적용하지 않는다. 비활성·배경 출력이 충분히 0인지도 확인해야 한다.

long e2의 평균 배경 출력/혼합 에너지비는 2성분 약 0.110736, 3성분 약 0.116547이다. 이는 해당 출력의 에너지비이며 신호 배분 비율이나 원인별 오차 기여율이 아니다. 위상·교차항 때문에 다른 출력의 에너지비와 단순 합산하지 않는다. [전력차 및 출력 슬롯 진단](PHASE_CONTEXT_POWER_GAPS.md).

## 아직 검증할 가설과 실제 상태

- **출력 표현의 학습 효율:** 동일한 원 규모 U-Net이 복소 값을 직접 예측하는 경우와 혼합 STFT에 복소 마스크를 곱하는 경우를 비교한다. 두 군 모두 같은 혼합/4 출력에서 시작한다. 전체 입력 CPU 검사는 통과했고, GPU TRAIN4 각 256업데이트 진단은 대기 중이다. [규약](OUTPUT_PARAMETERIZATION_PLAN_KO.md).
- **큰 오차 사례의 최적화 영향:** 극단 전력차가 포함된 실제 학습 batch32의 출력층 기울기 계산과 저장 벡터 독립 검산을 완료했다. long e2에서 가장 큰 사례의 개별 norm 합 대비 비율은 기존 90.62%→진단용 log1p 14.18%, 선택 U-Net e4에서는 79.16%→29.13%였다. 같은 원래 PIT 대응에서 계산했으며 모델 업데이트는 0회다. 모델별 출력층 크기와 학습량이 달라 서로 다른 모델의 norm 크기를 우열로 비교하지 않는다. 한 극단 batch의 결과를 전체 학습 기여율이나 과거 clipping 이력으로 해석하지 않는다. [문맥 모델 진단](HEAD_GRADIENT_E002.md), [U-Net 진단](UNET_HEAD_GRADIENT_E004.md).
- **실제 손실 비교:** 동일한 U-Net e4 가중치와 새 optimizer로 시작하는 기존 손실/log1p 두 군을 각 추가 3epoch/225업데이트로 등록했다. 원 규모 전체 입력의 CPU 기울기 검사를 통과했다. 앞선 GPU 작업 뒤에 실행하도록 대기 중이며, 실제 RF 학습 업데이트는 아직 0회다. 기존 raw NMSE와 SI-SDR로 평가한다. [비교 규약](ROBUST_NMSE_PLAN_KO.md), [CPU 검사](ROBUST_NMSE_CPU_CHECK.json).
- **긴 문맥의 효용:** 전체 20.89ms 복소 입력은 실제로 제공되지만, 입력 제공만으로 네트워크가 유용한 시간 구조를 학습했다는 뜻은 아니다. 현재 두 군의 각 5 epoch 규약은 유지한다. 충분한 수렴 후의 우열은 별도 문제다.

관찰을 원인으로 확정하지 않으며, 실패 사례를 평가에서 제외하지 않는다. 자료는 RFUAV의 같은 대역·원 수신 중심 차이·원기록 분할을 유지한다. Autel 및 기존 확인용 기록은 여전히 미개봉이다. 현재 결과는 정해진 기록 기여 파형의 합성 혼합 실험이며, 실제 동시 수신 드론 대수·범용 분리·기종 식별 성과를 대신하지 않는다.
