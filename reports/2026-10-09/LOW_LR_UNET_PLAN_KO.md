# 원 규모 U-Net: 미세조정 학습률의 대응 비교

2026-10-09 22:26 KST 설계. 실행 전 고정하는 추가 개발 실험이다. 기존 비교를 관찰한 뒤 설계한 탐색이므로 전체 연구의 사전등록 또는 독립 확인 실험으로 표시하지 않는다.

기존 학습률5e-4·새 AdamW에서 시작한 두 손실군은 추가e1에 모두 시작점보다 네 평균 파형 지표가 나빠졌다. log1p e2도 시작점보다 나빴다. 따라서 손실 변경의 효과와 미세조정 학습률에 대한 민감도를 구분한다. 이 관찰만으로 높은 학습률이 실패 원인이라고 확정하지 않는다.

## 실행 조건과 예산

- 현재 기존/log1p 각3epoch/225업데이트 비교와 독립 완료 검산을 먼저 끝낸다. 기존 실행·소스·학습량을 변경하지 않는다.
- 그 결과의 선택 모델 중 하나라도 시작 U-Net보다2/3성분의 NMSE 감소와 SI-SDR 증가를 모두 달성하면 본 후속은 실행하지 않는다. 선택e0는 개선으로 세지 않는다. 그 외에는 GPU 잠금을 이어받아 실행한다.
- 두 군은 같은 원 규모 U-Net32,142,859파라미터, 같은 부모e4/300업데이트, 같은 새optimizer·seed0에서 시작한다. TRAIN 일정1과 검증630개를 그대로 사용한다. 파형 정답·기종·합성 개수는 추론 입력에 전달하지 않는다.
- 학습률을5e-4에서1e-4로만 낮춘다. AdamW weight decay1e-4·clip1·실효batch32·microbatch1·FP32·TF32off를 유지한다. 각군1epoch/75업데이트이며 순서는기존→log1p다.
- 기존 손실과log1p 손실 각각에서 이전5e-4의 **실제e1**과 새1e-4의 **실제e1**을 비교한다. 이전e2/e3 또는 서로 다른 선택epoch로 학습률 효과를 대신하지 않는다. 모델 규모를 축소한 실험이 아니다.
- 기존 전체 창 PIT 대응·coherence·배경·0.1개수CE·미활성 슬롯 처리를 유지한다. log1p는 원래 PIT 대응에서 정규화 오차u를ln(1+u)로 바꾸는 기존 구현 그대로다.

자료는RFUAV 한 데이터셋·같은 원 RF 대역 합성·native100MS/s·원 수신 중심 간격·원기록 묶음 분할을 유지한다. 기존 TRAIN 일정1은 부모가 이미 본 자료이며 새로운 녹음으로 세지 않는다. Autel 및 예약 확인 기록은 열지 않는다.

## 판정과 한계

보정하지 않은 I/Q NMSE·복소 SI-SDR·약한 성분 오차·각 성분 개선 여부·합성 개수 정확도를 보고한다. 손실 숫자 자체는 서로 다른 척도이므로 비교하지 않는다. 선택은e0 포함2/3성분 평균 raw NMSE 최소이며 실제e1과 선택 모델의 수치를 구분한다.

각 손실에서 낮은 학습률이 두 혼합 개수의 NMSE와 SI-SDR을 함께 개선하는지, 시작 모델도 넘는지 따로 판정한다. 한seed·한epoch의 개발 민감도 검사이며 충분한 수렴·최적 학습률·미학습 기종 일반화의 증거가 아니다. 실패 조건과 기존 큰 학습률 결과도 유지한다.

원 규모 모델 생성·학습률/예산 제어·모델과손실 호출 불변성·합성 AdamW 한 단계의 배율을 CPU에서 검사했다. 기존 전체 입력 및 두 손실의 유한 기울기 검사 소스는 해시로 재사용 확인했다. 새 RF 학습 또는 새 데이터 읽기는0회다. 첫 검사에서는 Python import 경로 오류로 모델 생성 전에 종료됐으며, 실제 worker의 동일 import 경로로 수정한 뒤 통과했다. [CPU 검사](LOW_LR_UNET_CPU_CHECK.json).

학습 가중치·optimizer·RNG·실제/선택 체크포인트를 저장한다. 독립 완료 검산기는75개 업데이트와 실제optimizer 학습률1e-4, 모든630개 평가 행, 선택된 가중치의 일치까지 검사한다. 실행하지 않은 조건은 실행 완료로 표시하지 않는다.
