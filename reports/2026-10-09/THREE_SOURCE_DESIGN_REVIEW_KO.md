# 세 신호 분리: 선행 근거, 수식 검산, 다음 대조 설계

2026-10-09 23:55 KST. 현재 GPU 비교의 코드와 예산은 유지했다. 아래 문헌 검토와 CPU 검산은 추가 RF 모델의 학습 성과가 아니다.

SplitNet-3는 U-Net을 세 RF 신호에 적용한 직접 사례지만, 현재 우리의 파형 손실을 BCE로 바꿀 근거는 아니다. 정답 비트·변조 규약을 모르는 드론 기록에 같은 복호 목표를 가정하지 않는다.

‘혼합 자료 10종’이 ‘10개 신호 동시 분리’를 뜻하지는 않는다. 두 신호만 다룬 연구와 여러 안테나를 사용한 연구도 구분했다. 이번 검토는 선별 검토이며 선행연구 부재를 증명하는 전수 조사는 아니다.

구조 변경의 우선 가설은 **혼합의 공유 특징에서 성분별 잠재표현을 만들고, 성분 사이의 관계를 처리하면 세 출력의 파형 분배를 개선할 수 있다**는 것이다. SepTDA에서 얻은 적용 가설이며 드론 RF에서 검증된 처방은 아니다. 시간 문맥과 개수 추정기까지 동시에 바꾸면 어떤 변경이 효과를 냈는지 구분하기 어려우므로 첫 대조에서는 한 구조 변경만 시험한다.

## 현재 출력식이 세 정답 파형을 표현할 수 있는가

한 STFT 좌표에서 네 원시 출력을 복소 벡터 \(r\in\mathbb C^4\), 혼합을 \(x\)라 하면 현재 출력은 다음과 같다.

\[
y=r+\tfrac14\mathbf1(x-\mathbf1^T r)
 =Pr+\tfrac{x}{4}\mathbf1,
\qquad P=I-\tfrac14\mathbf1\mathbf1^T.
\]

\(P^2=P\), \(\operatorname{rank}P=3\), \(P\mathbf1=0\)이다. 네 원시 출력의 공통 성분은 사라지고 \(\sum_jy_j=x\)가 된다. 정답 \(t=(s_1,s_2,s_3,0)\)가 \(s_1+s_2+s_3=x\)를 만족하면 \(r=t\)에서 \(y=t\)이다. **출력식 자체가 세 정답 파형을 배제하지 않는다.** 네트워크가 그 해를 쉽게 학습한다는 증명은 아니다.

동시에 \((s_1+d,s_2-d,s_3)\)도 임의의 \(d\)에 대해 같은 혼합을 만든다. 따라서 합 일치만으로 정답 분리가 결정되지는 않는다. 시간·주파수 구조 등 데이터의 분리 단서를 학습해야 한다.

현재 오차는 \(e_1+e_2+e_3+e_b=0\)이다. 과거 두 출력의 \(e_1=-e_2\) 및 두 오차 에너지의 동일 관계를 그대로 적용할 수 없다. 각 기록의 수신 잡음도 정답에 포함하므로 별도 배경 정답은 합성 규약상 0이다. 네 번째 출력이 있다는 사실만으로 실패 원인을 확정할 수는 없다.

보존 중인 네 위상 평균 모델에서, 세 성분 사례의 배경 출력/혼합 에너지 평균은 0.001710이다. 이는 작은 배경 출력의 관찰이며 약신호 오차에 대한 기여율은 아니다. 배경 출력 제거의 효과는 새 학습 대조가 필요하다.

## 실제 구현 검산

실제 동결 손실 함수를 별도의 복소 스칼라 계산과 대조했다. 1·2·3개 활성 성분, 여섯 출력 순열, 비활성 0 표적을 검사했다. 순열 불변성과 완전 정답의 손실 0을 확인했다. 원 I/Q·체크포인트·보류 자료를 읽지 않았다. [검산 결과](THREE_SOURCE_MATH_CHECK.json).

실제 STFT 분석·합성 함수의 합성 복소 파형 왕복 NMSE는 약 \(1.37\times10^{-15}\)였다. 이 수치 오차가 현재 큰 복원 오차를 설명하지는 않는다. 첫 검사는 float32 창을 float64로 가정한 엄격한 허용오차 때문에 실패했다. 실제 창 dtype과 별도의 float64 창 왕복 오차 \(4.55\times10^{-32}\)를 확인한 뒤 진단의 허용오차만 수정했다. 모델 코드는 유지했다.

활성 성분의 손실은 정규화 파형 오차와 \(1-|\rho|^2\)이다. 평균을 제거한 비퇴화 신호에서

\[
\mathrm{SI\!\!\!-\!SDR}=10\log_{10}\frac{|\rho|^2}{1-|\rho|^2}
\]

이므로 coherence는 SI-SDR과 같은 방향의 목표다. SI-SDR 항을 더하는 것은 새로운 분리 정보를 제공하기보다 최적화 가중치를 바꾸는 실험이다. 절대 진폭·위상 오차는 NMSE가 반영한다. 상수 복소 배율에 대한 SI-SDR의 불변성도 수치로 확인했다.

개수 head는 파형 출력을 하드 마스킹하지 않는다. 개수 예측 오류가 곧 출력 슬롯 삭제로 이어지는 구조는 아니다. 정답 파형·기종·정답 개수는 추론 입력에 없다. PIT는 평가 구간 전체에 하나의 출력 대응을 적용하며 주파수 bin별로 정답 대응을 바꾸지 않는다.

현재 긴 문맥 경로는 **시간 평균 후** 인코딩한다. \(\bar H=T^{-1}\sum_tH_t\)는 시간 순열에 불변이므로 이 경로가 호핑 순서를 보존한다고 설명할 수 없다. 국소 복소 파형은 0.63872 ms다. 전체 20.89 ms 복소 입력 후보도 이미 시험했으나 해당 후보는 개선하지 못했다. 입력 길이 확대와 유용한 시간 구조의 학습은 구분해야 한다.

## 잔차 진단이 주는 우선순위

현재 최선의 네 위상 평균 U-Net에서 세 성분 중 약신호의 평균 NMSE는 0.948934다. 정답을 사용해 각 창의 상수 복소 배율과 DC를 최적으로 보정해도 진단값은 0.869289다. 이 종류의 보정으로 제거 가능한 평균 오차는 약 8.39%였다. **창 전체를 일정하게 키우거나 위상 회전하는 것만으로는 남은 오차 대부분을 설명하지 못한다.** 시간에 따라 달라지는 왜곡의 원인까지 확정한 분석은 아니다. [전체 모델·모든 조건의 진단](CURRENT_AFFINE_RESIDUALS.md).

## 실험 설계와 다음 단계

1. 진행 중인 학습률 1e-4의 두 군을 각각 총 3 epoch까지 완료한다. 이전 5e-4의 같은 실제 epoch와 비교한다. 학습률·손실 효과를 구조 효과로 부르지 않는다.
2. 실용적인 비교 기준으로 기존 선택 U-Net e2를 보존한다. 네 위상 평균은 별도 추론 조건이다. 모든 후보에 동일하게 적용하거나 단일 추론끼리 비교한다. 이전 학습 이력이 더 긴 모델과 새 초기화 모델의 차이를 구조 효과로 해석하지 않는다.
3. 다음 구조 후보에서는 원 규모 U-Net을 유지하면서 성분별 잠재표현 및 성분 사이의 처리를 시험한다. 공유 특징에서 마지막 여덟 채널만 출력하는 현재 구조와 구분한다. 긴 문맥·새 손실·개수 추정기를 한꺼번에 바꾸지 않는다.
4. 구현 후 입력·출력 차원, 출력 순열, 복소 합 일치, 기울기를 먼저 검사한다. 추가 파라미터·연산량·초기 예측의 차이를 기록한다. 합성 텐서 검사와 고정 TRAIN 적합도는 실제 RF 일반화 성과와 구분한다.
5. 두 군은 동일 부모·자료 일정·batch·업데이트 예산·seed를 사용한다. 대조군도 같은 양만큼 학습한다. 정답 개수를 주는 진단은 oracle count로 따로 표시하고 실제 추론 평가를 대체하지 않는다.

구체적인 새 구조와 예산은 현재 연속 비교가 끝난 뒤 고정한다. **새 구조는 현재 검토 단계이며 GPU 대기열에 등록하지 않았다.**

채택 판단에는 2·3성분 raw NMSE 감소와 복소 SI-SDR 증가를 함께 사용한다. 약신호와 모든 성분의 개선 여부, 1성분 보존, 개수 정확도, 실제 국소 전력차별 결과도 남긴다. 현재 개발검증은 다섯 원기록 묶음과 세 성분 한 기종 조합에 제한된다. 630개 창을 630개 독립 기록으로 세지 않는다.

같은 기종의 서로 다른 기록을 허용하는 두 성분 9구성·세 성분 14구성은 [이전에 준비한 별도 후보](../2026-10-07/DATA_VOLUME_AND_COMBINATIONS_KO.md)다. 현재 봉인 로더는 중복 기종을 거부한다. 이번 학습에 몰래 추가하거나 서로 다른 물리 기체의 실측으로 표시하지 않는다. 구조 효과와 조합 확대의 효과는 별도 대조가 필요하다.

개발 비교를 고정하기 전에 확인용 Autel과 예약 여섯 파일을 열지 않는다. 반복 개발검증과 한 seed의 한계를 공개한다.
