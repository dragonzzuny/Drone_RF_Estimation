# U-Net 출력 표현 비교: 준비와 GPU 진단 대기

2026-10-09 16:32 KST 기준이다. 현재 긴 복소문맥 비교는 GPU에서 계속 학습 중이며, 아래 후속 진단은 **대기 상태, 0업데이트**다. 실행 PID는 4190588이고 앞선 두 군의 각 5 epoch/375업데이트가 완료돼야 시작한다.

## 검증할 가설

현재 U-Net은 정규화한 복소 STFT 값을 직접 예측하고 네 출력의 합을 혼합 입력과 맞춘다. 입력의 복소 값을 곱셈 경로로 전달하는 마스크 표현이 같은 본체의 학습을 더 쉽게 할 수 있는지 확인한다. 정답 파형을 입력으로 주거나 기존 출력을 정답 배율로 보정하는 방식이 아니다.

혼합 STFT를 \(Z\), 본체의 네 복소 출력을 \(A_j\), 입력 STFT의 RMS를 \(q\)라 하면 두 표현은 다음과 같다.

\[
\hat S^{\mathrm{mapping}}_j
=qA_j+\frac{Z-q\sum_k A_k}{4}
\]

\[
\hat S^{\mathrm{masking}}_j
=ZA_j+\frac{Z-Z\sum_k A_k}{4}
=Z\left(\frac14+A_j-\frac14\sum_k A_k\right).
\]

두 방식 모두 출력 합은 \(Z\)다. 바꾸는 것은 복소 값의 직접 예측과 복소 곱셈 마스크라는 출력 표현이다. 본체·시간 평균 문맥·개수 head·손실은 그대로다. 신호 크기 가중 투영을 뒤늦게 적용하는 앞선 추론 실험과도 다른 비교다.

복소 마스킹과 합 일치 투영은 [Wisdom 등의 선행 연구](https://arxiv.org/html/1811.08521)에서 다룬 방법이다. 이 조합 자체를 새로운 이론이나 드론 분야에서 검증된 처방으로 주장하지 않는다. 해당 논문은 음성 향상 연구다.

## 공정한 진단 조건

| 항목 | 고정 조건 |
|---|---|
| 본체 | 같은 원 규모 U-Net, 각 32,142,859개 파라미터 |
| 초기화 | seed 0, 전체 초기 파라미터 동일 |
| 출력층 | **두 군 모두** 가중치·편향을 0으로 초기화해 처음에는 동일한 혼합/4 출력 |
| 입력 | 실제 RF 배치를 보존한 63,872 복소 표본, 같은 20.8896ms 평균 전력 문맥 |
| 학습 자료 | RFUAV 동일 TRAIN4: 2성분 2개와 3성분 2개, 행 4·5·2·11 |
| 예산 | 각 256업데이트, 실효 batch 4·microbatch 1 |
| 최적화 | FP32 AdamW, lr 5e-4, weight decay 1e-4, gradient clip 1 |
| 손실 | 같은 PIT NMSE·coherence·비활성/배경 오차, 합성 개수 CE 가중치 0.1 |
| 보고 | 단계 0·1·8·16·32·64·128·192·256의 2/3성분 NMSE와 복소 SI-SDR |

출력층 0 초기화는 두 새 군 사이의 통제이며, 이전 일반 초기화 U-Net의 학습 곡선과 같은 실험이라고 주장하지 않는다. 첫 단계에는 출력층이 먼저 학습하고 이후 본체로 파형 기울기가 전달되는 것을 검사했다.

이전 32업데이트 검사는 손실 감소만 확인했다. 이번에는 고정한 네 사례를 더 오래 학습해 양쪽 성분 수에서 NMSE가 0.1 이하까지 낮아지는지도 별도로 보고한다. 달성 여부는 아직 모른다. 이 기준은 학습 적합도 확인이며 논문 성능이나 일반화의 합격 기준이 아니다. 검사 가중치는 본학습에 재사용하지 않는다.

## 완료한 구현 검사

[전체 입력 CPU 검사](OUTPUT_PARAMETERIZATION_CPU_CHECK.json)는 원시 기록 대신 합성 난수를 사용했다. 직접 예측 분기는 출력층이 0이 아닌 경우에도 기존 부모 모델과 정확히 같은 출력을 냈다. 두 군의 초기 파라미터와 초기 출력이 같고, 두 번의 학습 갱신에서 출력층과 본체의 유한 기울기를 확인했다. 출력 합의 상대 오차는 약 \(10^{-14}\)였다. CPU에서 사용한 임시 가중치는 폐기했다.

마스크 표현에는 입력 STFT가 정확히 0인 칸에서는 모든 출력도 0이 되는 제약이 있다. 두 성분이 정확하게 상쇄된 칸의 비영 원성분을 이 표현으로 복원할 수는 없다. 또한 마스크를 만드는 본체는 실수·허수 채널을 처리하는 실수 가중치 신경망이므로, 출력에 복소 곱셈을 넣었다는 이유만으로 위상 회전 등변성을 보장하지 않는다.
