# 긴 복소 I/Q 문맥 모델: GPU 사전 검사 완료

같은 RFUAV TRAIN 혼합4개(2성분2개·3성분2개), 원 규모4,641,795파라미터, 각32업데이트. 두 군 모두20.8896ms 입력을 처리하고0.63872ms 구간을 복원한다. local은 복원 구간 밖 복소 표본을 가리고, 두 군 모두 전체RMS·평균전력 특징을 받는다.

|군|초기 NMSE|32업데이트 후 NMSE|학습·중간채점 시간 초|최대 할당 메모리 MiB|
|---|---:|---:|---:|---:|
|local|0.967364|0.570334|94.73|1233.41|
|long|0.967374|0.596051|94.68|1233.41|

고정된 4개 학습 혼합에서 NMSE가 감소했고 저장된 기울기는 유한하다. 소스·보존본·규약 해시, 개별/전체 평균, 1/8/16/32업데이트 기록을 검산했다. 최대 할당 메모리는 약 1.20 GiB이며 전체 GPU 사용량·예약 메모리와 다르다.

이는 원 규모 모델의 GPU 실행·역전파·초기 적합도 검사다. 소수 학습 혼합의 결과로 긴 문맥의 우월성이나 새 기록 일반화를 주장하지 않는다. 실제로 이 검사에서는 local의 최종 NMSE가 더 낮다. 가중치는 폐기하며, 후속 비교는 같은 seed0 새 초기값으로 각 5 epoch/375업데이트를 학습한다.
