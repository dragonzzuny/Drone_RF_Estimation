# 전력 배분 보조 손실: GPU 본 비교 시작

2026-10-09. 학습은 지도학습이고 입력·최종 복원 목표는 복소 I/Q 파형이다.
기존 STFT U-Net의 파형 손실에 상대 전력 배분 KL을 추가하는 효과를 분리해
시험한다. 현재 본 비교는 진행 중이며 완료된 검증 개선 결과가 아니다.

**실제 실행:** native CUDA, RTX 4070 Laptop, PID 3420134.
사전 진단 이후 공통 부모로 초기화했고 대조군 첫 epoch의 5업데이트/160혼합까지
진행한 것을 확인했다. GPU 순전파·역전파, microbatch2, optimizer update가 실제
동작한다. 이 수치는 시작 시점 스냅샷이며 최신 상태는 로컬 진행 파일이다.

| 통제 항목 | 고정 내용 |
|---|---|
| 모델 | 두 군 모두 원 규모 STFT U-Net, 32,142,859파라미터 |
| 초기화 | 같은 기존 선택 가중치, dense 추가 e1; 기존 e22 이력 유지 |
| 차이 | 기존 손실 / 기존 손실 + 0.1×상대 전력 배분 KL |
| 자료 | RFUAV 원기록 그룹 분할, 같은 대역·중심 정렬 합성, 동일 혼합 목록 |
| 예산 | seed0, 각 5 epoch·12,000혼합·375업데이트 |
| 최적화 | 새 AdamW, lr1e-5, batch32/micro2, float32, TF32 비활성 |
| 평가 | 매 epoch 같은 개발 검증 630혼합 전체, 1·2·3성분 각 210 |
| 선택 | 초기 epoch0 포함, 2·3성분 평균 NMSE 최소 |
| 채택 | 두·세 성분 각각 NMSE 감소와 복소 SI-SDR 증가 |

원래 I/Q 표본 오차와 coherence 손실은 유지한다. 보조 손실은 복원 I/Q와 정답
I/Q를 STFT로 분석해 성분별 상대 전력 비율을 비교한다. 학습용 정답은 추론에
전달되지 않으며, 혼합 전력이 성분 전력 합이라는 가정도 하지 않는다.

## 먼저 완료한 GPU 구현 진단

학습 네 혼합만 각 32번 업데이트했다. **이 가중치는 버렸고 본 실험에 사용하지
않는다.** 입력·가중치는 양쪽 동일하며, 네 혼합의 활성 성분 10개 평균이다.

| 조건 | I/Q NMSE | 복소 SI-SDR dB | 배분 KL |
|---|---:|---:|---:|
| 공통 출발 | 0.493785 | 3.5969 | 1.103307 |
| 기존 손실 32업데이트 | 0.402734 | 6.2314 | 0.803362 |
| 보조 손실 추가 32업데이트 | 0.398039 | 6.0603 | 0.723833 |

보조 손실군의 배분 KL과 NMSE는 더 작았지만 SI-SDR은 대조군보다 낮았다. 따라서
이 진단만으로 개선을 채택하지 않고 별도 기록 검증을 포함한 본 비교를 수행한다.
순전파 microbatch2 대 단일 예측의 상대 오차는 양쪽 모두 0이었다. 최대 torch
할당 메모리는 약 4.39GB이고 CUDA 예약량·디스플레이 메모리와는 구분한다.
양쪽 사전 진단은 각각 약 31초였으며 학습률이나 보조 손실 계수를 결과에 맞춰
다시 고르지 않았다.

## 직전 완료 실험과 관계

- 마지막 디코더에 긴 I/Q 문맥을 결합한 1D 비교는 5 epoch를 완료했고 3성분
  동시 개선 기준을 충족하지 못해 비채택이다.
- 고정 네 위상 추론 평균은 세 모델에서 전체 개발 검증을 완료했다. 현재 가장
  좋은 관측값은 기존 STFT + 네 위상 평균의 NMSE(2/3) 0.475592/0.660113,
  복소 SI-SDR 3.247/−2.469dB다. 3성분 NMSE 감소는 약 0.054%로 작다.
- 이번 본 학습 대조의 평가 추론은 양쪽 원래 1회 추론으로 고정했다. 한 군에만
  네 위상 평균을 적용하거나 그 결과로 학습 규약을 바꾸지 않는다.

최초 원 RF 주파수 간격은 보존하지 않은 합성이며 정답에 수신 잡음도 포함된다.
한 seed의 반복 개발 검증으로 물리 드론 수·미지 기체·실제 동시 수신 일반화나
논문 게재 가능성이 입증되지는 않는다. 보류 Autel/예약 확인 파일은 열지 않았다.
