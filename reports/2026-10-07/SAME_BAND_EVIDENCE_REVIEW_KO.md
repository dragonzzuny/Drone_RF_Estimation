# 같은 대역 시간 문맥 대조: 첫 동일 예산 결과와 검증 보완

2026-10-07 10:55 KST 확인. **원 규모 U-Net+TCN과 시간 평균 문맥 대조가 각각 첫 epoch/75업데이트를 완료했고 두 번째 epoch를 학습 중이다.** 첫 결과에서는 시간 문맥의 일관된 이점을 확인하지 못했다. 초기 수치로 구조를 바꾸지 않고, 고정한 5/10/25/50 epoch 비교를 계속한다.

## 무엇을 학습하고 있는가

복소 I/Q를 복원하는 약 0.639ms U-Net 경로에 약 20.972ms의 혼합 신호 특징을 TCN으로 연결했다. 각 모델은 32,142,859 파라미터다. 긴 경로는 64개 주파수 구간의 상대 전력과 상대 포락선의 시간 변화를 읽는다. 복소 위상은 짧은 복원 경로에서 사용하며, 긴 구간 전체의 복소 위상을 처리하는 구성은 아니다.

ordered군은 시간에 따른 특징 변화를 유지하고, mean군은 같은 특징을 시간 평균한 뒤 동일 TCN에 넣는다. 따라서 이 비교가 평가하는 것은 **시간 변화와 복원 창 위치에 맞춘 문맥의 추가 가치**다. FHSS 주기만의 효과를 분리한 실험이나 호핑 프로토콜을 해독한 실험으로 해석하지 않는다. 구조와 시간 정렬은 [모델 설명](../../docs/TEMPORAL_MODEL_KO.md)을 따른다.

두 군은 같은 seed 0 초기 가중치, 같은 합성 목록, 같은 손실과 업데이트 예산을 사용한다. RFUAV 한 데이터셋의 100MS/s 기록을 같은 RF 대역 안에서만 합성한다. 기저대역 중심을 맞춘 합성이며 실제 수신 중심주파수 차이를 유지한 동시 비행 측정은 아니다. 이전 대역 간 합성이 포함된 25 epoch 탐색 결과와 직접 비교하지 않는다.

## 첫 동일 예산 결과

군당 2,400개 학습 예시/75업데이트 이후, 동일한 개발 검증 630개를 평가했다. 표는 **epoch 1 자체의 결과**다. 여러 epoch 중 고른 최종 성능이나 독립 평가 성능이 아니다. NMSE는 정답 파형에 대한 무배율 보정 I/Q 오차다. SI-SDR은 평균을 제거하고 일정한 복소 배율에 불변인 기존 구현을 사용한다.

| 지표 | 시간 문맥 TCN | 시간 평균 문맥 대조 |
|---|---:|---:|
| 기존 1/2/3 성분 평균 NMSE ↓ | 0.739615 | 0.741458 |
| **2/3 성분만 평균한 NMSE ↓** | **0.940939** | **0.943542** |
| 2성분 NMSE ↓ | 1.014281 | 1.019898 |
| 3성분 NMSE ↓ | 0.867597 | 0.867187 |
| 2성분 혼합 대비 SI-SDR 개선량 ↑ | +0.051 dB | +0.232 dB |
| 3성분 혼합 대비 SI-SDR 개선량 ↑ | −0.301 dB | −0.237 dB |
| 2성분 중 두 성분 모두 SI-SDR 개선 | 40.00% | 40.48% |
| 3성분 모두 SI-SDR 개선 | 24.29% | 27.62% |

2/3 성분 NMSE 차이는 TCN 쪽이 약 0.28% 낮지만, 3성분 NMSE와 두 조건의 SI-SDR 개선량에서는 시간 평균 대조가 조금 낫다. 한 seed의 첫 epoch이므로 어느 구조의 우월성도 주장할 단계가 아니다.

1성분은 혼합 입력 자체가 정답이다. 이 조건은 통과 복원·불필요한 출력 억제를 평가하는 데 필요하지만 다중 신호 분리 성공의 근거로 쓰지 않는다. 기존 1/2/3 평균 체크포인트 선택 규칙은 유지하면서 **2/3 성분 평균과 각 개수별 지표를 함께 보고**한다. 단일 신호 SI-SDR이 약 29dB여도 NMSE가 약 0.337인 사례처럼, 배율 불변 지표만으로 진폭 복원을 판단하지 않는다.

## 실제 창별 전력차가 설정값과 얼마나 다른가

저장된 정답 성분 전력과 고정 합성 목록을 CPU에서 대조했다. 원시 I/Q를 다시 읽거나 모델을 재실행하지 않았다. 아래 SIR은 **한 기록 성분의 전력 / 나머지 기록 성분의 전력 합**이다. 각 기록의 수신 잡음도 포함하므로 송신 신호만의 SIR/SNR 또는 활동 주석과 같지 않다.

| 입력 진단 | 2성분, 210혼합 | 3성분, 210혼합 |
|---|---:|---:|
| 하나 이상 성분에서 실제 창 SIR과 긴 구간 설정 SIR의 차이가 3dB 초과 | 70.00% | 80.95% |
| 성분별 실제 창 SIR 범위 | −51.39∼+51.39 dB | −29.92∼+24.10 dB |
| 자기 긴 구간 평균보다 20dB 넘게 조용한 성분이 포함됨 | 17.14% | 0.95% |

두 성분의 설정 전력이 다른 140혼합 중 **19개(13.57%)는 짧은 창에서 강·약 순서가 뒤집혔다.** 따라서 설정 +10/−10dB만 보고 어느 기체가 약한지 정하면 일부 사례를 잘못 분류한다. 이는 긴 구간에서 합성한 뒤 자를 때 보존되는 국소 변동이며, 그 자체로 구현 오류나 성능 저하 원인의 입증은 아니다.

첫 epoch TCN의 2성분 결과에서 국소 SIR < −20dB인 40개 성분의 평균 NMSE는 5.098, 나머지 중 −20∼−10dB인 65개 성분은 0.958이었다. 매우 약한 구간이 평균에 큰 영향을 주는 관찰이다. 조용한 구간을 제외해 수치를 높이지 않고, 전체 결과와 국소 SIR별 결과를 함께 유지한다. 실제 송신 부재나 잡음 지배 여부는 별도 활동 근거 없이 단정하지 않는다.

## 개수 추정에서 확인한 혼동 요인

현재 알려진 세 기종 혼합은 AVATA2+FPV COMBO+MAVIC3 PRO 한 조합이며 모두 5.8GHz다. 2.4GHz에는 MINI3+MINI4 PRO 두 기종만 있다. 따라서 자료의 대역과 구성 성분 수가 독립적이지 않다.

학습 목록만 보고 대역별 최빈 개수를 정하는 간단한 메타데이터 기준선을 계산했다. 이 기준선은 2.4GHz이면 1, 5.8GHz이면 3을 출력한다. 검증 정답으로 이 규칙을 맞추지 않았다.

| 구성 성분 수 정확도 | epoch 1 개발 검증 |
|---|---:|
| 전체 최빈 개수 기준선 | 33.33% |
| **학습 목록으로 정한 대역별 최빈 개수 기준선** | **46.67%** |
| 시간 문맥 TCN | 49.84% |
| 시간 평균 문맥 대조 | 47.46% |

대역 메타데이터는 이 진단 기준선에 제공되며 신경망의 개수 head에 직접 제공되지는 않는다. 모델이 이 규칙을 사용한다고 입증한 결과도 아니다. 다만 33.33%를 넘었다는 사실만으로 신호 개수 구조를 배웠다고 말할 수 없음을 보여준다. 특히 TCN의 2성분 개수 정답률은 첫 epoch에서 1/210에 불과하다. 이후에도 개수별 혼동행렬과 대역·조합별 결과를 확인한다.

현재 개수 정답은 합성에 사용한 **기록 성분 수**다. 기체 폴더의 송신 방향, 국소 송신 활동, 같은 기종의 서로 다른 물리 기체를 확인한 주석은 아니다. 개수 예측은 파형 출력을 강제로 자르거나 기종을 배정하지 않는다.

## 추론·일반화·배경 출력 점검

- 실제 `predict()`는 혼합 STFT, 그 혼합에서 계산한 긴 문맥 특징, 창 위치만 모델에 전달한다. 정답 파형·기체명·정답 개수를 읽으면 실패하는 CPU 검사도 통과했다. 정답은 학습 손실과 평가 시 전체 창의 출력 순열 대응에만 사용한다.
- 학습 원기록 묶음은 8개, 검증 묶음은 5개로 겹치지 않는다. 검증의 각 기종은 원기록 묶음 1개다. 630개 혼합을 630회의 독립 녹음이나 독립 실험으로 세지 않는다. 기종과 검증 묶음, 일부 수신 대역폭 차이는 분리해서 추정하기 어렵다.
- 보류한 Autel I/Q와 별도 확인용 기록을 이번 분석에서 개봉하지 않았다. 동일 기종의 새로운 묶음 검증과 미학습 기종 검증을 구분한다.
- 긴 파형을 여러 창으로 복원할 때의 출력 순서 추적은 이번 짧은 창 평가와 다른 과제다. 창마다 정답을 보고 기종을 바꾸어 붙인 결과를 긴 파형 복원 성능으로 쓰지 않는다.
- 세 기여 기록에는 각자의 수신 잡음이 포함되어 있고 별도 배경 출력의 현재 정답은 0이다. 따라서 이 학습으로 잡음을 제거한 깨끗한 송신 파형이나 실제 드론/외부 배경 분리까지 입증한 것은 아니다. 첫 epoch 배경 출력에는 혼합 전력 대비 약 0.10의 에너지가 남아 있어 별도 지표로 추적한다.
- 사전 고정 3혼합/48업데이트 검사는 파형 손실 감소를 확인했다. 원파형에 정밀하게 적합했거나 미지 입력에 일반화했다는 검사는 아니다.

## 다음 단계와 실제 연결

1. **현재 두 군의 고정 학습을 유지한다.** 5/10/25/50 epoch에서 기존 규칙으로 선택한 체크포인트와 동일 epoch 진행 상태를 구분한다. 구조 변경은 별도 비교로 기록한다.
2. **전체 평균과 2/3성분·국소 SIR·기종별 결과를 동시에 확인한다.** NMSE 감소와 SI-SDR 개선이 함께 나타나는지, 어느 한 성분만 복원하는지, 불필요한 출력에 에너지가 남는지 점검한다.
3. **원인을 구분한 후 다음 변경을 정한다.** 극약신호 구간만 악화하는 경우에는 활동·잡음과 국소 전력 학습 분포를 먼저 검토한다. 같은 조건에서 시간 문맥의 이점이 없으면 단순히 TCN을 크게 만들었다는 이유로 채택하지 않는다. 개수별 실패는 파형 복원과 별도로 진단한다.
4. **일반화 검증은 모델·평가 규약을 고정한 뒤 수행한다.** 미학습 기종으로 손실 가중치나 체크포인트를 고르지 않는다. RFUAV와 DroneDetect는 독립 실험으로 유지한다.

CPU 보고서 자동 생성기를 실제 실행했다. 첫 동일 예산 보고서 생성이 완료됐고, 다음 5/10/25/50 epoch에서 양쪽 완료 파일이 모두 생긴 후 같은 분석을 수행한다. 학습 소스·스케줄·체크포인트는 수정하지 않으며, CPU 코어 14/15·낮은 CPU/I/O 우선순위를 사용한다. 이 자동 생성기는 채팅 메시지를 전송하거나 결과를 자동 채택하지 않는다.
