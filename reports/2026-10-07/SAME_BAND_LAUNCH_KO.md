# 같은 대역 GPU 실행 및 기존 25 epoch 결과

확인 시각: 2026-10-07 10:31 KST.

**새 RFUAV 단일 데이터셋·같은 대역 GPU 작업이 시작됐다.** GPU 순전파·역전파 검사와 고정 혼합 학습 검사가 통과했다. 기존 두 군은 각각 25 epoch/1,875업데이트와 단계 평가를 완료한 상태로 보존했다. 새 실험 후 기존 비교의 나머지 예산을 재개하도록 실행 순서를 연결했다.

## 새 실행

추가 확인: 10:32 KST, 새 시간 순서 모델의 1 epoch에서 5회 optimizer 업데이트를 확인했다. 준비·진단 단계에서 실제 본 학습으로 전환됐다.

- 두 군 모두 32,142,859개 파라미터이며 초기 가중치 해시가 같다. 기존 결과의 가중치를 이어받지 않고 새 seed 0 초기화에서 학습한다.
- 입력은 RFUAV 내부 같은 대역의 혼합만 사용한다. 학습/검증 분할과 새 고정 검증 630개는 봉인한 규약을 따른다.
- 1/2/3개 고정 혼합을 48업데이트 학습하는 진단에서 파형 손실이 감소했다. 이 가중치는 본 학습에 사용하지 않는다. 이는 구현의 학습 가능성 검사이고 새 자료 일반화 성능이 아니다.
- 긴 문맥은 약 21ms의 전력·주파수 특징이며, 약 0.64ms의 복소 STFT 복원 경로에 위치를 맞춰 전달한다. 전체 긴 구간의 복소 위상을 직접 처리하는 구조로 표현하지 않는다.
- 새 화면 공유 프로세스가 기존 GPU 검사에서 미등록으로 분류돼 잠시 대기했다. 해당 RustDesk 프로세스의 PID·시작 시각·실행 파일·명령줄을 고정하고 사용 메모리 256MiB 이하만 허용하는 별도 실행 검사를 추가했다. 화면 공유 프로세스와 이전에 봉인한 자원 규약은 변경하지 않았다. GPU 신원·메모리 여유·다른 연산 프로세스 검사는 유지한다.
- 프로세스 전환 6개, 혼합 제약 7개, 추가 자원 검사 5개의 코드 검사가 통과했다. 실제 이전 체크포인트 복사 해시와 새 GPU 실행도 확인했다.

## 기존 탐색 비교: 같은 25 epoch 기회에서 선택한 결과

| 지표 | 시간 순서 TCN | 시간 평균 대조 |
|---|---:|---:|
| 선택된 epoch | 23 | 11 |
| 전체 검증 NMSE | 0.526027 | 0.532076 |

TCN의 전체 NMSE는 대조보다 1.14% 낮다. 한 seed의 검증 선택 결과이고 차이가 작으므로 통계적 우월성이나 범용성을 확정하지 않는다. epoch별 값은 변동했으며, 마지막 epoch만 유리하게 골라 비교하지 않았다.

아래는 동일 선택 체크포인트의 저장된 검증 행을 원래 수신 대역별로 다시 집계한 값이다. 각 하위 집단에 맞춰 체크포인트를 다시 고르지 않았다.

| 성분 수·대역 | 사례 수 | TCN NMSE | 대조 NMSE | TCN 혼합 대비 SI-SDR 개선 | 대조 개선 |

같은 대역의 세 성분 조건은 기존 검증에서 21사례뿐이었다. TCN의 해당 절대 SI-SDR도 약 −5.024dB로 잔여 오차가 크다. 새 같은 대역 학습의 결과가 나왔다는 뜻이 아니다. 서로 다른 하위 집단은 신호 조합까지 달라 대역 자체의 인과 효과를 이 표로 주장하지 않는다. 모든 수치는 짧은 파형 검증이며 실제 물리 드론 대수·실측 동시 혼합·미학습 기종 검증은 아직 남아 있다.
