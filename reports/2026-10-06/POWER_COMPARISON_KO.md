# 전력 처리 대조: 50 epoch 완료와 채택 판단

2026-10-06. **이번 설정에서는 긴 기록의 전력을 유지한 학습이 기존 창별 정규화보다 나빴다. 이 변경을 현재 N의 개선안으로 채택하지 않는다.** 학습 50 epoch·3,750 업데이트, 예정한 네 단계 평가, 저장 출력 84개 재검산을 완료했다.

## 비교 조건

두 군은 같은 5 epoch 부모 체크포인트에서 시작한 원 규모 N(31,391,752 파라미터)이다. 부모 이후 각 50 epoch·3,750 업데이트, seed 0, 자료 위치·상대 위상·순서·손실·옵티마이저·검증 선택 규칙을 맞췄다. 차이는 학습 시 짧은 창마다 개별 신호 전력을 다시 맞추는지 여부다. 기존 대조는 완료된 실행을 재사용했다. 무작위 초기화부터 학습한 비교나 독립 seed 반복은 아니다.

평가는 DRFF-R2의 D1 개발 자료 12조건이다. Air 2/Mavic 3 및 Air 2S/Mavic 3 조합, −10/0/+10dB, 각 두 구간을 포함한다. D1은 반복적으로 확인한 개발 자료이며 독립 시험이 아니다. 최종 비교는 50 epoch 예산 안에서 같은 검증 규칙으로 선택한 모델이다. 선택 시점은 기존 N 26 epoch, 전력 보존 N 18 epoch다.

## 최종 파형 성능

| 지표 | 기존 창별 정규화 N | 긴 구간 전력 보존 N |
|---|---:|---:|
| 두 성분 전체 평균 NMSE ↓ | **0.377778** | 0.970858 |
| −10dB 약한 Air 계열 NMSE ↓ | **0.694697** | 2.343946 |
| +10dB 약한 Mavic 3 NMSE ↓ | **0.688986** | 2.053164 |
| 약한 Air 계열 절대 SI-SDR ↑ | **−3.075dB** | −9.101dB |
| 약한 Mavic 3 절대 SI-SDR ↑ | **−2.704dB** | −9.481dB |
| 두 성분 모두 입력보다 SI-SDR 개선 | **12/12** | 5/12 |
| 저장 평가의 순열 맞춤 후 평균 NMSE ↓ | **0.377778** | 0.966689 |

전체 NMSE는 기존 대비 약 2.57배(+156.99%)다. 출력 순서를 맞춘 뒤에도 악화가 유지돼 단순한 기체 이름/출력 순서 뒤바뀜으로 설명되지 않는다. 양쪽 약신호의 NMSE와 절대 SI-SDR이 모두 악화했으므로 평균 개선과 약신호 악화 사이의 절충 결과도 아니다. 기존 N 역시 약신호 절대 SI-SDR이 음수이므로 완벽 복원으로 해석하지 않는다.

| 학습 예산 | 기존 N 전체 NMSE | 전력 보존 N 전체 NMSE |
|---:|---:|---:|
| 5 epoch | 0.926305 | 0.952004 |
| 10 epoch | 0.615582 | 0.952004 |
| 25 epoch | 0.429199 | 0.970858 |
| 50 epoch | 0.377778 | 0.970858 |

25·50 epoch 평가에서 전력 보존 군은 같은 18 epoch 체크포인트를 선택했다. 중간 개발 결과를 보고 예산을 줄이거나 유리한 단계로 바꾸지 않았다.

## 저장 파형 검산과 전력 구간 분석

예정된 출력 84개(합성 혼합 48, 단독 입력 32, 정답 없는 실제 혼합 4)를 별도 NumPy 경로로 재계산했다. NMSE 재계산의 최대 차이는 4.89×10⁻¹⁴였다. 실제 혼합 4개에는 성분별 정답이 없어 복원 NMSE를 제시하지 않는다.

추가 CPU 분석은 두 최종 모델의 저장 출력 24개를 비중첩 63,872표본 구간과 마지막 짧은 구간으로 나눴다. 총 1,584개 성분 구간을 확인했다. 전력 구분에는 이전에 학습 자료에서 정한 기종별 25·75백분위 임계값을 그대로 사용했다. 이번 평가 결과에 맞춰 임계값을 다시 정하지 않았다.

| 약한 성분 | 상대 전력 구간 | 기존 N 구간 NMSE | 전력 보존 N 구간 NMSE |
|---|---|---:|---:|
| Air 계열 | 낮음 | 4.5268 | 62.3216 |
| Air 계열 | 중간 | 0.6740 | 2.3712 |
| Air 계열 | 높음 | 0.6878 | 1.6041 |
| Mavic 3 | 낮음 | 2.6352 | 15.5082 |
| Mavic 3 | 중간 | 0.7703 | 1.9112 |
| Mavic 3 | 높음 | 0.5001 | 1.3196 |

이 표는 각 구간 묶음의 오차 에너지 합/정답 에너지 합이다. 위의 네 사례별 NMSE 평균과 집계법이 다르므로 같은 분모의 수치로 비교하지 않는다. 전력에는 수신 잡음도 들어 있어 낮은 전력 구간을 송신 부재 정답으로 해석하지 않는다.

각 구간의 오차를 해당 전체 파형 정답 에너지로 정규화해 전체 NMSE 증가에 대한 기여도도 계산했다. 추가 오차 중 **Air 계열 약 85.7%, Mavic 3 약 68.3%는 중간·높은 전력 구간**에서 발생했다. 이번 악화를 저전력 구간 몇 개의 문제로 한정하기 어렵다. 다만 최적화·검증 선택·활동량 가중치 중 어떤 요소가 원인인지는 이 사후 분석으로 확정할 수 없다.

## 다음 실행과 해석 범위

다음 GPU 대조는 기존 창별 정규화를 유지하며 기존 I/Q 손실에 **비로그 STFT 크기 L1 항만 추가**한다. 같은 부모·50 epoch·3,750 업데이트 비교이며, 전력 보존 학습과 크기 손실을 동시에 바꾸지 않는다. 이번 결과를 확인해 유리하게 바꾼 처방이 아니라 이미 따로 정한 대조다. 크기 지표와 실제 I/Q 오차가 함께 감소하는지 확인한다.

RFUAV 다기종 혼합 입력 준비와 이번 DRFF 모델 성능은 별개다. RFUAV의 국소 전력 변동을 보존하는 로더는 구현·검산돼 있지만, 성능 개선이 검증된 학습 처방으로 표시하지 않는다. 새로운 자료의 GPU 학습 규약을 고정할 때 전력 처리와 선택 지표를 명시해야 한다.

이 결과는 NMF 없는 U-Net의 전력 처리 대조다. Deep NMF 전체 방법이나 모든 정규화 기법이 무효라는 결론은 아니다. [단계별·조건별 수치와 해시](power_comparison.json), [구간별 분석과 검산](power_activity.json)에 실패 조건을 포함한 결과를 남겼다.
