# 비로그 STFT 크기 손실의 25 epoch 중간 대조

DRFF-R2 D1의 기존 개발 평가 12개 합성 혼합에서 **같은 부모 체크포인트 이후 25 epoch·1,875업데이트**를 비교했다. 두 군 모두 검증으로 선택한 epoch 22 모델이다. 기본 파형 손실에 비로그 STFT 크기 L1을 추가한 군의 전체 평균 NMSE가 **0.429199 → 0.389153**, 약 **9.33% 감소**했다.

| 지표 | 기존 N 대조 | 크기 손실 N |
|---|---:|---:|
| 두 성분 평균 NMSE ↓ | 0.429199 | 0.389153 |
| −10dB 약한 Air 계열 NMSE ↓ | 0.762164 | 0.669618 |
| +10dB 약한 Mavic 3 NMSE ↓ | 0.832216 | 0.796786 |
| 약한 Air 계열 SI-SDR ↑ | −3.925dB | −2.567dB |
| 약한 Mavic 3 SI-SDR ↑ | −3.725dB | −3.636dB |
| 두 성분 모두 혼합 대비 SI-SDR 개선 | 9/12 | 12/12 |

양쪽 약신호 NMSE가 감소했지만 개선 폭은 다르고, 절대 SI-SDR은 여전히 음수다. 최종 채택은 동일 50 epoch 결과에서 판단한다. 새 RFUAV 자료·시간 문맥 모델·세 신호 분리의 성능을 뜻하지 않는다.

seed 0, 반복 사용한 D1 개발 자료다. 모델 선택을 하지 않은 독립 확인 시험이나 다중 seed 우월성 검증은 아니다. 모든 12조건을 집계했고 성공한 사례만 골라 평균하지 않았다.

CPU에서 대조군과 실험군의 저장 출력 24개를 다시 읽어 독립 NumPy 계산으로 NMSE와 SI-SDR을 검산했다. NMSE 최대 차이는 **6.13×10⁻¹⁴**, SI-SDR 최대 차이는 **1.60×10⁻¹³dB**였다. 입력 수신 기록 해시·평가 조건·부모 체크포인트·업데이트 수가 같은지 확인했다. 전체 단계의 크기 지표·단일 입력 검사까지 완료됐다는 뜻은 아니다.
