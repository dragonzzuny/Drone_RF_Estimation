## 실제 실행한 CPU 작업

GPU N 학습은 16/50번째 epoch에서 계속되고 있다. 별도의 CPU 프로세스는 코어 14·15에 묶고 nice +10, I/O best-effort 우선순위 7로 실행했다. CUDA를 사용하지 않는다. 현재 37/131개 파일, 긴 I/Q 구간 111개를 처리했다. 관찰된 프로세스 최대 RSS는 152.1MiB다.

1. 드론 학습·검증 후보 131파일의 전체 SHA256을 계산한다. 총 읽기 대상은 102,867,677,072바이트다.
2. 같은 읽기에서 각 파일의 25·50·75% 위치를 기준으로 2,097,152표본(20.97152ms)씩 세 구간을 복사한다. 최종 계획은 학습 249구간, 검증 144구간, 총 393구간이다. 정규화·리샘플링을 하지 않은 복소 I/Q를 SSD에 저장한다. 이것을 전체 원자료를 모두 학습한 것으로 부르지 않는다.
3. 전체 파일의 정확한 중복을 확인한 뒤 학습·검증 캐시 사이의 시간 이동·복소 배율 유사도를 계산한다. 8,192표본 구간에서 ±1,024표본 이동을 검사하고, 제곱 상관 0.98 이상인 쌍은 63,872표본으로 다시 확인한다. 높은 상관은 공통 프로토콜 구조일 수도 있어 자동으로 복제라고 판정하지 않는다. 이 제한된 검사만으로 모든 유사성·과적합을 배제하지 않는다.

조종기와 미지 기종 후보 Autel 파일은 이 작업의 읽기 대상에서 제외했다. CPU 캐시 준비 완료와 새 GPU 분리 모델의 학습·평가 완료는 별개다. 송신원·세션·분할 검토가 남아 있어 결과 파일도 자동으로 최종 학습 승인 상태가 되지 않는다.

코드·수치 검사 총 14개를 통과했다. FFT 기반 이동 상관을 독립적인 직접 합산과 비교했고, 배율·위상·시간 이동을 준 신호, 상수 입력, 원기록 묶음의 역할 혼입 및 바이트 단위 캐시 추출을 검사했다.
