# 실제 I/Q 혼합 입력 검산

2026-10-06. RFUAV 개발 후보의 첫 학습 epoch 2,400개와 검증 120개를 실제 I/Q 배열로 생성해 검사했다. 모델을 학습하거나 분리 성능을 평가한 결과는 아니다. 미지 기종 후보 Autel과 기존 DRFF 확인용 자료는 열지 않았다.

## 완료한 내용

- 긴 2,097,152표본 문맥의 전력으로 각 성분의 배율을 정하고, 63,872표본 창을 잘랐다. 표본률 100MHz에서 각각 20.97152ms와 0.63872ms다. 짧은 창마다 개별 전력을 다시 맞추지 않는다.
- 두 성분에 독립 복소 위상을 적용했다. 설정 SIR은 첫 성분 전력/둘째 성분 전력의 dB 값이다. 명목상 두 성분 전력의 합이 1이 되도록 공통 배율도 적용한다. 실제 혼합 전력에는 두 신호의 교차항이 포함된다.
- 검사한 2,520개 모두 입력과 정답 두 성분의 합이 정확히 일치했다. 원래 창의 전력을 별도로 계산한 예상 SIR과 실제 합성 SIR의 최대 차이는 **6.80×10⁻⁸dB**였다.
- 각 역할의 처음 10개 혼합은 반복 생성한 결과가 바이트 단위로 동일했다. 원 규모 모델·손실·자료 검사까지 포함한 CPU 단위 검사 **21개**가 통과했다.
- 이번 검사는 캐시 393개 중 **362개**를 실제로 사용했다. 앞서 완료한 전체 393개 캐시 검산과 범위가 다르다. 첫 epoch와 120개 검증 조건을 검사했으며, 50 epoch의 모든 파형을 생성한 것은 아니다.

## 관찰: 설정 전력차와 짧은 창 전력차는 다르다

학습 창의 **84.0%(2,016/2,400)**, 검증 창의 **81.7%(98/120)**에서 설정값과 실제 국소 SIR이 3dB 넘게 달랐다. 국소 전력 변동을 제거하지 않고 합성한 결과다. 설정한 −10dB/+10dB만으로 모든 짧은 창의 약한 기종을 지정하면 잘못 분류하는 창이 생긴다. 0dB의 순서는 원자료 기종 이름의 고정 정렬이며, 중앙값의 양수 편향을 모델 출력 편향으로 해석하지 않는다.

이 결과는 **RFUAV의 이번 합성 입력**에 대한 관찰이다. 과거 DRFF에서 관찰한 잔차의 원인이나 새로운 학습 방식의 성능 우월성을 입증하지 않는다. 검증 조건은 묶음별 대역폭도 달라 학습 조건과 같은 분포라고 보장하지 않는다. 검증 결과를 보고 유리한 혼합만 다시 뽑지 않았다.

## 다음 평가에 반영할 내용

새 다기종 실험에서는 명목 SIR별 전체 결과와 실제 창별 SIR별 결과를 함께 보고한다. 주 지표/체크포인트 선택 규칙은 GPU 학습 전에 고정하고, 부진한 조건도 전체 집계에 유지한다. 수신 잡음을 포함한 전력과 실제 송신 활동을 구분한다. 이 검사에서 전력이 작다는 이유만으로 드론이 없다는 정답을 붙이지 않는다. 기존 실행 중인 DRFF 실험의 봉인한 규칙은 변경하지 않았다.

2,520개 중 2,280개는 원기록의 중심주파수가 서로 다르다. 모두 복소 기저대역 좌표를 맞춰 합친 **합성 혼합**이며 실제 같은 대역에서 동시 수신한 자료가 아니다. 기종별 원기록에는 수신 잡음도 들어 있다. 배경 정답을 0으로 둔다는 것은 추가 배경 기록을 섞지 않았다는 뜻이며 원자료가 무잡음이라는 뜻이 아니다.
